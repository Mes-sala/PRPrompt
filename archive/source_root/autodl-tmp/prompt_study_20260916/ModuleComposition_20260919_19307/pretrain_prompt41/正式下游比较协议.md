# 正式四路＋预训练＋Prompt比较协议

本协议在新一轮query评分前确定。数据集为ENZYMES、MUTAG、PROTEINS，沿用原20个5-shot支持组和固定query。标签和图总体此前已用于开发，因此属于开发比较，不能称盲测。

每个数据集14个编码器条件：标准随机GCN、DGI_both、GraphCL_full、SimGRACE_full、GraphMAE_full、GraphMAE2、S2GAE、Bandana、Edgepred_GPPT native/full、Edgepred_Gprompt native/full、GraphMultiGprompt匹配随机架构/修复预训练。全部seed101，共42条件，其中涵盖10类预训练目标。额外优化器版本与专用随机架构是对照，不算新的预训练家族。

每条件、每支持组训练GPF-plus、Gprompt、二者联合三个Prompt接口，学习率0.001/0.01，200步固定支持更新并保留100/200端点；头seed42、Prompt seed4242，Adam权重衰减0.0005。共5040个训练作业。每个作业同时封存初始化0步、100步和200步的四路、HM、WA、H、M与独立原生读出，共90720条相关端点指标；另有42×20×5=4200条无Prompt指标。0步在两学习率之间重复，必须注明相关性，不当成独立重复。

GCN权重、运行模式冻结。输入Prompt通过GCN反传，输出Gprompt只改变末层。W/A使用原始输入；H/M在每个端点从提示后的节点表示重新计算。训练FP32，最终特征与核岭FP64；原生分类头也以FP64执行已训练参数，不能与ProG36原生FP32评分混为逐位重放。核读出沿用六正则、带截距、先单纯形投影再平均；四路round(10)取argmax，独立分类头不舍入。独立增广系统检验岭分数与最终类别；若数值检验失败，停止并保存问题，不自动跳过或改为较有利类别。

所有42条件封存完成后才统一评分。结果至少比较：同权重无Prompt、同初始化未训练Prompt、当前标准随机四路，以及旧三seed随机四路指标均值/已有强具名四路作为补充参照。GraphMultiGprompt另比较专用架构随机基线。不能用不同query的准确率直接相减。

候选筛查沿用设计文档：对当前随机四路和同权重无Prompt均至少+1pp，同时报告配对区间、非负支持数、宏F1/recall和未训练提示对照；回顾选最高端点只用于开发候选，不作为部署选参器。选中后补seed211/307与冻结重划分验证。没有通过的条件也完整记录。

只保存一次预训练GCN参数；各作业保存小型Prompt/头状态和分数、类别、支持身份、源码/权重指纹及损失轨迹。预训练完成和准入通过是执行前提。首次smoke因来源清单误包含本地管理脚本而在运行前失败，已保留原清单/错误，改为递归引用代码加全部ProG快照；没有改变算法、训练预算或预测。
