# 两类边预测预训练适配

复用ProG的Edgepred_GPPT和Edgepred_Gprompt损失及原生前向。输入替换为此前准入的无标签图列表，结构负采样按断开图并集执行，保留原实现允许跨图负样本的行为。输出维度沿用边预测的2，不读取图分类标签。

两方法的原生优化器只覆盖GCN，未覆盖graph_pred_linear。因此分别运行native与full两个具名版本：native保持投影头固定，full将投影头与GCN一起优化；不能悄悄修复后统一声称原生结果。两版本同seed101、同GCN初始权重、同负采样初始化。采用100次全边/三元组批次更新，不按query或训练损失选模型。这与原生64样本小批次预算不同，比较中必须保留预算标签。

三个数据集×两个目标×两个优化器版本，共12份编码器。先执行单步准入，验证有限损失、GCN实际更新、投影头更新范围，再进行生产。绑定源码及预算的文件为edge_pretrain_freeze.json。下游全部版本单列比较，full作为预先指定的主适配版本，native作为优化器行为对照；不从query选取“原生版本”。
