# GraphMAE2、S2GAE、Bandana适配冻结说明

这三个ProG端口默认仅接受节点数据集，但提供显式`data=`输入。采用原图列表的断开并集作为无标签节点图，保留全部节点属性和图内边；消息传递不增加图间边。分类标签不进入预训练。这是明确的图数据适配，不是原作者图分类预训练复现。

三数据集各训练seed101，沿用原random_s101的两层128维GCN初始化。调用快照原生`pretrain_one_epoch`，原优化器、默认掩码/带宽参数保持不变；100次全并集更新后导出编码器，不按query或训练损失选checkpoint。GraphMAE2的EMA编码器同步到匹配初始权重。不同于旧GraphMAE的100轮小批次训练，因此只能比较具名预算条件，不将方法间差异全部归因为目标函数。

S2GAE和Bandana原生负采样在整个并集中进行，可能取到不同原图之间的负边；这与图内负采样不同，保留原端口行为并明确记录，不悄悄改成另一种目标。后续如果该差异成为必要研究问题，另立协议比较，不以query涨点决定本轮实现。

生产前先进行三个数据集×三个方法的单步准入，验证有限损失、编码器确实更新和导出；单步准入不算预训练方法已完成。所有源码、初始权重和100步预算绑定到`masked_pretrain_freeze.json`。生产输出保存在`masked_training/`，不覆盖旧模型。
