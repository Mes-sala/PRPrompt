# GraphMultiGprompt的显式修复版

当前快照GraphPrePrompt.pretrain构造优化器并计算损失，但没有loss.backward或optimizer.step，且每个batch重建Adam。不能把这个循环的导出权重视为经过目标优化的编码器。BatchNorm运行统计可能在前向变化，因此“没有参数更新”不等同于所有state_dict值都不变。

本轮保留原GcnLayers、DGI/GraphCL/LP损失和0.9/0.9/0.1权重；单独实现持久Adam(lr=0.0001)及反向更新。使用原图顺序身份校验后的无标签输入，绕开读取图分类y的process_tu，用断开并集直接构造邻接。保留原normalize(A+I)+I的算子，不改成标准GCN归一化。稀疏计算替代原稠密邻接。

seed101、两层128维、dropout0.3，固定100轮，每批最多32图、不丢尾批。原始/两份增广邻接与50负样本表在训练前固定并保存，特征打乱每步重新产生；边增广按原0.1比例的删除/添加规则，用均匀拒绝采样取代枚举所有非边，随机数轨迹不同，不声称逐位复现原增强。保留损失公式原貌，包括原LP中温度的实际位置，不无声修正。

每个数据集保存该专用架构的初始随机编码器，作为下游匹配对照；它不能与标准GCN随机参数互相加载。单步准入先确认原生前向不更新可学习参数，加入backward/step后才有参数更新。源码检查与这一局部重放不等于执行原1000轮预训练。

本版本必须标记为GraphMultiGprompt repaired adapted，不能与原作者结果或未修复端口混报。此处修复只保证实际优化发生，不预设分类效果。
