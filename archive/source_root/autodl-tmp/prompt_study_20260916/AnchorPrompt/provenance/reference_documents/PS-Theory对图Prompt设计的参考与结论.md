# PS-Theory 对图 Prompt 设计的参考与结论

整理日期：2026-09-15

论文：*Message Tuning Outshines Graph Prompt Tuning: A Prismatic Space Perspective*，ICML 2026。

来源：[论文摘要](https://arxiv.org/abs/2606.03290)、[正文与附录](https://arxiv.org/html/2606.03290v1)、[作者代码](https://github.com/CYCUCAS/MTG)。

本文依据论文及讨论整理，区分论文理论表述、数学上的局部推论与待验证的设计建议；不构成对全部证明的独立验证，也不包含代码复现或新增实验结果。

## 1. 核心结论

PS-Theory 最有价值的设计视角是：**评估 Prompt 应同时考虑干预位置、传播方向和冻结 backbone 的变换能力。** Prompt 参数量增加，并不必然增加最终可用的任务信息。

由此可以形成三个设计问题：

1. Prompt 产生的变化能否穿过后续 GNN 层并到达最终读出？
2. 到达输出的变化是否作用于任务需要的方向？
3. 少量标签是否足以学到这种变化，并使其在未见样本上有效？

PS-Theory 主要帮助分析第一个问题；后两个问题仍需要任务监督、容量控制和泛化实验。

## 2. 理论基础：冻结 GNN 如何变换表示空间

### 2.1 棱镜空间

论文将输入建模为紧致光滑流形，将 GNN 建模为逐层映射的复合：

\[
\Phi=F^{(L)}\circ\cdots\circ F^{(1)}.
\]

在分段线性假设下，每个局部区域可以用 Jacobian 描述。其奇异值反映不同方向的变换：零奇异值对应局部方向消失，小于 1 对应收缩，大于 1 对应放大。ReLU 还可能改变激活区域，使整体映射具有折叠和分区结构。

因此，不能把所有冻结 GNN 都描述为严格收缩映射；实际行为取决于权重、激活状态、图结构以及考察的方向。

### 2.2 三类几何容量指标

| 指标 | 直观意义 | 解释边界 |
| --- | --- | --- |
| 内在维度 | 表示能够沿多少个独立方向变化 | 不等于类别信息量；上界不等于实际达到的维度 |
| Hausdorff 测度 | 在相应维度下的有效空间大小 | 会受尺度影响；更大不保证类别更可分 |
| 直径 | 表示之间的最大距离 | 可由简单放大增加，不能单独证明分类收益 |

论文 Theorem 3.12 用各分区路径上的层间最小 Jacobian rank 给出最终内在维度上界。Theorem 3.15 用逐层奇异值和算子范数约束 Prompt 后表示空间的测度与直径。

这些是带假设的几何约束，不能直接读成分类准确率上界。具体公式与假设见[论文第 3 节](https://arxiv.org/html/2606.03290v1#S3)。

## 3. 对 Prompt 设计的参考

### 3.1 比参数数量更先检查有效输出方向

**依据：** 输入扰动经过冻结网络后，可能被后续投影、聚合和激活削弱。

固定图结构，在局部可微点附近，记最终表示为 \(z=f(X)\)，有：

\[
\Delta z\approx J_X\Delta X.
\]

如果 Prompt 参数为 \(\theta\)，则：

\[
\frac{\partial z}{\partial\theta}
=J_X\frac{\partial X_\theta}{\partial\theta}.
\]

这说明 Prompt 的参数数目与它在输出端产生的独立变化数目不同。多个参数可能产生几乎相同的输出方向，也可能落入局部零空间。

**设计建议：** 增加 token、prototype 或维度前，检查输出对 Prompt 的响应是否多样、是否达到最终读出。可使用方向有限差分、JVP/VJP 等方式近似检查，无需显式构造完整 Jacobian。

### 3.2 将注入位置作为独立设计变量

**论文直接启发：** 第 4.1 节提出逐层注入，以提供输入层之外的适应自由度；MTG 在各层采用可学习消息融合。

在多个层输入处加入小扰动时，一阶近似可写为：

\[
\Delta z\approx\sum_\ell J_{\ell\rightarrow z}\Delta h_\ell,
\]

其中 \(J_{\ell\rightarrow z}\) 表示该注入位置到最终读出的导数。不同注入位置提供不同的输出响应方向。

**设计建议：** 对比输入层、单个中间层、末层和多层注入，并匹配参数预算。优先寻找能产生有用输出变化的位置。

**不能直接推出：** “最晚注入必然最好”“低秩层之后必然最好”或“每层都加必然最好”。晚层注入减少了传播路径，也可能失去利用早期结构信息的机会。

### 3.3 区分避免信息丢失与恢复已经丢失的信息

**局部数学推论：** 若两个样本在某层已经得到完全相同的表示，且后续模块只依赖该表示和相同的图条件，则确定性的后续 Prompt 无法区分它们。

因此，瓶颈后的 Prompt 可以改变剩余表示的几何形状，但不能凭空恢复被丢弃的样本特有信息。

**设计建议：** 若目标是保留早期判别信息，可以在瓶颈前改变信息路由，或从原始特征、早层表示引入旁路。后者引入了额外信息路径，需要单独验证其贡献。

### 3.4 同时考虑传播能力与任务相关性

**理论启发：** 不同扰动方向通过 backbone 的能力不同。

**进一步推论：** 大奇异值方向更容易影响输出，但可能对应任务无关变化；小奇异值方向也可能携带重要类别信息。因此，不能直接将“选择最大奇异值方向”当成最优 Prompt 原则。

可以把候选方向的价值理解为三个因素共同决定：

\[
\text{候选方向价值}
\leftarrow
\text{输出可达性、任务相关性、估计稳定性}.
\]

**设计建议：** 在相同预算下比较随机方向、传播强方向和任务引导方向；标签只能来自允许使用的训练/support 集。关注归一化表示下的分类间隔和独立样本表现，避免将单纯尺度放大误判为改进。

### 3.5 动态融合提供额外自由度，但优势需要对照

MTG 的每层融合形式为：

\[
\widetilde H=H+\operatorname{Softmax}(HW_p)M,
\]

其中 \(M\) 是消息原型，\(W_p\) 根据当前节点表示生成原型权重，原 backbone 权重保持冻结。

对于共享的固定加性偏移 \(H\mapsto H+P\)，融合本身对 \(H\) 的 Jacobian 是单位矩阵；输入条件化融合则增加一个随输入变化的导数项。但固定偏移仍可能改变后续 ReLU 激活区域，从而改变完整网络的局部响应。

**设计建议：** 对比共享偏移、节点条件化原型融合、固定路由和可学习路由，判断收益来自何处。

**边界：** 动态融合是 MTG 的具体方法选择，不能从 PS-Theory 单独推出它在所有任务上优于静态 Prompt。逐层原型融合已经属于 MTG 的核心机制，仅增加同类模块不能直接视为新机制。

参见[论文第 4 节](https://arxiv.org/html/2606.03290v1#S4)。

### 3.6 结构 Prompt 可以改变传播算子，但需要新的分析条件

**进一步推论：** 对图模型 \(f(A,X)\)，改变邻接关系 \(A\) 会影响聚合算子及后续 Jacobian，因而也可能改变信息传递方向。

**设计建议：** 对结构 Prompt 检查其是否保留或引入了任务相关的邻居信息，并设置同等边预算的随机结构对照。

**边界：** 离散增删边不宜直接套用固定图上的特征扰动微分公式。论文对部分输入 Prompt 的等价化建模，也不应自动外推为任意结构 Prompt 的统一严格上界。

### 3.7 保留可退回基线的参数配置

**工程建议，非 PS-Theory 定理：** 使用残差形式、受控幅度或层门控，可以让训练从接近冻结模型的状态出发，并限制少样本下的偏移。

例如：

\[
\widetilde H=H+\alpha\Delta H_\theta.
\]

实现时需要检查初始化梯度：若门控和内部输出同时置零，可能使分支无法启动。存在 identity 配置，也不意味着训练算法一定能找到或保持该配置。

## 4. 理论不能直接支持的说法

| 过强表述 | 更准确的结论 |
| --- | --- |
| 冻结 GNN 的每一层都压缩空间 | 某些方向可能收缩、消失，也可能放大 |
| 最低 rank 的层就是最优注入层 | rank 提供瓶颈线索，位置选择仍要考察任务信息和后续传播 |
| 瓶颈后的 Prompt 能恢复所有丢失信息 | 恢复样本特有信息需要仍可访问的信息来源 |
| 最大奇异值方向就是最佳 Prompt 方向 | 输出敏感性与任务相关性是不同条件 |
| 多层、动态 Prompt 必然优于输入、静态 Prompt | 多层动态干预提供候选自由度，实际收益需要匹配实验 |
| 表示空间越大，泛化越好 | 几何容量不包含准确率、优化成功或泛化保证 |
| MTG 已证明任意图 Prompt 都被严格支配 | 结论受论文模型、Prompt 家族及证明假设约束 |

论文明确承认：Softmax 融合及某些非线性需要近似处理，部分几何结果依赖单射等假设，而容量到泛化的理论联系仍未建立。参见[Limitations](https://arxiv.org/html/2606.03290v1)。

## 5. 将设计启发变成可证伪实验

以下是本文建议的验证顺序，不是论文已经完成的统一验证流程。

| 要回答的问题 | 最小对照 | 判断依据 |
| --- | --- | --- |
| Prompt 是否能影响最终输出？ | 零 Prompt 与非零干预 | 最终读出变化，而非仅中间激活或梯度非零 |
| 注入位置是否关键？ | 输入、单层、末层、多层；匹配预算 | 相同 checkpoint 和数据划分下的配对差值 |
| 所选方向是否有信息价值？ | 随机方向、传播强方向、任务引导方向 | 输出变化相近时，独立样本收益是否不同 |
| 动态路由是否必要？ | 固定路由、随机路由、可学习路由 | 排除原型数量和参数预算的影响 |
| 是否只是放大表示？ | 标量缩放及归一化读出对照 | 类别间隔和准确率的改善是否保留 |
| 是否过拟合 support？ | 冻结基线与 Prompt；重复划分 | support 改善能否转化为独立 query 收益 |

所有对比应保持 checkpoint、预处理、数据划分、读出头和调参预算可追溯。query/test 标签只用于最终评估，不用于 Prompt 训练或选择。若需要验证集选层或选参数，应事先规定验证协议。

建议停止条件：如果干预已经能显著改变表示、降低 support loss，却持续无法改善匹配的独立 query 结果，应停止将问题简单归因为“容量不够”，重新检查信息来源、任务相关性和估计稳定性。

## 6. 总结

PS-Theory 为图 Prompt 提供了一个有用的分析框架：**从干预位置与方向出发，追踪变化如何穿过冻结网络，并检查它是否保留到最终表示。**

对设计最直接的启发是探索逐层干预；对研究最重要的约束是，几何变化和泛化收益必须分别验证。一个有价值的新 Prompt，需要同时证明它提供了可用的输出变化、变化包含任务信息，并且这种信息可以由有限监督稳定利用。
