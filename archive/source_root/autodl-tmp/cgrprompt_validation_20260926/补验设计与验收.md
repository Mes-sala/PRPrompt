# CGRPrompt叙事补验：预先锁定的设计与验收

本轮目标：补齐主线叙事中尚未验证的科学问题，在用户指定51542服务器执行，回传原始结果、配对分析、源码与结论文档。结果不以成功为验收条件；覆盖完整、协议通过、结论忠于证据才是验收条件。旧实验只作为历史参照，不能替代新实验。

## 1. 问题与必要对照

1. 教师信息经Prompt是否增值：同轮rect_uncentered、A2_center、rawprop、冻结表示及完整方法；记录教师正确而Prompt错误、教师错误而Prompt正确的比例。教师无checkpoint，不重复解释成底座独立证据。
2. 固定类别分配的价值：在同一隐藏层注入、支持损失、读出下，比较固定类别系数、打乱节点系数、随机固定系数、属性驱动学习分配、类别教师初始化后学习分配。报告路由参数与残差参数，额外参数不能称为完全等容量。
3. 具体机制：原8格全因子；门控等范数/仅幅度；矩阵对角/无范数匹配；M3原图、冻结表示近邻、教师近邻、去支持钳制、去初始回注。完整因子只用于统计交互，不将功能相连表述为协同。
4. 收敛和调参：固定100/300/1000更新、学习率0.001/0.01/0.1；针对Adam、匹配矩阵、无匹配矩阵及最接近分配对照。调参仅用支持集内部每类留一验证，不用查询标签选择。固定预算结果与支持选择结果分开。
5. 独立范围：原Cora/CiteSeer六格仍为开发条件；增加Actor、Chameleon、PubMed各三底座，以及Cora/CiteSeer的GraphCL/GraphMAE底座，用新20seed。新seed不等于新图，且这些图有历史研究暴露，称锁配方扩展确认，不称从未使用的盲测。
6. 运行代价：同GPU、同步计时，报告构造门控、拟合、读出耗时、峰值GPU显存、可训练参数；额外成本与Accuracy分开报告。

## 2. 统一协议与不变量

原六格使用24092800至24092819，每类5-shot、官方训练池/测试查询集合；新条件使用26092600至26092619。数据变换沿用原grid.py，冻住同SHA的两层128维GCN并保持eval。预测和规范概率先封存再接触查询标签。Accuracy、Macro-F1、Micro-F1、宏OVR AUC、宏AP均报告。支持集、查询集合、图、checkpoint、源码、预测均记录SHA256。

机制与直接教师复验先运行；定制分配代码必须通过零提示、冻结断言、查询标签隔离与原算子等价检查后扩展。程序错误允许修复，但工程试跑结果独立于正式结果。

## 3. 判定规则

同设置按seed配对，bootstrap 10,000次，报告均值差、95%区间、正/平/负数。整体准确率之外保留排序指标退化。支持“稳定优于”须区间下界大于0；跨0记为未确认；上界小于0为反例。多重比较未校正的区间为描述性证据。不同图分别报告，不将重复支持采样伪装为独立图。

对未胜过强教师或学习分配的条件，给出明确不支持结论，不添加新模块寻求事后成功。已完成固定确认范围不因初步负结果而删减。

## 4. 完成验收

- 逐项覆盖表列出预定/完成/失败及原因；不能用文档存在替代运行完成。
- 所有正式结果通过源码、split、冻结、有限数与封存哈希审计。
- 原始预测、指标、配对差、负结果与成本均回传本地，核查文件清单SHA256。
- 中文结论逐项对应PPT的主张，明确哪些可写、哪些应收紧、哪些被否证。

## 5. 算子来源与原创性边界

类别残差为固定条件矩阵乘可学习token的受限组合；学习分配对照来自GPF+的basis/attention思想；Shampoo和grafting为已有优化技术；支持钳制传播为已有半监督读出思想。本轮是验证既有结构选择，不声称新原语。来源：本项目CGRPrompt设计稿、gate79.py、optimizer83.py、run_round83_graft.py、GPF论文及已有确认轮。

## 6. 运行清单补充（正式扩展前固定）

发现CiteSeer的GraphCL和GraphMAE各有两份SHA不同权重，全部纳入，不依据性能挑选。共原6格与扩展15格。

- 基础/机制：原6格×22方法×20seed + 扩展15格×7方法×20seed = 4,740条。
- 分配结构：原6格×8配置×20seed + 扩展15格×4配置×20seed = 2,160次拟合；每次同时封存原型和传播读出。
- 支持内调参：原6格×7配置×20seed = 840个最终重训结果。每组3学习率×3预算，以4-shot训练、每类留出的1个支持节点验证选择；最终5-shot重训。仅原始六格做此预算复核，扩展格保持锁定配方。
- 分配配置含固定Adam、固定矩阵、属性学习路由、教师初始化学习路由；原六格另含打乱、随机、等总参数预算学习路由及固定低秩残差。等预算版本同时改变隐维表达能力，应结合固定低秩对照解释，不声称仅改变一个因素。
- 外部充分预算验证选择GPF+与GPrompt两项最接近且与已有争议直接相关的方法，沿用其原生读出与已归档移植实现，仅显式开放学习率；不宣称覆盖全部外部方法的最优结果。
- 专项成本：原6格与PubMed3格，5次重复，完整Prompt、Adam版本、学习路由、直接教师、冻结传播共225条。所有其他实验结束后串行运行，数据和主干已预加载。正式运行中穿插的工程试跑时段不作为最终成本证据。
- 新增固定/学习分配算子已在工程试跑中与历史Adam、匹配矩阵实现做数值等价检查；M3新读出与原qeps-50概率对齐检查通过。工程试跑不计入正式结果。
