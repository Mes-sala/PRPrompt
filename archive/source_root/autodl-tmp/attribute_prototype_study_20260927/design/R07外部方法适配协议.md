# R07：外部推断方法的公平适配

比较目的：在相同属性表示、支持标签和可见无标签节点上，检验本项目原型精炼相对标准推断算子的价值，不与三模块主线比较。

- SimpleShot-style：行归一化属性、支持类别均值、平方欧氏原型距离。中心化采用当前图可见属性均值；不同于原图像论文的训练特征均值，故明确标为style适配，不能冒称完整复现。
- Soft-kmeans-adapted：支持sum与无标签soft-assignment sum合并，按支持计数+软计数更新；三轮，距离温度.05，最终温度.2。体现经典半监督soft-kmeans，不声称复现原论文端到端训练。
- LaplacianShot-adapted：保留作者bound update、lambda=1、20步及能量停止阈值1e-6。作者默认knn=3包含自身，实际两个非自身邻居；有向二值邻接。推断集合为所有非支持节点，支持标签仅经类别原型进入；与原图像任务相比，此处使用图属性和完整可见无标签集合。
