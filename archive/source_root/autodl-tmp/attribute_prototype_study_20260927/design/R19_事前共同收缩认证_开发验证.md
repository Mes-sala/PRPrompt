# R19：在运行完整软校正前认证共同收缩

本轮是开发验证，不能称留出确认。规则来自非渐近推导，运行前冻结；原14数据集、原预处理两跳、旧种子271700–271704，共70组。beta=0.5、tau=0.05、T=3、分类影响容差1 pp均不变。

先从固定表示和支持原型计算共同轴、可行域最小投影、节点直径、完整协方差的上界；运行三步标量直径递推，得到最终原型相对共同收缩的事前球半径。不得先计算q或u，再把得到的残差当事前上界。

两项预先指定的协方差上界均报告：trace；120次幂迭代后PSD块上界与Frobenius/trace取最小。Rayleigh值仅是下界，不用旧切向协方差谱替代完整协方差上界。所有浮点上下界保留安全裕量，本轮不宣称严格区间算术。

利用共同收缩的节点分数和球的方向锥计算每类分数区间，认证winner下界严格超过所有competitor上界的节点。固定裕量1e-12；零行、零原型、无正共同轴、半径覆盖原点的情况拒绝认证。

先落盘事前半径、类别分数区间及认证掩码，再运行完整三轮方法；核验实际每步方向直径、软原型与均值距离、最终余弦分数都在界内，认证节点不得异判。查询标签不进入本轮，主指标是认证比例、实际异判率与界的有效性。

判读：若事前未认证比例≤1%，则该指定输出的Accuracy贡献绝对值至多1 pp。未通过即保留失败，不修改阈值。若至少有非平凡覆盖，后续另冻结新支持抽样和未用于本轮的传播几何作确认。若无覆盖，则根据界的过松项决定下一原语，不把正确但无用的界当作可用算法。

必须分列固定表示的统计预计算成本与每次支持抽样成本；本轮先验证非空与正确性，不仅凭少算softmax即声称wall-clock加速。协方差预计算可能昂贵。
