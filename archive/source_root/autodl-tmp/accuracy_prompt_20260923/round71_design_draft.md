# 第71轮草案：PubMed固定强提示的只读中心化

依据第68轮CiteSeer成功与第70轮Cora确认失败，中心化不能作为通用默认值。继续在PubMed做独立、固定迁移检验，不扩大Cora，不调中心化强度。

固定GraphMAE2原修正教师提示根、GraphMAE原提示+VAT0.3强根，二者保持各自100步训练/教师/早层位置不变；中心化仅在最终读出减去全图无标签表示均值。PubMed第48/55轮已否定k50与scale2迁移，本轮不叠加它们，仅余弦原型读出。

拟两权重，各Frozen、GraphPrompt、原提示、原提示只读中心化；GraphMAE额外保留无VAT原提示及其中心化，便于区分VAT影响。独立修正教师保持为参考，标记为Direct且只计算一次，不能伪装成使用checkpoint的方法。

每支持训练根只算一次，各读出严格复用参数。需独立重构修正教师门控、早层提示、中心与原型分数，核对checkpoint CPU映射、输入契约、VAT种子/轨迹及主干冻结。规模较大，先3步预检，顺序运行两权重；只保存提示、预测、均值和哈希，不保存完整全图表示或新邻接。

初始五组新支持及强对照，只有候选超过同批两权重现有最好提示和直接教师才固定新20支持确认；否则明确失败。SimpleShot操作来源与原文基础类均值/此处传导全图均值差异沿用第68轮记录。尚未实现、seed及正式矩阵未封存。
