# 第62轮固定设计：局部尺度核

来源及边界见round62_design_draft.md，固定配置round62_config.json。CiteSeer修正教师，五个新支持93100–93104，原教师/修正教师/三种核各alpha0.5与0.9，共40条。三种核：原余弦top50+softmax/.2、相同top50+局部尺度权重、按局部尺度距离全量重排top50+局部尺度权重。局部尺度为第7欧氏近邻距离，下限1e-6；真实平方范数计算距离，处理零向量。保存三份共享稀疏邻接，不保存稠密NxN矩阵。

先8条预检及零向量/重复向量合成测试，独立CPU重算核权重、尺度、top50门限、传播和alpha0恒等；然后正式40条。比较所有候选与未传播修正教师及同alpha全局核；超过最强参照才扩大20新支持确认。直接特征方法没有checkpoint，单独记录null和依赖源码SHA。无新增提示训练；有效后再检验提示作用。封存后才读取查询标签，同图重复开发边界不变。
