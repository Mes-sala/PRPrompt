# 第36轮：低秩通道残差适配

借鉴[LoRA原文第4.1节](https://arxiv.org/pdf/2106.09685)冻结主干、低秩残差与一因子零初始化。这里实现隐藏特征的残差适配器，非Transformer LoRA复现，准确率有效即可保留，不把权重适配自动称为新Prompt。

同一个仅自环GCN，第一层激活前或后插入 $ V'=V+(V D^{-1}AB)D/r $，D为全图无标签基础表示逐维标准差。A为128×r高斯初始化标准差1/sqrt(128)，B为r×128全零，r固定1/4，缩放1/r。跨通道映射不同于第35轮对角缩放；激活后分支可折叠为第二层权重低秩更新，不主张复杂消息机制。原始checkpoint不更新。最终使用同一固定diag10均值/矩阵，不随提示重算，无末端分数融合。

每位置/rank比较训练A+B、固定随机A只训练B、两者固定随机（B标准差.3）；后者不看标签。另带Frozen/rawridge/diag10 base/GP/条件token/SSF前层仿射，共18方法×2权重×5支持=180。Actor官方fold0 dev，seed54100..54104；查询已使用。Adam .01，100步，支持LOO CE+.001[B均方+(A-A0)均方]，固定A不加A正则。参数数目256r或128r，非严格等参数比较，rank1双因子与SSF256参数相同。

36条3步预检验证零残差恢复、梯度有限、冻结及固定A不变；有强对照外新增收益才锁定新支持确认。无改进则停止该配置扩大。全部封存预测后评分、保留哈希。
