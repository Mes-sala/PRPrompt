# 第二十一轮：无标签软分配修正教师原型

来源：[Prototype Rectification，ECCV2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123460715.pdf)。借鉴利用无标签样本与加权原型减少少样本估计误差的思想。本轮实现支持锚定软聚类，不是原文BD-CSPN复现；不引入其跨类特征平移或视觉训练过程。

令 $ R=\hat A^2X $，逐节点L2归一化后，支持原型均值 $ M_0 $ 固定。排除支持节点形成U。重复3次：按当前原型余弦相似度/0.05 softmax获得软类别分配，计算每类无标签加权均值 $ M_U $，更新 $ M=(1-\beta)M_0+\beta M_U $。固定beta0.25/0.5，最终教师概率采用原0.2温度。不会让无标签数量直接淹没每类5个支持的权重。

同一教师有两种用途：直接分类（纯教师改进，单列）；给原型教师gamma3内部token提供门控和KD，最终仍用提示表示的支持原型分类。主干冻结，提示位置、参数量、100步Adam保持原设置。另保留Cora较强的平滑岭教师后层gamma10与普通GraphPrompt，不因只超过原型提示而声称当前最佳。

打乱控制：每次软分配行随机打乱后求加权均值，保持类别总软质量，破坏节点-类别对应；直接教师和提示都各有此对照。3图×2权重×5seed30100..30104×11方法=330正式指标。

预检：beta0必须精确退化为rawprop2原型分数；支持节点不参与无标签加权均值，参数冻结与零提示恒等；预测sealed后才评分。所有教师只使用支持标签和全图无标签特征/边。候选确认需超过相应原方案且优于匹配打乱控制，收益若仅来自直接教师，明确归类。
