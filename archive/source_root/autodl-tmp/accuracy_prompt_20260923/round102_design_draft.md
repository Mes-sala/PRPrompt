# 第102轮草案：多原型固定教师

已读[Infinite Mixture Prototypes，ICML2019，第3节/算法1](https://proceedings.mlr.press/v97/allen19b/allen19b.pdf)。原文按DP-means自适应簇数、学习方差/嵌入，并采用每类最近簇分类。本草案只借鉴每类多中心，以固定2簇和冻结特征替代；不是IMP复现，也不是贝叶斯推断。

保持原中心化平滑特征及行归一化。每类5支持按节点ID排序，用CPU double余弦最远对选两个锚，按更近锚分组；锚自身强制属于各自组以处理退化并保证非空。每组均值为原始子中心，3步对所有非支持节点的12分量softmax/.05更新，.5原子中心+.5软聚类中心。排除全部原支持，未用query标签。均匀分量先验，不按初始组大小加权。主教师分数每类两分量cos/.2取最大，另考虑logmeanexp聚合对照。

随机支持2/3拆分控制（CPU seed+1020000，保留正类身份）；单中心及重复两个相同中心必须恢复原3步教师。重复中心的全12分量概率各减半，但条件均值不变；max/logmeanexp均恢复旧分数。原语包含支持顺序不变、非空簇、极端相同特征和原根恢复。

下一步将6类教师概率转换为原6列门控，提示仍单6×128 token，冻结同共享GCN第一层预激活；不增加多分支网络。门控的.1温度作用在聚合后的6类score上，与先锐化12分量再聚合并不相同。比较raw/等范数/幅度、随机簇及相同新教师Direct；因此固定教师提升和Prompt提升可区分。旧教师Direct必须同批保留。
