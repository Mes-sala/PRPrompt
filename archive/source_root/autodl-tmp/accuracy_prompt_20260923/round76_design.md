# 第76轮：随机提示初始化在GraphMAE上的固定确认

延续第73轮从[Lester等的提示初始化研究](https://aclanthology.org/2021.emnlp-main.243.pdf)得到的实验，而非新模块。第73轮两组20支持确认仅GraphMAE2，增益第二组不明确；不能把该结论外推GraphMAE。GraphMAE在第73轮开发随机69.76%对零67.92%、第74轮68.68%对68.44%、第75轮71.28%对70.36%。这些开发记录促成本次确认选择，不计为独立确认。

固定GraphMAE、CiteSeer、随机有效token幅度0.1、教师门控后的实际RMS匹配规则、100步Adam0.01、768参数、只读中心化及k50。完全复用run_round73_initial.py与init73.py训练源码，不增加参数、不选强度、不融合预测。新支持115100–115119，confirm后500节点。随机+k50为唯一主终点，零初始化、新KD、语义/置换0.1、原型以及独立Direct均保留，共340条。

检查summary、audit73、audit73_geometry；两权重在第73轮已有预检与100步验证，因此本次不重复烟测。同图及确认query多次使用，不能称新图独立泛化。若对强根没有明确增益则不继续本权重初始化搜索；若只胜提示不胜Direct，保留对应边界。
