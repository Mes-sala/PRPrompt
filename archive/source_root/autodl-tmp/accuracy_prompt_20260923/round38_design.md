# 第38轮固定设计：类协方差读出与现有Prompt

借鉴[Simple CNAPS，CVPR2020，第4.2节](https://arxiv.org/pdf/1912.03432)：支持集类均值、类内协方差与支持全集协方差形成收缩Mahalanobis距离。只借鉴距离，不复现视觉元训练或其特征适配器。官方CVF PDF403后已读取arXiv正文。Mixup在本任务首轮已测，暂不重复。

下一步先做最终分类读出替换，判断读出瓶颈，不先混入新训练。使用Cora/PubMed的原Frozen及当前强条件提示输出；强提示训练不变。比较现有cosine原型、单位化表示上均值欧氏距离、共享协方差距离、类协方差收缩距离。统一节点表示L2归一化，但欧氏/协方差类均值不再次单位化；因此必须带欧氏对照，不能将均值归一化变化归于协方差。

支持全集协方差C与每类协方差Ck只用支持节点。拟定 $ Q_k=\lambda C_k+(1-\lambda)C+\beta\tau I $，tau=tr(C)/128，相对floor处理；共享lambda0，类收缩lambda5/6，beta先固定.1与1，不按query选择。分数为负二分之一马氏平方距离，不加logdet，明确这不是完整高斯QDA似然。无query标签进入均值/协方差。主干及提示不因新读出更新；任何收益先归为读出改善。只有读出正向，再设计与同分类头匹配的提示训练，而不能称本轮产生新Prompt。

需要数值审计：单位矩阵恢复欧氏距离；类协方差相同时类/共享头一致；相对正则在共同缩放下预测不变；协方差正定、有限；原cosine恢复旧脚本。固定Cora/PubMed×GraphMAE/GraphMAE2×5支持seed57100..57104，旧dev500查询。两表示各6读出，加Frozen/GraphPrompt/两直接教师，共320条。72条3步预检包含两个旧root用于原cosine对照。每个支持/权重只训练一次强提示，六读出共享同一表示并记录表示SHA256。数值使用double Cholesky求逆，tau下限1e-30，beta固定.1/1；先预检再正式。
