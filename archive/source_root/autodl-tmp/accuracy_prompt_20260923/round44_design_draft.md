# 第44轮草案：借鉴行人重识别的互近邻过滤

检索并阅读[CVPR2017 Re-ranking Person Re-identification with k-reciprocal Encoding](https://arxiv.org/pdf/1701.08398)。原论文还包含互近邻向量、Jaccard距离与查询扩展；本草案仅借用互近邻判断，不宣称完整算法复现。

已有Cora强提示后的10NN传播有复核增益。下一步在相同表示和同一10NN列表上，只保留互相位于对方10NN中的边，再按原余弦权重重归一化。空行回退原10NN，明确记录回退比例；不删除节点、不查标签。传播alpha.9、20步固定，带原有有向10NN作为强对照。必须带按每行实际保留数量随机删边再归一化的对照，以区分互近邻判断与稀疏化；可以再带互近邻图与原图50/50混合，但需运行前定矩阵。

输入均为旧强提示训练后表示，冻结主干，训练不变，改进首先属于传导读出。Cora两权重起步，原教师/普通GP/原提示/原10NN同时报告，若有效再扩数据。存稀疏图、原始邻居及保留mask与表示哈希，不存N平方矩阵。需核验真实保留边互惠、随机与真实每行边数相等、无自边、行和为1、空行策略及图不变。
