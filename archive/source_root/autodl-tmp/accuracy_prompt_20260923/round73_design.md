# 第73轮固定设计：支持类别初始化

继承[来源及草案](round73_design_draft.md)。固定CiteSeer两GCN、支持110100–110104、dev500、100步Adam0.01、768参数、中心化教师门控无KD；最终只读中心化并比较原型/k50。原/中心零初始化与新KD为强参照，Direct教师每支持计算一次。6初始化×2读出+4旧配置×2读出+Frozen/GraphPrompt，每权重22项，总225条；49条3步预检带强度0恢复。

按支持隐藏类别均值减全图隐藏均值、除通道标准差，逐类RMS归一化得到方向D；语义有效token取0.01D/0.1D。有效token指tanh(tokens)，本地用atanh逆变换初始化，区别于草案直接设置原始token。

置换采用固定种子730000偏移生成的非零循环移位，无固定类别；随机方向用seed+730001生成且逐类RMS归一化。两者再乘标量，使10×gate×有效token×std的全图实际RMS与同强度语义初始化完全匹配。只匹配总实际扰动，不宣称逐类token范数也一致。有效token绝对值必须小于0.95，类方向RMS必须大于1e-8；失败则停审，不截断掩盖差异。比例、初值、类均值、方向和置换均保存。

同一初始化的原型/传播共用训练。支撑初始化的标签只来自支持集，查询标签封存后评估。初始零提示恢复检查在写入初值前，字段prompt_noop_norm_error指零算子；非零初值不是无扰动，实际幅度由initial_rms记录。保存驱动与init73.py联合源码SHA。

独立CPU审计从主干重建支持均值/方向、随机对照和幅度匹配，核对初值、最终中心/原型以及邻接绑定；强度0恢复原训练和两读出。初始误差/训练CE改善不能替代最终准确率，只有超过本批最强Prompt及直接教师才固定20支持确认。同图多轮查询限制不变。

零恢复审计修订：初值严格为零，两次GPU训练token最大差8.08e-7、原型分数最大1.19e-6，预测相同。近邻并列导致GraphMAE传播分数差0.00874；不声称两次重训近邻图/分数严格恢复。保留原型与参数恢复，增加逐项独立CPU近邻门限/权重和传播重算，明确容许近并列邻居，算法及正式配置未改。诊断round73_recovery_diagnostic.json保留。
