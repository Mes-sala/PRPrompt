# 第64轮草案：中心化强教师接入冻结GCN提示

第63轮中心化直接教师在两批20支持确认超过原修正教师：+1.36pp、+1.77pp；去PC在两批略高，但第二批对中心化差异区间跨零。先以简单中心化作为固定新教师，不继续按查询选择PC数量或传播参数。

拟沿用CiteSeer相对更强的原位置平滑岭条件token：冻结GraphMAE/GraphMAE2两层GCN，输入X不变，100步Adam0.01，gamma10，原CE不变。旧教师是既有平滑岭概率，新教师是中心化r=Ahat²X后做beta0.5三次原型修正所得概率（不额外再平滑）。Prompt条件门控与KD分开替换：仅门控、仅KD、两者；带旧教师原方案及未中心化修正教师两者替换对照，区分教师种类变化和中心化增量。必要时去KD对照检验提示是否只拟合支持。

共享主干参数冻结；门控由教师概率减列均值再经Ahat传播，作用于原token注入位置，KD作用于训练损失。融合不是最终预测平均，而是训练时门控/监督替换，仍须以查询准确率检验。直接中心化教师及原修正教师都保留为跨方法强参照；即使Prompt胜旧Prompt，也必须注明是否仍低于强直接教师。若提示无额外收益，直接教师结果独立保留。
