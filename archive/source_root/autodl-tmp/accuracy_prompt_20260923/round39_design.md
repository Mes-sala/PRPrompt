# 第39轮：隐藏表示虚拟对抗一致性

借鉴[VAT原文算法1及3.4节](https://arxiv.org/pdf/1704.03976)：由当前预测KL而非未标注真标签寻找敏感扰动，并停止对扰动方向反传。本轮迁移到图提示后的隐藏表示，不复现原图像/文本输入VAT；不同于第16轮提示参数SAM，也不同于第12轮dropout/硬伪标签。

Cora后层平滑岭gamma10、PubMed早层修正gamma3提示不变。每步当前未扰动输出形成固定原型及stop-gradient概率；在对应隐藏位置增加按基础逐通道std缩放的扰动。每节点标准化扰动RMS固定epsilon .1/.3；随机RPT与VAT同幅度。VAT先以xi=.01随机方向求KL对扰动的梯度，按节点归一化一次，再detach方向。图消息使不同节点相互影响，所以这是整图隐藏扰动版本，不是假设节点独立的原算法严格复现。

原型在一致性项内stop-gradient，来自未扰动当前表示和支持标签；所有节点预测可参与KL，不使用query真标签。原CE+教师KD+.001参数均方保持，再加权重1一致性；训练100步Adam.01，最终关闭噪声。每个VAT步额外两次扰动forward（含一次扰动梯度），RPT额外一次；不声称等计算预算。

无一致性/两VAT/两RPT共5提示配置，加Frozen/GP/两个直接教师，2图2权重5支持seed59100..59104，共180开发，旧dev500查询。44条3步预检带两旧root；核对无一致性与旧脚本、扰动RMS、有限梯度及冻结。只对超过原提示和同幅度RPT的配置做新支持确认。
