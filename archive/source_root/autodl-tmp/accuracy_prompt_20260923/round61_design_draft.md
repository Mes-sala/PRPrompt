# 第61轮草案：把有效的概率传播迁移到CiteSeer强教师

第41/47轮近邻概率传播只系统验证Cora/PubMed；第21轮CiteSeer最强为原始特征两次图平滑后的修正原型教师，GCN提示低于它。下一轮在CiteSeer同时保留强直接教师与冻结预训练提示，避免长时间只在Cora优化微小增量。来源沿用第41轮已读视觉少样本LaplacianShot与第46/47轮图像检索聚合经验，不声称是新机制。

拟固定CiteSeer GraphMAE/GraphMAE2、每类5支持，比较：原直接修正教师(beta0.5、3次修正)、直接教师同空间k50传播、冻结GCN原型/传播、平滑岭教师后层token+KD的旧CE/scale2强方案及各自k50传播。提示学习率以第60轮确认结果为依据封存，不能先看CiteSeer查询再选学习率。直接教师的传播锚必须保留修正原型分数，不能误用未修正原型替换；两种教师分数另作独立控制以检查实现。直接教师没有checkpoint，应单独记录特征/图哈希，不伪造GCN checkpoint来源。

Cora固定k50、alpha0.9、20步、softmax余弦/.2、支持钳制，先不在CiteSeer调这些超参。近邻分块计算，禁止保存全量NxN缓存，复用成员表示；传播属于传导读出，强教师没有Prompt，不将其增益归于提示。先新5支持开发，超过同批直接教师与最好提示才固定组合20支持确认。预检alpha0恢复修正教师、概率守恒、标签隔离、共享邻接与封存SHA；已有confirm查询重复使用必须披露。目前尚未固定正式矩阵/seed、未实现或运行。
