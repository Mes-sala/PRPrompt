# 第64轮固定设计：中心化教师门控/KD替换

配置round64_config.json：CiteSeer GraphMAE/GraphMAE2，新5支持98100–98104。原位置平滑岭提示为旧根，固定100步Adam0.01、gamma10、768参数；主干冻结且输入不变。中心化修正教师不再额外平滑，分别替换门控、KD、两者；另保留未中心化修正教师两者替换和新门控无KD对照，各原型/k50两读出，Frozen/GraphPrompt及两个直接教师，总150条（直接教师不按checkpoint重复计数）。

旧教师为平滑岭概率，新教师为中心化r后beta0.5三轮修正概率，门控均减列均值再Ahat传播。条件token在第一层卷积后、激活前；没有终端多模型混合。Prompt局部进步须与同批中心化直接教师比较；超过旧Prompt但低于强教师不称整体最佳。

预检旧教师恢复、各分支使用Q的哈希绑定、无KD仍有支持CE梯度、主干冻结、两读出共享表示。16条5步预检（两个直接+每权重7个原型），不按预检准确率选择。正式源冻结，150条开发后只有超过强直接教师的候选才扩大。直接教师center须恢复第63轮同公式；保存参数/预测SHA，同图重复查询边界保持。

元数据说明：继承的teacher_filter/ridge参数描述计算出的旧平滑岭教师；实际门控/KD使用哪份概率，以teacher_switch及gate_teacher_sha256/kd_teacher_sha256为准。新中心化修正教师没有额外平滑。
