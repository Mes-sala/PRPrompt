# 第58轮固定设计：跨权重概率平均

配置见round58_config.json。复用第57轮Cora开发集的五支持种子，两个冻结预训练成员各为scale2+k50；第二成员权重0.25、0.5、0.75，另设0.5权重固定类别循环置换。共20条新增预测，四个既有单模型强参照不重复计数。先验证重复成员混合恒等；逐个核对支持、查询顺序、图、split SHA、两个真实checkpoint SHA、预测SHA与类别数7。成员分数是传播概率的log，先softmax恢复概率，不直接平均log。

来源Deep Ensembles（https://arxiv.org/pdf/1612.01474）分类概率平均。本轮是终端预测组合，不共享主干，不声称内部Prompt交互或原创性；实际使用两次提示训练和两套主干推断。复用既有开发输出不追加训练，禁止查询标签拟合权重。先封存混合分数再加载标签评分。以三个合法组合中开发均值最高者为候选（同分优先0.5），必须超过四个单模型中最强者才进入新20支持固定比例确认；置换仅作对照不参与选择。开发和确认均为同图重复查询，非独立泛化证据。集合没有单一checkpoint SHA，保留成员列表并独立审计。
