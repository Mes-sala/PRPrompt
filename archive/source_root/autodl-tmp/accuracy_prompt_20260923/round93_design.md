# 第93轮：DEC逆频率门控

来源：[Xie等，ICML2016 DEC原文第3.1.2节公式3](https://proceedings.mlr.press/v48/xieb16.pdf)，已读取原文。仅借用目标分布的平方及逆软类别频率，不复现Student-t分配、聚类中心学习或迭代KL训练。本轮仍是固定教师和单token提示训练。

设当前温度.1教师概率为 $ q_{ic} $，仅在排除全部原始支持节点的未标注池 $ U $ 计算 $ f_c=|U|^{-1}\sum_{i\in U}q_{ic} $。以均值替代论文的求和，行归一化后常数消去。DEC目标 $ p_{ic}=(q_{ic}^2/f_c)/\sum_d(q_{id}^2/f_d) $，代码在log域计算。门控为 $ B_p=\hat A(p-\operatorname{mean}_{nodes}p) $；主候选将其范数匹配当前 $ B_q $。这是无标签软频率，不声称真实类别先验或强制均衡。

共享参数为同一个冻结两层GCN及一个6×128零初始化token；第一层激活前注入 $ 10(B\tanh T)\odot\sigma_u $。原CE+.001提示L2、100步、支持原型和最终中心化+k50读出保留。GraphMAE当前Adam、GraphMAE2当前graftedShampoo均.01；不融合预测。教师三次原型修正完全不变，不同于第27轮在原型迭代内部使用Sinkhorn约束类别质量。

固定五个变体：der原DEC；dem等范数DEC主候选；dea原概率门控纯幅度控制；def仅逆频率且等范数；des仅平方且等范数。平方单独严格等于将温度.1降为.05，因此收益需与des比较后才归因于频率；dei恢复仅预检。保留tr1、gsh、Direct、Frozen、GraphPrompt。未标注池包含查询特征但不读取查询标签，沿用转导边界。

143100..104开发、143199预检，CiteSeer两个权重，165正式/37预检。CPU几何审计直接计算概率平方除频率，独立于log域helper；保存频率、目标分布及SHA；NumPy逐步重放原优化器。原语检查支持节点排除、行平移不变、零门控、恢复、平方温度等价及范数。先预检全审计，再运行正式。只对超过对应当前强根的固定候选追加20支持确认；同图查询反复使用，区间只反映支持抽样变化。未经实验不声称准确率收益。
