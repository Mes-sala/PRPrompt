# 第72轮实现与预检记录

已读[官方interventions.py](https://raw.githubusercontent.com/stanfordnlp/pyreft/main/pyreft/interventions.py)：LoReFT用torch正交参数化约束矩形旋转矩阵，学习另一线性映射和偏置。官方默认映射不是本实验的恒等初始化；本地特意令映射等于投影、偏置为零，使四个对照都从原模型开始。当前官方DireftIntervention类也调用正交参数化，不能把该类名直接当论文中的无约束控制；本地明确实现无约束残差。

`reft72.py`四种模式：orth可训练正交投影并减原投影；fixed固定同一初始正交子空间；plain取消正交但保留差分；residual普通双因子仿射残差，输入映射零初始化。rank4，前三种映射初始化等于投影。四者输出均可写为同阶低秩仿射残差，区别是参数化/约束与优化轨迹，不声称表达能力突破。

算子预检验证：初始恒等、5步更新有限梯度、显式仿射等价、输入梯度等价、orth/fixed正交补不变、fixed矩阵不变。CPU双精度及实际128×4 GPU检查通过。实际新增训练参数orth/plain/residual均1028、fixed516；加入6×128提示后分别1796/1284。正交模式另有16896个缓冲元素（含参数化基矩阵和初始投影），不是同数量可训练参数。

`prompt72.py`把干预施于早层教师门控提示之后、激活之前；不融合预测。教师沿用CiteSeer中心化修正原型，无KD，CE使用原未中心化输出训练；最终读出才中心化。对所有适配器使用相同的标准差归一化实际扰动平方惩罚0.001，并保留token L2，不能把它误写成原LoReFT训练目标。冻结主干与相同100步Adam0.01预算用于下一步正式矩阵。

`smoke72_primitive.py`在真实CiteSeer/GraphMAE2做四模式×token有无的3步原语检查，不读取查询标签、不计正式准确率。它尚不代替完整封存预测、独立前向重构、k50邻接绑定等正式预检。

后续仍需：将新函数接入封存流水线，记录reft72.py/prompt72.py及驱动的联合源码哈希；保留无提示中心化、强中心化Prompt、新KD中心化和Direct教师；按2×2及无约束/固定子空间控制比较；正式seed和矩阵在启动前固定。
