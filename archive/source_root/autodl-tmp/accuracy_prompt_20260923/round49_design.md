# 第49轮固定设计：Poly-1支持损失

检索并阅读[PolyLoss原文](https://arxiv.org/pdf/2204.12511)的Poly-1定义及复现代码。将支持留一原型CE替换为 $ -\log p_y+\epsilon(1-p_y) $，只固定两档 $ \epsilon=-1,1 $，KD/VAT/参数正则、100步、同一强提示位置保持不变，不新增头。不是完整视觉检测系统复现。

梯度等于逐样本CE梯度乘 $ 1+\epsilon p_y $，因此它可能只是改变样本权重及CE/KD平衡；不以形式区别宣称新机制。带常数CE缩放对照：从初始支持留一概率算平均 $ 1+\epsilon p_y $ 并固定整个训练，不使用查询；区分动态样本加权与总体监督强度。所有候选使用相同原型温度，查询封存后评分。

先Cora两权重、5支持开发，保留原强提示与原强提示+k50概率读出；候选亦可提供相同k50读出配对以免读出掩盖训练收益。PubMed若扩则保留GraphMAE VAT根。矩阵/seed在实现前冻结。验证epsilon0恢复、解析梯度乘数、epsilon−1非负及高置信有限梯度、同支持/教师/冻结主干、常数缩放来源纯支持。以匹配强对照准确率为准，不以训练loss好看筛选。

固定Cora两权重×seed75100..75104×12方法=120条开发dev500。Frozen/GP加原提示、Poly正负、常数缩放正负共5种训练各原读出与qeps50读出，共12。100步，同训练结果两个读出共用embedding缓存；各训练方法从同零token起点，常数系数由初始支持计算，不是调参选择。第48轮PubMed失败不作为此损失有效性依据。
