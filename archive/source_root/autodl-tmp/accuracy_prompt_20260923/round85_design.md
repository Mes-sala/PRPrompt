# 第85轮草案：支持集自助采样教师

来源：[Breiman，Bagging predictors，Machine Learning 1996](https://doi.org/10.1007/BF00058655)，以及[Berkeley作者技术报告](https://statistics.berkeley.edu/tech-reports/421)。借鉴对训练集进行bootstrap扰动并聚合预测的思想；原文收益依赖预测器对数据扰动的敏感性，不假设必然提升。本轮采用概率平均而非原分类多数投票，明确属于适配。

第84轮IDF降低Direct和提示性能，停止。改回原中心化属性教师，固定每类原5个支持中有放回抽5个，8组独立固定随机流。每组计算同一修正原型教师、最终softmax温度0.1，再平均概率形成单一门控。支持标签仍只有原30个；不会额外访问训练池其他标签，不重划query。训练的仍是一个共享冻结GCN、一个768token矩阵，最终不集成8个提示模型。

候选8教师平均，参照第1个bootstrap教师、原完整支持教师；范数匹配与仅幅度控制区分平均导致的变软和变化幅度。保留原Direct、bootstrap平均Direct，避免只看提示绝对分数。GraphMAE用Adam，GraphMAE2用已保留grafted Shampoo；原loss/100步/中心化+k50不变。固定候选数8，不按query挑B。

预检需保存8×30支持索引与SHA，确认每类5且均属于原支持、允许重复但不丢类；全部重复原索引的恢复分支应还原原教师，独立重建8个概率和均值。记录教师之间概率方差/argmax分歧为描述，不能当作真实错误或统计独立样本。正式预期131100–131104，矩阵未封存，代码未实现。第20轮已做教师熵权重，本次不原样重复该旧方案。


## 固定实现

150正式/34三步预检；131100–131104与131199。每个bootstrap教师的无标签修正池固定排除原全部30支持，不能仅排除抽到的索引。每次类别样本可重复，原型按重复次数计权；8概率在温度.1下平均，源概率方差仅作描述。随机流seed+850000+b，不扰动原训练生成器。

两权重各保留Adam与graft根，加bag raw/matched/amplitude/first四候选两读出，Frozen/GP和原/Bag Direct各一份。GraphMAE用Adam、GraphMAE2用graft。全原支持重复8次的bgo恢复分支仅预检。reconstruct85.py独立按类别均值和逐类加权重建8教师，并验证抽样索引、类别数、方差、门控和最终几何；更新沿用NumPy重放。正式开始后不得改训练源。
