# R172 TIES物理权重合并

来源：[NeurIPS2023 TIES-Merging](https://arxiv.org/abs/2306.01708)，全文ties172_paper.md；作者代码44e7891fc84f3de7e4caa52664cd864ca3715e91，merge_utils快照ties172_official.py。借鉴trim/elect/disjoint-mean，当前是同任务两学习率成员，不冒称原论文多任务迁移复现。

继续同checkpoint同支持的l1/l4两成员，冻结原W但合并实际deltaW，Prompt固定l4以隔离权重合并。teacher/gate单份共享；成员及shared.pt仍去重引用并全量审计。所有成员完整训练100步。不会把LoRA因子拼接成任务向量。

预定t20/t50/t100为保留阈值.2/.5/不裁剪的TIES mass sign与nonzero mean；a20/a50为相同裁剪后的普通两成员均值；n20/n50为a20/a50按对应TIES输出范数缩放，零范数保持零并记录；u50为未经裁剪物理平均，另l1/l4端点。共十候选，顺序如上，各先GraphMAE。只作用deltaW，不合并Prompt与权重不同尺度的拼接向量。

源码topk用d-floor(dK)阶统计量且>=阈值，实际保留可多于K，例如100维K=.2保留21个；并列保留更多，必须记录实际非零数。K=1原函数k=0报错，明确本地绕过裁剪。全局符号和为零时官方disjoint分支偏向负值，按源码保留并记录此边界，不隐藏为中性处理。九组随机/并列/全零×三阈值与独立NumPy逐元素结果完全一致，尚无图实验。

开发支持242100..104、smoke242199；正式285，继承30实际训练轨迹60快照100合成140邻域口径。对最强旧根及Direct至少+.20才固定20新支持确认；同时必须报告相对u50、两个端点及范数控制。即使符号冲突率很低也保留诊断，不用支持loss替代query准确率。


正式封存：真实GCN两ck共4成员轨迹8首末快照、20合成通过。训练合并使用CPU float32物理rank1更新，独立审计用NumPy外积/排序/逐符号汇总，记录真实裁剪数、符号冲突数、未解平票数、缩放率及输出范数；共享输入/成员仍逐文件SHA。先61条12步smoke，再285条100步。
