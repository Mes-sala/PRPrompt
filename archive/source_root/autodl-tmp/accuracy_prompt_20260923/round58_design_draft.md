# 第58轮草案：不同预训练权重的提示预测组合

来源：[Deep Ensembles NIPS2017](https://arxiv.org/pdf/1612.01474)第2.4节/算法1后的分类概率平均，已读原文。本轮借用预测混合，成员为现有GraphMAE与GraphMAE2冻结权重及各自训练的强提示；不复现随机初始化全网络训练或其对抗训练。不是共享主干内部Prompt交互，而是两个模型的终端预测组合，按用户准确率优先目标评估，同时记录额外训练/推断成本。

初步候选：同一支持集、相同查询顺序下，两成员各固定scale2+k50，第二成员权重0.25/0.5/0.75。带两成员单独、原CE+k50两个强参照、重复同一成员混合的恒等预检；必要时固定类别列置换第二成员检验标签对应。不能因混合超过弱GraphMAE2就称进步，必须超过同批最好单模型。若scale2在当前批次低于旧CE，旧CE仍作为强对照保留。

可以先封存固定配置再复用既有dev sealed预测减少GPU与空间，但必须明确是重复dev开发而非新独立证据，成功后使用新20支持且固定混合比例复核。禁止按query学习权重或在确认后重新挑系数；两成员支持/查询/类别映射一致、checkpoint和预测SHA分别保留。集合没有单一checkpoint，不伪造相同checkpointSHA来通过旧配对脚本，应新增支持/图匹配的跨权重审计并绑定两个来源。

只保存必要混合预测和来源哈希，不复制checkpoint或邻接。正式方法矩阵/数据集/seed尚未固定，尚未实现。此轮先以Cora为主；PubMed如扩展，保持未传播VAT/ref50强根。第18/50轮是单权重筛选，并未测试这些新强根的跨权重组合。
