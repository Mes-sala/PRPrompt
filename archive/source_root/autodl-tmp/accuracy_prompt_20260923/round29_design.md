# 第二十九轮：原始特征支持缓存与门控路径

借鉴[Tip-Adapter，ECCV2022，第3.1节](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136950487.pdf)的支持缓存指数余弦检索，形成固定教师；没有CLIP文本分支，不做原文两路最终分数融合。

原始归一化节点特征为key/query，支持one-hot为value：$ A_{ij}=\exp(\beta(x_i^Tx_j-1)) $，beta固定10/30。实现用行减最大值稳定指数；去掉支持节点自身缓存项；按每行每类剩余key数求均值，再行归一化为教师q。直接分类输出log(q)。支持自身移除后剩余4个同类和5个其他类，按计数补偿；不读取任何查询标签。原始特征岭教师作另一个对照，区分缓存非线性与特征来源改变。

共享同一冻结两层GCN、后层激活后token、gamma10、100步训练，原型头及CE+KD不变。三种原始教师各比较门控B=q−mean(q)直接注入与原Ahat B注入，共6训练方法；主干最后一层仍在原有有向图上传播，不把不传播门控误称为完全去掉GNN传播。所有新token统一后层gamma10，避免cache10/30名称改变幅度。

带原始岭/两个缓存直接分类、原始特征原型、Frozen、GraphPrompt、旧二跳平滑岭后层提示，加原始岭与cache30直接门控随机token，共15方法×3图×3权重×5支持seed42100..42104=675条开发指标。使用官方fold0 val，test仍不参与选择。原始主干输入/教师单独NormalizeFeatures/有向边契约延续第28轮。只有超过强直接分类而非弱Frozen才追加确认。

先检查实际缓存函数：标签只接受support标签、self项精确零、概率和1且有限；beta0均匀性、缩放不变性、支持标签置换引起输出类别置换。本轮预检实际为15×3图×1权重=45条3步；逐一核对zero-token、梯度和封存评分。
