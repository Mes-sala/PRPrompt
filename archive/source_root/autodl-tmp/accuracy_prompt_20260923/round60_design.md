# 第60轮固定设计：Lookahead提示优化

借鉴[Lookahead NeurIPS2019](https://arxiv.org/pdf/1907.08610)算法1。每5次Adam更新将慢提示向快提示插值0.5，再复制慢提示回快提示；保留Adam状态，共100次梯度更新/20次同步。冻结主干，仅896个提示参数增加等大慢副本，最终单模型原型/k50读出不变。

Cora两权重、新5支持90100–90104，普通CE/scale2分别测试旧恒定Adam0.01、恒定0.005、恒定0.02、Lookahead内lr0.01/0.02，均原型/传播两读出，另Frozen/GraphPrompt，共220条。第59轮余弦确认未证明更强，维持恒定scale2和旧CE强对照。任何候选需超过同批最强合法单模型（包括新恒定学习率对照），才固定配置进入20新支持确认。

预检10步：alpha1恢复原Adam；k1 alpha0.5与恒定半学习率一致；同步次数与Adam step持续递增。纠正草案：无权重衰减的当前Adam、k1逐步插值、相同初始状态下，k1 alpha0.5与半学习率的参数轨迹可归纳等价（浮点误差除外），后续梯度因此也相同。草案“后续梯度不同所以不等价”判断不正确，不将该恒等对照重复加入正式矩阵。

只用支持标签优化，封存后评分；同图反复开发/确认边界保持。第17轮末端SWA/EMA不替代本轮每5步回写的实测。同步历史记录快慢差及Adam step，保证不重置内状态。公式 $ \phi \leftarrow \phi+0.5(\theta-\phi) $，随后 $ \theta\leftarrow\phi $。
