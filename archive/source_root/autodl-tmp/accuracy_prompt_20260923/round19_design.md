# 第十九轮：教师条件仿射调制

来源：[FiLM，AAAI2018](https://ojs.aaai.org/index.php/AAAI/article/view/11671)。原文用条件信息产生逐特征缩放和平移，用于视觉推理。本轮把条件改为支持标签生成的平滑岭教师，保持同一冻结GCN，调制发生在第一层激活后、第二层GCN前。

继承固定门控 $ B=\hat A(Q-\bar Q) $。原提示 $ H'=H+10B\tanh(T)\odot\sigma_H $。FiLM候选为 $ H'=H\odot[1+0.5\tanh(BS)]+10B\tanh(T)\odot\sigma_H $。T和S均零初始化，缩放范围(0.5,1.5)，零提示严格回到原主干。只缩放版本删除平移，参数数目与原提示相同；仿射版本参数翻倍。

增加双平移对照 $ H'=H+(10/\sqrt2)B[\tanh(T)+\tanh(S)]\odot\sigma_H $。该对照匹配参数数目但不匹配表达能力：零初始化下两矩阵对称，主要检验额外平移幅度/参数化，不能据此单独证明缩放机制。全套保留Frozen、GraphPrompt、直接平滑教师、原型教师gamma3、原单平移，共8方法。
