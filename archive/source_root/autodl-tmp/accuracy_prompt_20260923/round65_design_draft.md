# 第65轮草案：关系蒸馏约束提示表示

来源：[Relational Knowledge Distillation，CVPR2019](https://arxiv.org/pdf/1904.05068)第3.2.1节式5–8，已读原文；CVF网页403后用arXiv正文核对。原方法用批内平均距离归一化的样本对距离及Huber损失传递教师关系。此处只试距离项，不同时引入三元角度项。

拟在第64轮中心化门控提示上添加关系损失，比较无KD根、普通概率KD与关系蒸馏。教师几何为L2归一化的中心化Ahat²X，学生为L2归一化GCN提示表示；仅提示参数可训练，主干输入/权重不变。注意直接欧氏距离具有平移不变性，若不先逐行归一化，中心化不会改变教师两两距离；这里必须写清先中心化再L2的顺序，不能把恒等变换当新作用。

固定支持节点加128个不读标签的非支持锚点，同一训练全程共用锚点。全体非对角样本对距离分别除各自平均距离，Huber(delta1)取均值，增加权重候选0.1/1/10；保留λ0恢复、教师锚点固定置换控制及未中心化教师关系控制。支持CE不变，不能仅比较训练关系损失。直接中心化教师与第64轮门控/KD各强方案仍是准确率参照。

记录额外梯度项是否生效、教师/学生平均距离、防零分母触发、锚点和目标SHA；不保存全图NxN矩阵。无标签锚点可含查询特征，不使用查询标签，明确传导设置。正式矩阵/seed和具体保留根待第64轮确认后封存，尚未实现或运行。不能把原论文学生超过教师的结果当作本方法有效证据。

第64轮确认已完成：主GraphMAE2无KD门控传播67.49%，旧61.06%，但直接教师69.10%。后续固定该无KD提示为训练根，并保留普通KD67.27%的同配置对照；目前未实施关系蒸馏。
