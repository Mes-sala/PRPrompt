# 第112轮草案：干净提示与两扰动视图的JS一致性

已读[AugMix原文](https://arxiv.org/html/1912.02781v2)及[作者cifar.py训练代码](https://raw.githubusercontent.com/google-research/augmix/master/cifar.py)。仅借鉴干净视图CE与三分布JS一致性，不移植其图像操作链/Dirichlet混合，不称完整AugMix，也不声称图分类鲁棒性保证。原作者实现只在clean计算CE，三视图JS乘12。拟沿用这一权重，区别于R110两扰动的双CE+对称KL。

三个前向仍用同一冻结GCN及同一768token：完整提示为clean、两个独立连接掩码为扰动。JS包含干净预测且有界；与R110不同的训练目标并不证明准确率更好，必须真实验证。最终仍完整提示一次推断。

拟主项cleanCE+12JS，三视图CE均值（同前向预算的采样对照）、错配扰动节点对应JS、原cleanCE根；若主项胜出，再补原根300步的粗略前向预算控制。所有LOO分数仅用支持标签，JS三端均反传。不得因双CE在R111表现改变已运行111的源码或候选。

loss112.py使用logsumexp混合分布保证数值稳定，不使用作者概率下限截断；这是明确实现差异。本图cosine/.2分数范围有限时一般不触发作者下限，但仍需实测。独立熵差公式验证JS与三端梯度、相同视图零JS恢复CE、极端有限及JS上界。当前只有损失原语，真实图接入、数据种子和完整审计尚未实现/封存，不计准确率结果。
