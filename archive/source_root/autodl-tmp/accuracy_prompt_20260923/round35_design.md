# 第35轮：节点共享的激活前后仿射提示

来源：[SSF，NeurIPS2022](https://papers.neurips.cc/paper_files/paper/2022/file/00bb4e415ef117f2dee2fc3b778d806d-Paper-Conference.pdf)。借鉴输入无关的逐通道缩放和平移，不复制视觉模型或声称复现。第19轮FiLM使用类别教师门控；本轮所有节点共享128维参数，完全不用教师，只用支持LOO监督。

固定Actor GraphMAE/GraphCL，仅自环冻结两层主干，最终沿用diag10固定几何。提示作用于第一层激活前或激活后，第二层前：$ v'=v\odot[1+0.5\tanh(a)]+\sigma_v\odot\tanh(b) $。只缩放、只平移、两者、随机两者各一组；a/b零初始化，随机分支标准差.3。尺度来自全图无标签初始特征，最终均值/矩阵固定不重算。不改变checkpoint参数，无末端分类融合。激活前平移可以改变激活区域，激活后共享平移经第二层线性层成为统一表示偏移；不能将后者当作复杂消息交互。

每个权重带Frozen/rawridge/diag10无提示/同几何GraphPrompt/旧内部条件token，共13方法，5支持seed53100..53104，官方fold0验证集，130条。Adam .01，100步，LOO交叉熵+.001参数均方；不因query选步数。26条3步预检检查无操作恢复、梯度有限和冻结，再正式运行。该批验证节点已重复使用；如超过同几何强基线且超过对应随机提示，再锁定20新支持作确认。
