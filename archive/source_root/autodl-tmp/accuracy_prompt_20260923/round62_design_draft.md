# 第62轮草案：局部尺度近邻传播

来源：[Self-Tuning Spectral Clustering，NIPS2004](https://proceedings.neurips.cc/paper/2004/file/40173ea48d9567f1f393b20c855bb40b-Paper.pdf)第2节式1/2，已读原文。原论文在图像等聚类问题用每点第7邻居距离作为局部尺度；这里只借用亲和核建图，不复现谱分解、簇数选择或宣称原论文结论自动适用。

拟在归一化CiteSeer教师表示上，以真实欧氏距离定义 $ \sigma_i=d(z_i,z_{i,7}) $，亲和度 $ w_{ij}=\exp[-d(z_i,z_j)^2/(\sigma_i\sigma_j)] $。注意零向量时不能直接用 $ 2-2z_i^Tz_j $ 代替欧氏平方，须使用两侧实际平方范数。尺度下限需明确固定并记录触发数。先保持同top50邻居集合，只改变权重；另比较按局部尺度距离重排top50，以区分权重与邻居选择。

第61轮原始近邻图最大入度818、平均50；部分支持条件下传播后500查询预测集中到同一类（最多261），传播前该类84。此为观测，不证明入度导致错误。局部尺度不能保证消除hub，必须记录变化并以准确率而非图指标作选择。

对照保留未传播修正教师、原全局余弦核，同时对全局核/局部核匹配alpha0.5与0.9、20步/支持钳制；不能只把减弱传播带来的恢复算局部尺度效果。直接教师没有主干，作为强准确率方案单独归类；若超过强教师，再考虑同算子是否帮助提示，不能以非Prompt结果声称提示机制有效。新5支持开发，冻结配置后运行；同图查询重复使用须披露。尚未实现、正式矩阵和seed未封存。
