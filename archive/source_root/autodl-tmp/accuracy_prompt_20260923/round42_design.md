# 第42轮：训练内固定表示近邻一致性

借鉴[视觉LaplacianShot](https://proceedings.mlr.press/v119/ziko20a.html)的邻域一致性，但这里直接对图提示训练加入概率差平方损失，并非原论文推断算法复现。承接第41轮已有论文阅读和传播实现。目标只看匹配强基线的准确率提升。

冻结同一个两层GCN，训练C×128条件token，位置为第一层激活后、第二层卷积前。Cora使用旧平滑岭教师与幅度10，第一阶段CE+KD训练100步。用第一阶段归一化表示构建固定10近邻、温度.2的行随机权重。第二阶段复用同一token与Adam状态100步；不同方法从完全相同第一阶段状态分支，图不更新。

新增项为 $ R=\frac1N\sum_i\sum_j W_{ij}\|p_i-p_j\|_2^2 $，其中概率由当前表示与支持集原型计算，梯度流经两侧概率及支持原型。第二阶段损失为原CE+KD+参数L2，再加 $ \lambda R $。所有图节点参与，不使用查询标签。lambda固定1/10，随机图使用同度数、同边权、共享目的节点随机重排并移除自边；并非保持入度的严格随机化。

正式开发：Cora×GraphMAE/GraphMAE2×seed66100..66104×10方法=100条。方法为Frozen、普通GraphPrompt、平滑岭教师、stage100、stage200、knn1/10、random1/10、stage100纯传播。开发查询仍旧dev500。零权重重复分支仅供程序检查，不计为正式方法。正式配置不根据预检准确率修改。

预检比较旧100步输出、旧200步连续训练输出、100步纯传播输出，检查零新增损失、相同初始token和Adam步数、常数概率正则为零、邻接不变、冻结参数、预测先封存后评分。每个sealed保存初始token/Adam及稀疏图，可审计分支起点，不保存大检查点。若超过stage200和对应随机图，再在新支持种子确认；另比较纯传播基线，准确率相当时不优先复杂训练。

预检记录：旧100/200步与零新增损失输出误差均小于1.7e-6。独立GPU重训练的近邻发生并列换位（两权重84/98行），传播概率最大差0.00173/0.000288，分类相同；不声称传播逐位等价。正式分支共享同一图，消除分支间重新构图因素。
