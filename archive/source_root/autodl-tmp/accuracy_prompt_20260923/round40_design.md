# 第40轮固定设计：鲁棒原型聚合

来源：[Robust Aggregation for Federated Learning，Pillutla等，几何中位数及平滑Weiszfeld聚合](https://arxiv.org/pdf/1912.13445)。将客户端更新聚合思想迁移为5-shot类别向量聚合；不假设存在错标或恶意节点，不引用其联邦收敛/攻击容忍保证作为图准确率证据。

先在相同Frozen与强Prompt表示上比较均值原型、几何中位数原型、均值与中位数等权折中。节点表示统一L2归一化，类别聚合后归一化，余弦温度.2不变。中位数采用平滑Weiszfeld：从均值出发，按与当前中心距离的倒数重加权，分母下限预定1e-3，固定30次；记录目标下降与最后残差，不宣称精确求解几何中位数。只读支持标签，原训练不变。若读出改善，再将支持留一原型改为同一稳健聚合并比较新训练增量。

与第38轮协方差度量不同，本轮只改类别中心，不学习协方差/更换距离。必须带原均值、随机权重或单步重加权简单对照，避免把任意重加权收益归于稳健性。先审计相同输入点保持不变、样本重排等价、平移/旋转等变及异常点合成诊断；合成诊断不是实际数据效果证据。固定Cora/PubMed×GraphMAE/GraphMAE2×5支持seed61100..61104，旧dev500。Frozen与强提示各5种中心（mean/30步median/blend/one/random），另加Frozen/GP/两教师，共280条；68条3步预检含旧root/VAT参考。PubMed/GraphMAE强提示采用已确认VAT.3，其余旧强root不变。每个条件只训练一次，所有中心共享表示SHA256。random类内独立均匀权重+.01，仅作无标签权重对照。只借鉴平滑几何中位数，30步不保证精确解。
