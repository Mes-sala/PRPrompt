# 第57轮草案：支持原型分类的训练温度

借鉴[CLIP ICML2021原文](https://proceedings.mlr.press/v139/radford21a/radford21a.pdf)第2.2节和图3：余弦分数乘可学习的对数参数化标量。借用标量温度优化，不引入图像/文本分支或CLIP预训练。

当前支持留一原型CE一直使用温度0.2。拟只改变该监督项的温度，候选固定0.1/0.4及从0.2初始化的可学习温度；保留原教师、门控、KD温度0.2、100步和token注入。查询原型读出及k50传播仍固定原0.2，检验的是训练表示变化，而非查询时的概率校准。学习标量上限可预设为100，记录达到上限的步数；它与token一起优化，但不纳入token L2。

必须带原CE和新scale2强根。对新scale2，系数从对应监督温度下的真实类概率计算并detach，会同时改变监督梯度的分布与整体尺度，不能简化成单纯固定CE缩放。可先固定温度比较原CE/scale2两类训练，再检验学习标量是否超固定候选。固定矩阵/seed尚未设定，不能以query拟合温度。

预检温度0.2恢复原根、常数标量不改变推断argmax、学习标量梯度有限、冻结主干、教师温度未变；记录训练标量轨迹。若后续评价使用学习温度作传播锚，必须另作为读出消融，不能混入本轮训练比较。尚未实现运行。
