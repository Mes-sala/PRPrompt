# 第100轮：初始支持尺度匹配的LogitNorm

来源[LogitNorm公式4](https://proceedings.mlr.press/v162/wei22d/wei22d.pdf)，本轮不评估OOD，不把原文检测/校准收益等同分类提升。适配为固定零token时支持LOO logits范数均值作为目标k，非原文固定tau复现。

CiteSeer两种GraphMAE权重，各自当前Adam/graftedShampoo .01；冻结共享2层GCN128，单6×128 token在第一层预激活注入，教师3步中心化、.1门控、amp10、100步、.001参数正则全部保持。无KD，最终中心化原余弦读出/k50保持。

lnr主候选：$CE(k s_i/(\|s_i\|_2+10^{-7}),y_i)$，梯度穿过分母。lnd停止分母梯度（同参数同前向，但训练轨迹可不同）；lng以当前支持平均缩放因子停止梯度后统一缩放logits；lni原CE只作预检恢复。k只由初始支持LOO计算并固定，分数不再中心化。参数正则不缩放。保存初始分数/k、每步因子、全梯度与首末更新前token，独立CPU逐支持逐类重建并核验k和梯度。

解析梯度、零向量有限性、epsilon=0径向不变、原CE恢复预检；正式epsilon1e-7不宣称精确径向不变。29预检158199三步、五项审计通过后125开发158100..104。主比较lnr减各权重当前根，同时比较lnd/lng与Direct；没有提升停止，有候选固定20新支持确认。统一沿用之前的封存评分/同图重复查询限制。
