# 第66轮草案：角度关系蒸馏

来源：[RKD，CVPR2019](https://arxiv.org/pdf/1904.05068)第3.2.2节式9/10，原文已读。三元关系是以同一锚点为顶点的两条差向量夹角余弦，再用Huber损失匹配教师与学生。第65轮只验证距离项，不能代替角度项的准确率检验。

沿用中心化门控无KD的冻结GCN Prompt，固定支持+128无标签锚点，从中用独立生成器取2048个三点互异的固定三元组。教师仍先中心化再逐行L2，学生逐行L2；再计算差向量单位化后的内积。与距离项一样，未经逐行归一化时角度也具有整体平移不变性，不能将无效中心化算新变化。

拟权重0.1/1/10，每档有教师锚点固定置换控制；保留无KD、概率KD/旧KD门控强对照、第65轮距离权重10及直接中心化教师。教师零长度边三元组应由无标签教师特征预先排除并记数，学生归一化分母下限需明确记录触发。同一三元组列表用于所有候选，保存索引/目标SHA，避免全图三阶张量；无query标签参与。

预检λ0恢复、独立内积计算、合法三元组、教师目标和梯度有限，强对照同100步预算。超过强Prompt与直接教师才扩大。第65轮距离项仅局部改善，当前仍未超过强直接教师，本轮不预设有效。方法矩阵/seed尚未封存、尚未实现。
