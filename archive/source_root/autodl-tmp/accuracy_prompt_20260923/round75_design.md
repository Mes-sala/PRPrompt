# 第75轮：低置信支持样本降权

来源：[Zhang与Sabuncu，Generalized Cross Entropy，NeurIPS2018](https://proceedings.neurips.cc/paper/2018/file/f2925f97bc13ad2852a7a551802feea0-Paper.pdf)，已读第3.2节公式6及第4.1节。其噪声视觉分类实验用q=0.7；原文也说明干净数据过大q可能降低准确率。这里不假设支持标签错误，而检验少样本LOO原型中极低置信样本的梯度是否过度主导提示。

固定现有CiteSeer零初始化强根，768token在共享GCN第一层卷积后/激活前，冻结主干，100步Adam0.01，教师门控/只读中心化/原型与k50保持。只改变支持监督损失，不增加伪标签、不删支持节点、不读查询标签。

GCE=(1-p_y^q)/q，q固定0.3/0.7；q=0按CE极限实现。它的梯度等于原CE样本梯度乘p_y^q，倾向降低困难样本影响，与第53轮Focal的方向不同。为分离整体梯度缩放与样本对应，另带detach平均权重×平均CE、固定无自映射置换权重×逐样本CE，两q都匹配；没有把简单梯度缩小直接叫作鲁棒增益。

保持token正则0.001，因而监督项缩小会改变相对正则强度；匹配平均权重控制用于检测该混杂。候选必须超过同批零初始化、新KD、随机候选及均值/置换控制，再用新支持确认；Direct始终独立参照。预期两权重、新支持114100–114104。算子梯度核验先行，正式矩阵与驱动待封存，尚未运行准确率实验。
