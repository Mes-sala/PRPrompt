# R113：错配JS次要准确率发现的固定确认

R112主正确JS未胜：GraphMAE jsr69.68 vsAdam69.76，GraphMAE2 jsr69.48 vsgsh69.44且低于三CE69.52。主项不扩展。GraphMAE2错配JS jsp69.84相对gsh69.44 +.40pp、正确JS+.36、三CE+.32、Direct69.76 +.08，按准确率目标单列**开发后挑选的次要发现**。不能解释为同节点一致性成功，也不能预判这是负熵作用。GraphMAE错配69.76=原Adam，不扩大。

固定179100..119、GraphMAE2、原112源码不变。100步全部13方法260条，另gsh300步两读出40条，总300条。主要jsp100对gsh100，辅助正确JS100、三CE100、Adam100、Direct、gsh300（粗前向预算，非严格墙钟/FLOP，更新次数不同）。若主要增量区间>0才进行第二组复核；若不胜gsh300不宣称特有三视图方法收益。固定10,000次支持bootstrap与(.025,.975)，不得据确认重挑超参。

本实验仅确认这个固定损失控制的准确率，不冒充AugMix完整方法；共用一个768token和冻结GCN，无终端融合。所有分数封存后评分，五审计和两预算目录source/checkpoint/split/support/query绑定。原型与KL/JS不读取查询标签。
