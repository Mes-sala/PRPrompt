# 第81轮草案：借鉴Sparsemax的稀疏类别门控

来源：[Martins与Astudillo，ICML2016](https://proceedings.mlr.press/v48/martins16.html)，已核对[原文](https://proceedings.mlr.press/v48/martins16.pdf)第2节式2–4及算法1。该方法将分数向量欧氏投影到概率单纯形，能给部分分量精确零值；原文涉及多标签分类及自然语言推理注意力。仅借鉴概率映射，不迁移其专用损失或重训主干。

第80轮PubMed门控锐化未提升，不再扩大；回到第79轮已确认CiteSeer配方，以它作为必须战胜的对照。设已有教师score为s（已除0.2），候选固定sparsemax(2s)，和当前softmax(2s)比较。不再同时搜索温度。零概率不等于节点完全不受某类影响，因为后续减列均值和Ahat传播会改变稀疏结构，必须分别记录概率零比例及最终门控密度。

模型仍冻结同一个GCN，早层token共享该主干，768参数，不加KD，最终中心化+k50固定。比较稀疏原门控、缩回当前softmax门控Frobenius范数的版本，以及只将softmax门控放大到候选范数的控制；保留旧温度0.2根、Direct。公式 $ q_i=\max(2s_i-\tau,0) $，阈值满足 $ \sum_iq_i=1 $。仅改变门控概率，非读出融合。

必要预检：双精度独立二分阈值与排序实现一致、平移不变、单纯形、并列/极端输入、门控范数与全网络重建；如需随机控制使用固定生成器且不扰动训练。待固定完整矩阵和新支持122100–122104。此文件仅设计，未实现或运行，不记入有效方案。

复查旧设计发现标签平滑（R54）和SwAV分配归一化（R27）已做；本次不原样重复。文献检索不将这些旧方法重新计为新实验。
