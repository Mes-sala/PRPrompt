# 第60轮草案：Lookahead提示优化

来源：[Lookahead，NeurIPS2019](https://arxiv.org/pdf/1907.08610)算法1及第2节。借鉴视觉/机器翻译训练中快慢参数插值；在每5次Adam更新后，将慢提示向快提示插值，再用慢提示覆盖快提示继续训练，保留Adam内部状态。主干仍冻结，只多一份896维慢提示，100次梯度预算不变。最终使用第100步同步后的提示，读出仍为原型或k50，不增加推断成员。

候选慢步长0.5，内Adam学习率0.01或0.02，普通CE与scale2分别测试。恒定Adam0.005/0.01/0.02作为更小/更大更新量参照，另设置k1、alpha0.5控制连续缩小更新幅度；alpha1预检应恢复原Adam。k1在保留状态的Adam下不简单等同于降低学习率，因为后续梯度由改变后的参数决定，需实测而非断言。原论文讨论内部状态保留/插值/重置，此轮固定保留，不同时搜索。

与第17轮SWA/EMA区别：第17轮平均仅用于最终读出；本轮慢参数每5步重置快参数，改变后续训练轨迹。过去平均失败不替代本轮实测。需要记录同步次数、快慢差与实际参数更新量；同训练预算、支持与查询严格配对。尚未固定完整矩阵或实现；先根据第59轮确认决定是否将余弦方案列为强参照，避免只胜弱旧基线。
