# 第96轮草案：节点门控RMS尺度归一化

来源：[Zhang与Sennrich，RMSNorm，NeurIPS2019第4节公式4](https://papers.nips.cc/paper_files/paper/2019/file/1e8a19426224ca89e83cef47f1e7f53b-Paper.pdf)，已读原文。借鉴按向量RMS归一化的操作，不加入原论文可学习gain，不归一化冻结主干，也不宣称其训练速度或稳定性结论自动适用。

原温度.1教师门控 $ B=\hat A(q-\bar q) $ 不变。逐节点权重 $ w_i=(C^{-1}\sum_c B_{ic}^2+10^{-6})^{-1/2} $，候选 $ R_i=w_iB_i $。主候选再乘 $ \|B\|_F/\|R\|_F $，保留整体范数。原R、原B乘范数比的纯幅度控制、将w按独立CPU seed+960000置换后乘B并匹配整体范数，identity恢复。所有零方向显式返回零，固定epsilon不扫描；epsilon使严格尺度不变性不成立，不能误称保持完整RMSNorm理论性质。

由于概率行和为1，B沿类别维均值理论为零，因此此处RMS与相同epsilon、无gain的LayerNorm等价，不再把LayerNorm当独立机制比较。操作等于固定节点行重加权；较小门控行会被相对放大，但不假定它们更有用或更可信。第20轮曾按教师熵加权并在传播前再中心化，本轮按传播后的门控RMS重加权，不新增中心化或第二次图传播。

一个冻结GCN和同一768token，第一层激活前使用新门控乘tanh(token)，不做预测融合。原三步教师/原温度.1、当前Adam与Grafted、100步、最终中心化+k50保持。第95轮未保留六步，不继承该变体。
