# 第66轮固定设计：角度关系蒸馏

来源和边界见round66_design_draft.md。CiteSeer新五支持101100–101104、两预训练权重，230条开发。普通角度/固定教师置换各权重0.1/1/10，加原无KD、新KD、旧KD门控根与距离项权重10，两读出，另Frozen/GP和两个直接教师。主干冻结、768参数、100步Adam0.01不变。

30支持+128无标签锚点，与距离项采样规则相同；独立seed+660000生成8192候选三元组，排除重复节点、重复三元组并随机重排，使用教师原顺序及固定置换共同的非退化掩码，截取2048组。如此保证正确/置换共享合法三元组，不能各自筛出不同列表。置换seed+660001。教师先中心化L2，学生L2，差向量范数下限1e-8，Huber均值。排除数和学生分母触发累计记录，保存三元组、置换和目标SHA。

预检λ0恢复、三元组唯一/节点互异、独立余弦计算及梯度、教师锚点对应、冻结/共享表示。8个原型方法×2权重=16条3步预检。只有超过同批强Prompt与直接教师才扩大。同图重复查询限制保持，不保存全图三阶张量。
