# 下一候选：保留节点自身信息的结构提示（未实现）

跨领域借鉴：[ResNet，CVPR2016](https://www.cv-foundation.org/openaccess/content_cvpr_2016/html/He_Deep_Residual_Learning_CVPR_2016_paper.html)保留输入路径的原则。此处不宣称复现残差网络，也不宣称自环加权是新机制；考虑在同一冻结GCN中改变每层图自环权重，增强节点自身消息相对邻居的比例。

原图非自环不变，自环设为lambda，交给原GCN归一化；lambda=1须恢复原forward。先比较固定lambda=1/10/100与仅自环（无跨节点消息），再学习两个层标量，从lambda=1初始化，只用支持LOO CE，另比较原始岭教师KD。权重矩阵、bias、分类原型协议全部冻结/保持原规则。固定图算子对照与学习结构提示必须分开报告，不能把移除邻居的固定收益归给梯度学习。

这是可学习图结构/边权提示，作用于共享主干输入的消息图，不是末端读出融合。只保留自环相当于沿用预训练线性层的节点MLP，是必要强对照，不能省略。需核对有向GCN度归一化及重复自环处理、lambda梯度有限性、lambda1精确恢复；同图原始特征岭分类仍是强上限参考之一。此为下一设计草案，不计入实验结果。
