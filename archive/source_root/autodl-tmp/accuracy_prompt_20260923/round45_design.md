# 第45轮固定设计：支持集监督对比损失训练提示

检索并阅读[SupCon原文](https://arxiv.org/pdf/2004.11362)第3.2节式2，借用平均各同类正样本log概率的损失。与原图像方法的多增强/投影头/全编码器训练不同，本任务只更新已选强token，不加投影头或查询伪标签。支持集每类5个，每个anchor另4个同类正样本，所有其他支持节点进入分母，自身排除；温度先固定.2，归一化表示。无标签图节点仍只受旧教师KD（PubMed/GraphMAE保留VAT）。

在相同100步原CE+KD(+VAT)上添加SupCon，权重先.1/1；对照原损失、对应权重的支持标签固定置换（仅改对比正样本关系，CE/KD真标签保持）、强最终传播读出。不把额外步骤或头容量当损失收益。可先Cora两权重，再有条件扩PubMed；矩阵与种子在实现前固定。须检查每anchor正样本数4、self不入分母、类别重排与支持顺序不变、零权重恢复、无查询真值、有限梯度及冻结主干。

原型CE先求同类均值，SupCon在个体正/负样本上约束，可能补足原型掩盖的类内离散；这是待验假设，不是收益结论。不能只报告训练loss降低。正式矩阵固定Cora×GraphMAE/GraphMAE2×seed70100..70104×9方法，共90条开发dev500。9方法：Frozen、GraphPrompt、岭平滑教师、强提示原读出、强提示原10NN传播、SupCon真/置换标签×权重.1/1。原始提示训练100步、温度.2，不加投影头。只有超过同权重原提示且有希望超过强传播的候选扩大确认。
