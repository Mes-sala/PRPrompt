# 第十四轮：两项已验证改进的配对组合

借鉴第十轮的[VPT提示位置](https://arxiv.org/abs/2203.12119)与第十一轮的[图像滤波思路](https://doi.org/10.1109/ICCV.1998.710815)，只组合实测较好的普通邻域平均与后层提示。不新增论文原创性要求。

共享同一个冻结两层GCN；平滑发生在固定岭教师概率上，同时改变内部token门控和KD目标；后层位置发生在第一层激活后、第二层GCN之前。最终仍为单一原型读出，不是两个分类结果融合。参数数目不变。

预先固定2×2因子：早层/后层 × 原教师/两步普通平滑教师，gamma10。Cora、GraphMAE/GraphMAE2、20新支持种子20100..20119、确认query，共8方法×2权重×20=320。Frozen、GraphPrompt、两种直接教师同批配对。没有先筛选该批查询结果。

主要判据：组合分别对仅后层、仅平滑的配对准确率差及支持种子bootstrap区间；若只超过旧方案却不超过最好单项，不宣称可叠加。GraphMAE2后层在第十轮仅属探索性观察，此轮首次预先固定验证。查询图和节点已在历史轮使用，明确为同图新支持稳健性验证。
