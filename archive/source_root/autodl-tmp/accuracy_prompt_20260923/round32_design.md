# 第三十二轮：收缩协方差几何与Prompt

来源：[Whitening Sentence Representations，Su等2021，第3.2节](https://arxiv.org/pdf/2103.15316)。借鉴去均值和逆协方差平方根变换，作为经验度量选择；不把各向同性当作余弦相似度可用的必要条件，不直接接受原文的该理论解释。完整白化与历史round2逐维缩放不同。

候选基础是第30/31轮Actor有效的仅自环冻结主干，同时在Cornell/Chameleon保留强原始岭直接对照。全图无标签基础表示估计mu和C；固定收缩 $ C_a=(1-a)C+a\operatorname{tr}(C)I/d $，逆平方根用于变换表示。用原几何、仅中心化、对角收缩a=.1、完整收缩a=.1/.5五组，各自比较无适配、同几何GraphPrompt、同几何内部gamma3 CE token；另保留原图Frozen/GraphPrompt、raw/rawridge。统计矩阵在提示训练前固定，不因支持loss或查询标签更新。

固定19×3图×2权重×5支持=570开发指标；seed49100..49104，官方fold0 val。内部token仍在第一层激活后、第二层前，原始岭教师提供固定门控，但不加KD；最终白化只改变分类几何，单独收益归为非Prompt固定校正，训练增量必须匹配同几何无提示/GraphPrompt。不做维度搜索或按query选收缩强度。

单元预检应涵盖：非奇异合成矩阵a=0白化协方差接近I；a=1变换等价于中心化后统一缩放；收缩a>0正定且有限；零token恢复对应校正基础，主干冻结。实现可共享保存每个图/权重/几何的mu与W，避免每种支持结果重复存矩阵。第31轮多fold已完成，内部token增量不稳定；执行本轮固定设计。统计矩阵每图/权重/几何共享一份，以SHA256记录引用。正式前57条3步预检。


## 数值修订（初轮后记录）
