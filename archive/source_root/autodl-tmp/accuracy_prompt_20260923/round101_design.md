# 第101轮：留一类原型Circle Loss

来源[Circle Loss第3节公式5/6及梯度9/10](https://arxiv.org/html/2002.10857v2)，借鉴图像检索/识别的正负相似度独立权重。本轮用可微支持留一原型代替独立分类权重，不声称复现原视觉任务。

固定CiteSeer两种GraphMAE及各自当前优化器、单768token、冻结共享GCN第一层预激活、原教师/门控/100步/最终中心化+k50。只换支持损失；原scores除以5还原余弦，固定gamma5与原温度对应，m=.25，不用原视觉大gamma。

cir：$\alpha_p=[1.25-s_p]_+$，$\alpha_n=[s_n+.25]_+$，系数停止梯度；$L=softplus(logsumexp(5\alpha_n(s_n-.25))-5\alpha_p(s_p-.75))$。cic：同间隔系数均为1，等价原CE正类余弦减.5（score减2.5），不是原CE。cip：CPU seed+1010000每步置换支持行的系数向量（第一位正类、其余五位按类别升序的负类），保留正负角色但打乱样本对应。cii原CE仅预检恢复。正则保持.001token²，不缩放。

保存置换、实际使用系数、全部梯度及首末token并绑定SHA。解析梯度/常数间隔归约/identity预检；CPU独立逐支持逐类重建损失梯度。29预检160199三步五审计后125开发160100..104。主cir对两当前强根，匹配cic/cip/Direct，未提升停止，有价值候选才20新支持确认。同图重复查询限制不变。

数值预检曾因softplus默认threshold20的线性近似与精确softmax梯度误差超过1e-14而停止；正式封存前将threshold固定50（有界余弦下输入不超过约26），梯度误差降至2.08167e-17。算法目标未变，原语失败保留在进展记录。
