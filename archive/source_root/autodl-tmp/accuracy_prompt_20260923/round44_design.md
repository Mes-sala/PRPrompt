# 第44轮固定设计：互近邻传播

来源及边界见[草案](round44_design_draft.md)，借鉴行人重识别互近邻规则，非完整Jaccard重排复现。Cora两个权重、100步旧强提示、alpha.9传播20步固定。所有方法共享同一表示和原10NN。互近邻仅保留双向命中边，按原边权重归一化；空行回退完整原10NN。随机删边在每行原10NN中随机保留相同数量，再归一化，权重总量均1但单边权分布不严格相同。混合图=.5原图+.5互近邻归一图。

9方法：Frozen、GraphPrompt、平滑岭教师、强提示原读出、原10NN传播、互近邻钳制/无钳制、等边数随机删边、混合图传播。2权重×seed68100..68104×9方法=90条dev500开发。主候选相对原10NN、原提示及随机删边配对；无钳制只作解释对照。保留真实互惠mask、回退mask和随机mask，稀疏图绑定表示哈希；不存N平方磁盘矩阵。支持5shot，query标签封存后评分。若超过已验证强传播再扩大20新支持确认。

预检：每条有效互惠边必须双向命中，随机/真实每行数量一致、空行回退一致、行和1、无自边、非负；常数概率保持、alpha0恢复，训练源码AST不变。正式图不随方法重算近邻。

开发后预选：仅GraphMAE混合图+0.32pp值得复核，纯互近邻及GraphMAE2不扩大。确认seed69100..69119，主权重8方法+GraphMAE2原读出/原传播2方法，共200条。v2仅添加50/50随机删边混合图对照，候选及训练代码不变。
