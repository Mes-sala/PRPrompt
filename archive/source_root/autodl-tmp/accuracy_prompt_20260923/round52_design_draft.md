# 第52轮草案：LaplacianShot式联合概率推断

来源：[ICML2020原文](https://proceedings.mlr.press/v119/ziko20a/ziko20a.pdf)，已读2.1–2.3节，式4、8、12。将原型距离一元项与邻域一致性结合，闭式更新为softmax(-a+lambda W Y)。本轮借鉴其非线性联合推断，不直接照搬视觉模型与预处理。

拟保持现有100步强提示及原型不变。对同一提示嵌入的50近邻图，用原始原型logits作为一元项，迭代 $ Y^{t+1}=\operatorname{softmax}(L+\lambda W Y^t) $，支持行钳制one-hot，20步，lambda候选1/3/10。与现有线性锚定概率传播作同图同嵌入比较；加lambda0、随机等度图和仅一次非线性更新。明确是推断读出，未增加可训练Prompt参数。

理论边界：现有有向行归一50NN不保证对称半正定，不能直接继承论文的MM单调收敛证明。先核查作者实现，再决定使用对称归一图还是保留有向图作为工程变体；对称图亦不自动半正定。记录迭代差/目标趋势，限制固定步数；不声称理论收敛。若调整图，补相同图的线性传播，区分图改变和更新规则改变。
