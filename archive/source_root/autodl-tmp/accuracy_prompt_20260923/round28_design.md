# 第二十八轮：三种异配图上的机制迁移

本轮将前面跨领域借鉴形成的修正原型教师、岭教师与内部token迁移至Cornell/Actor/Chameleon，先核查它们在不同图上是否有效，不继续只在引文图上调损失。复用5090迁入的9个权重（DGI/GraphCL/GraphMAE）及源数据，全部来自assets5090_manifest.json。

输入契约：主干原始特征、有向原始边；两层冻结GCN128、LeakyReLU、最后线性层，先与完整model.forward数值比较。教师特征独立NormalizeFeatures，再按原有有向GCN算子传播2次；不将图静默对称化。相同支持/教师/主干下比较内部提示与原型分类。共享参数只有单一类别token，原型修正方案早层gamma3；岭方案早层gamma10或普通平滑教师后层gamma10。训练100步Adam .01。

在正式运行前细化上一轮资源预案：开发使用官方fold0的val_mask，确认才使用test_mask；两者都只从train_mask取每类5个支持，固定seed41100..41104开发。新图测试标签不用于本轮开发选择。数据加载允许知道类别数，但查询标签仅在封存预测之后用于评分。新增fold参数支持之后多fold检查；Cornell测试37节点，单次准确率步长2.70pp，不能通过重复支持扩大独立样本量。

13方法：Frozen、GraphPrompt、归一化原始特征余弦原型、二跳特征原型、原始归一化特征岭分类、二跳岭教师、平滑二跳岭教师、修正原型直接教师、修正原型早层提示、二跳岭早层提示、平滑岭后层提示、后两类代表的随机token（修正早层与平滑岭后层）。随机token与对应训练方案同幅度/教师/位置；不读取查询标签选择参数。

3图×3权重×5支持×13方法=585条正式开发指标。先每图/权重1支持3步预检，核对输入图哈希、5-shot、不重叠、主干冻结、zero-token无操作以及直接教师跨权重一致。沿用强原始特征对照，只有超过对应强基线才确认。弱基线上的增益单独记录，不能当跨图成功。所有推理与训练在51542，继续复用ProG环境。
