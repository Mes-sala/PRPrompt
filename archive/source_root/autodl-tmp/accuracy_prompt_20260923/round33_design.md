# 第三十三轮：既有强Prompt与固定几何校正

继续借鉴第32轮NLP句向量几何校正，不改变已确认提示的教师、门控、共享主干、位置或幅度。Cora用平滑岭教师后层gamma10；PubMed用beta.5修正原型教师早层gamma3。两者都是冻结两层GCN内token，不做末端分数融合。

每图/权重从原始无提示GCN输出估计全节点无标签均值/协方差，并固定校正矩阵；只改变学生最终表示的原型分类几何和训练损失，教师概率与门控仍按原方案生成，不对教师原始特征应用该校正。四种几何：原始、中心化、对角收缩.1、完整收缩.1（相对数值下限，沿用32修订）。每种分别比较无提示、同几何GraphPrompt、同几何强内部token。额外Frozen、原GraphPrompt、两种直接教师，共16×2图×2权重×5支持seed51100..51104=320条开发指标。

沿用引文图官方train池5-shot和既有固定500开发/500确认划分；这些查询已在过去轮次使用，并非全新测试。步骤100、Adam .01、支持LOO CE+原教师KD+token正则不变。校正矩阵共享保存及SHA引用；实际token训练输出与最终评分使用同一固定几何。原始几何必须恢复原强Prompt，校正后零token应恢复同几何无提示；先每图/权重1支持3步预检，再运行。

只有超过原强Prompt、同几何无提示/GraphPrompt和直接教师才追加新支持确认；固定几何收益与训练增量分开记录。source：Whitening Sentence Representations (https://arxiv.org/abs/2103.15316)，仅借鉴算子，不接受各向同性是余弦有效前提的解释。
