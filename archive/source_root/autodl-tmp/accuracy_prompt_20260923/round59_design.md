# 第59轮草案：提示优化的余弦学习率

来源：[SGDR，ICLR2017](https://arxiv.org/pdf/1608.03983)第3节式5，已读原文。只借用余弦学习率思想，保留当前Adam、冻结主干、强提示和100步预算；不是复现原文SGD全网络视觉训练，也不声称继承其性能结论。第一轮先无重启，避免同时引入快照集成。

计划在Cora GraphMAE/GraphMAE2新5支持开发种子88100–88104，旧CE与scale2各比较恒定0.01、恒定0.005、余弦0.01至0、余弦0.02至0，均有原型与k50读出，另Frozen/GraphPrompt。公式 $ \eta_t=\eta_{max}(1+\cos(\pi t/99))/2 $，$ t=0,\ldots,99 $，离散累计学习率恰为50倍峰值。故0.02余弦与恒定0.01累计量相同，0.01余弦与恒定0.005相同；这不保证Adam真实参数步长相同，记录实际更新范数。不改变CE/KD相对权重，不与第56轮监督损失退火混同。保持Adam状态不中途重置，保存完整学习率历史和末步参数。

先验证恒定0.01恢复旧提示和scale2、数值端点与累计量、冻结主干、同表示缓存对应同训练配置。筛选后仅优于同批最好单模型的方案进入新20支持确认。预算、矩阵待正式封存；当前仅草案，未实现运行。禁止按查询曲线选训练步数；同图重复开发/确认须披露。
