# 第73轮草案：支持类别驱动的提示初始化

来源：[Lester等EMNLP2021原文](https://aclanthology.org/2021.emnlp-main.243.pdf)，已读第2.1/3.2节初始化比较：随机、词表嵌入和类别名称嵌入。图数据没有可直接复用的类别词嵌入，因此仅借鉴“用任务相关表示初始化”的思路，以支持节点隐藏表示替代；不是原论文复现。

第72轮新增子空间参数未胜强提示，下一步不增加模块或参数。固定CiteSeer当前中心化教师门控、无KD、768参数、100步Adam0.01和只读中心化+k50；仅替换原零token初始化。

拟每类用5个支持节点第一层卷积后、激活前的隐藏均值，减全图无标签隐藏均值，再除原通道标准差。按每类RMS归一化并缩放至0.01/0.1，作为tanh之前的token初值。明确标准差/近零类向量下限，禁止读取query标签。两个强度各带类别行置换控制和逐类匹配范数的随机方向控制，保留零初始化和中心化新KD强对照及Direct教师。

不能把初始CE较低当最终效果，需保存初值/类别均值/置换索引/随机种子、初始实际隐藏扰动RMS与最终预测。同强度随机方向不一定与语义初始化有相同门控后扰动，因此同时记录实际扰动，并考虑匹配实际总扰动范数以免混淆幅度。训练步数和学习率均保持，若只加速收敛而未提高100步准确率则不称最终收益。

预检验证幅度0恢复原实现、支持标签来源、原主干不变、初始化确定性、置换/随机对照范数及梯度；主候选须胜过同批最强提示与Direct才固定20新支持确认。预期仍是同图重复开发查询，不能声称独立图泛化。正式幅度匹配规则、seed和矩阵尚未封存，未实现。
