# 第56轮固定设计：损失下降速率调权与简单监督退火

检索[视觉多任务MTAN CVPR2019](https://openaccess.thecvf.com/content_CVPR_2019/html/Liu_End-To-End_Multi-Task_Learning_With_Attention_CVPR_2019_paper.html)的Dynamic Weight Average；已读[原文](https://arxiv.org/pdf/1803.10704)第4.1.3节及温度设置，式7按最近两个时段任务loss比值做softmax权重，权重和为任务数。借鉴的是损失权重规则，不引入MTAN注意力网络，也不改变图主干。

当前Cora有效scale2的CE整体系数从约1.1降至0.2，可能主要来自监督与KD相对权重随时间变化。拟对CE/KD两项测试DWA温度2、连续5步均值作为一个时段、最初两个时段权重1/1；按前两完整时段的比值更新，不能看未来loss，更不能使用查询标签。对照含新scale2强根、原1/1、固定CE0.2，以及CE从1.1线性退火至0.2而KD固定1。DWA令CE/KD权重和2；固定退火不归一，需明确总体loss尺度与token正则相对权重的不同，不能视为纯粹只改比例的消融。

尚未实现，矩阵/seed待固定。先检查Cora旧训练loss下降比值的实际范围；若DWA几乎等同1/1，保留等价诊断而不大规模重复。为区分整体尺度，可补DWA按KD权重归一后的相对CE系数形式，是否加入在启动前固定。纯标量规则无可训练额外参数、无新教师或查询伪标签。所有训练共享同一原型/k50双读出，继续按强基线准确率判断，不按原创性筛选。

已有训练history通常只存首尾，无法还原连续时段比值；需先补一条不读取query标签的完整训练轨迹，仅用于检查比值数值范围。不要从两个首尾loss伪造5步历史。
