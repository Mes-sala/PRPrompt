# 第65轮固定设计：关系蒸馏

来源/适配边界见round65_design_draft.md。CiteSeer两冻结权重，五新支持100100–100104；中心化门控无KD根不变，100步Adam0.01/768参数。关系项先分别L2归一化教师/学生表示，再对158个锚点全部无序节点对计算欧氏距离，各除自己的均值（学生均值参与梯度），Huber均值；权重0.1/1/10。每个权重带正确中心化教师、固定锚点置换、未中心化教师，保留无KD/新KD/旧KD门控根，各原型/k50读出，加Frozen/GP及两直接教师，270条。直接教师不按权重重复计数。

锚点是30支持+128固定随机非支持，只读其特征，采样使用独立seed+650000生成器。无对角距离；均值必须>1e-8，不静默用截断掩盖退化。记录关系损失、梯度范数、均值和锚点/目标SHA；只存158锚点距离向量，不存全图NxN。预检λ0恢复根，独立距离/Huber算子核验，支撑节点包含、无重复锚点、主干冻结和分支生效。超过全部强Prompt及直接教师才扩大确认；同图重复查询边界保持。
