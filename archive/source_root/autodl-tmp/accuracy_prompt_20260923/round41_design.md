# 第41轮固定设计：表示近邻上的预测传播

借鉴[视觉少样本LaplacianShot](https://proceedings.mlr.press/v119/ziko20a/ziko20a.pdf)的邻近样本预测一致性；拟实现带原预测锚定的随机游走传播，而非原论文的界优化器，不引用其收敛证明。这与第11轮原图教师平滑不同：此处用已训练强提示表示构造近邻，处理最终分类概率；初轮先归为传导读出，后续有收益再设计教师/提示训练交互。

每个支持条件训练一次强提示（PubMed/GraphMAE VAT.3，其余沿用原root），同时有Frozen表示作对照。单位化表示分块计算精确10近邻，排除自己；邻居权重softmax(cos/.2)，有向逐行归一化。只读特征，图覆盖全图无标签节点，不仅500查询。拟对比原概率、原图均匀邻居传播alpha.5、表示近邻alpha.5/.9、随机重连alpha.5。随机图保持每行10边及原权重，需排除自边；保留支持标签钳制的开关对照，以区分标签传播与单纯平滑。

初始P0来自当前余弦原型。迭代 $ P^{t+1}=(1-a)P_0+aWP^t $，有钳制时每步支持行替换为真实one-hot，仅支持标签。固定20步，记录末步残差，不按query选择。alpha0恢复原概率（支持行不评分），W行和1、孤立原图节点补自环。查询标签仅在封存预测后评分。不能以传导提升声称新Prompt机制。

固定Cora/PubMed两权重×5新支持seed63100..63104；两种表示各7方案（原读出、原图.5无/有钳制、knn.5无/有钳制、knn.9钳制、随机.5钳制），加4强对照，共360条。84条3步预检带旧root/VAT参考。邻接只存10近邻索引/权重并绑定表示SHA256，按块计算避免全量N平方磁盘缓存。预检应含alpha0、常数概率保持、支持钳制、行和、邻居无自边、原读出恢复。先完成预检再正式运行。

额外来源：[Zhou等Local and Global Consistency第2节](https://proceedings.neurips.cc/paper_files/paper/2003/file/87682805257e619d49b8e0dfdc14affa-Paper.pdf)包含随机游走变体。本轮锚为已有全图原型概率，支持可钳制，非原文只有支持one-hot的Y。随机对照用节点编号置换重连，若产生自边则换为首个未占用非自身节点；保持每行10个不同邻居和同权重，但并非严格保持全图入度。
