# 第77轮：支持原型的加性余弦间隔

来源：[CosFace，CVPR2018](https://arxiv.org/pdf/1801.09414)，核对第3.1节公式4。CVF直接打开403，转arXiv原文；已由检索及原文核对训练正确类余弦减m、整体乘s。人脸识别原文训练分类权重；这里使用支持LOO类原型，原型依赖提示后的支持表示，不等同论文分类器复现。

固定当前CiteSeer早层教师门控提示、768参数、冻结两层GCN、零初始化、Adam0.01与100步；最终只读中心化、原型/k50不变。只在支持LOO训练logit正确类别减m/0.2，m固定0.1/0.3，m0用于恢复。教师与查询logits均不减间隔，查询标签绝不用于设置margin。

对于原正确类概率p，间隔交叉熵对原logit的梯度等于CE梯度乘a=1/(1-p+exp(-m/0.2)*p)。该权重随p上升，范围1至exp(m/0.2)；不能未经核对称其专门强调困难样本。由于恒等关系对所有logits成立，即使原型参与梯度，链式法则仍成立。

每个m带detach平均a×平均CE、固定无自映射置换a×逐样本CE。这些控制分离总体缩放和样本对应，与第53轮Focal、75轮GCE虽均属梯度重加权但函数形状不同。不要求原创，实际是否提升为唯一扩展依据。token正则0.001固定，均值控制同时检验相对正则变化。

预期新支持116100–116104，两权重，带无KD/新KD、随机候选、Frozen/GraphPrompt和Direct。正式矩阵及训练驱动尚未封存。先以零margin、常规和极端logits核验梯度等价，再接入真实GCN，保存损失和梯度轨迹进行独立核对。若不超过强根和匹配对照则停止本配置，不继续任意间隔搜索。
