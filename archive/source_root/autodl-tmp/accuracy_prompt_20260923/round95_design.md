# 第95轮固定设计：教师原型更新阻尼

来源：[Mean Teacher，NIPS2017第2节EMA公式](https://papers.nips.cc/paper/2017/file/68053af2923e00204c3ca7c6a3150cf7-Paper.pdf)，已读取原文。只借用参数状态指数平均思想；原文平均SGD学生权重并加一致性损失，本轮没有这些流程，不称复现。第17轮平均的是训练中的token；本轮修改训练之前的固定原型教师。

令原支持中心为 $ C_0 $，当前教师修正映射为 $ F(C)=.5C_0+.5P(C) $，其中 $ P $ 使用全部非支持节点的温度.05软分配加权中心。拟改 $ C_{t+1}=.5C_t+.5F(C_t) $。这实际是反馈式欠松弛，不是对独立原始轨迹做事后EMA，也不能预设它减少错误。仍保留每轮原支持锚点和原beta=.5。首步等于减小伪中心系数，之后有历史状态，因此必须保存轨迹并区分简单早停。

固定候选damped3（三步），damped6（六步）与plain6（无阻尼六步）作为预算/收敛控制；原plain3为当前根。identity衰减0三步恢复，hold衰减1保持初始中心仅原语。主候选先指定damped3等范数门控，带原幅度及纯幅度控制；其他轨迹均等范数，不扫描衰减。直接教师分数亦比较，防止单靠提示读出归因。

单冻结GCN与同一768token，最终一个教师门控乘token，注入第一层激活前，无末端模型融合。原损失、100步、CiteSeer两权重的Adam/Grafted、中心化+k50保持；第94轮未完成确认时不将其变体混入基线。所有非支持特征可用，不读查询标签。

实现teacher95.py、run_round95_damped.py、reconstruct95.py。固定CiteSeer两权重，148100..104，170正式；148199三步预检38条。dar/dam/daa为三步阻尼原门控/等范数主候选/纯幅度；das六步阻尼、dap六步无阻尼均等范数，dao恢复仅预检。两Direct分别原式和三步阻尼，按支持只计一次。

独立CPU逐类求和与轨迹重建，检查proposal和center及SHA，NumPy重放优化器；三步身份恢复必须预测一致。原语最大误差5.0664e-7，衰减0精确恢复原教师。正式数据源/配置SHA启动前封存，先预检四审计再运行正式。若超过当前匹配强根才固定新20支持确认；同图查询反复使用限制不变。
