# 第78轮：按支持类别分解的提示梯度冲突处理

检索Simple CNAPS时发现第38轮已有完整协方差读出及确认失败，暂不原样重复。改读[Gradient Surgery for Multi-Task Learning，NeurIPS2020](https://papers.neurips.cc/paper_files/paper/2020/file/3fe78a8acf5fda99de95303940a2420c-Paper.pdf)第2.2/2.3节及算法1。论文明确冲突本身不必然有害，还涉及梯度幅度差异与曲率；本任务尚未证实其完整条件，不能把负余弦直接叫作失败机制。

把CiteSeer每类5个支持的LOO CE均值作为一个伪任务，共6组，每组对同一768token求梯度；类原型保持完整可导，不冻结其他类原型。共享参数和GCN位置与当前强根相同，主干冻结，最终读出中心化+k50不变。不是多头或预测融合。

依照算法1，每组工作梯度按固定生成器生成的随机顺序，遇到与原始参考梯度负内积时去掉该投影。参考梯度不被覆盖，最终取均值而非和以保持原CE平均尺度。token正则梯度另加，不参与投影。Adam0.01、100步、零初始化。正则与更新顺序需固定。

对照：同六类梯度直接均值恢复CE；真实类别PCGrad；先把30支持固定随机分成6组各5个但不改变标签的PCGrad；按PCGrad最终范数缩放原均值梯度以检测步长效应（原均值为零时明确记录，不任意除零）。加原强无KD/新KD及Direct。每步6次反传，需报告相对原单反传开销；不宣称计算等价。

先验证独立NumPy投影、无冲突/零/相反梯度，再做真实GCN每类平均梯度恢复检查并记录冲突率/投影次数/范数变化。仅有原语，完整驱动、正式矩阵、真实训练及梯度轨迹审计尚待实现；候选必须超过匹配控制再扩大。预期新支持117100–117104，具体矩阵后续封存。


## 固定执行
