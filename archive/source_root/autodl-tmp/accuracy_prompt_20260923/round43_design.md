# 第43轮固定设计：借鉴跨语言检索的密度校正

重新检索TIM后发现本任务第15轮已测试其损失，不原样重复。新参考[Word Translation Without Parallel Data](https://arxiv.org/pdf/1710.04087)，已读第2.2节式6与K=10设置。CSLS用两侧邻域平均相似度惩罚枢纽点。

将节点表示作为源集合、支持类原型作为候选目标。对每个原型计算其与无支持标签节点的top10平均余弦 $ b_c $。分类分数用 $ (s_{ic}-\alpha b_c)/0.2 $，alpha固定.25/.5；.5对应CSLS除以2后去掉对所有类别共同的节点项。该共同项不改变softmax，除以2的温度选择须明确，这是借鉴而非完整词翻译算法。

先只改强提示最终读出，Cora必须配原提示及已确认的knn.9传播；PubMed带VAT强根及GraphMAE2根。对照包括均值偏置（应无改变）、类间置换偏置、真实偏置；保证同一嵌入和类原型。支持节点从密度池排除，不用查询真值。不预设类均衡，不把不同节点查询密度解释成新图泛化。

代码run_round43_density.py沿用第41轮同一embedding缓存。每个条件8方法：Frozen、GraphPrompt、强提示原读出、csls.25/.5、constant.5、perm.5、knn.9传播；2数据Cora/PubMed×2权重GraphMAE/GraphMAE2×5支持seed67100..67104，共160条开发，100步提示。PubMed/GraphMAE仍带VAT.3，其他根不变。开发dev500，强同权重原读出与传播均作配对参照，增益候选再选20新支持确认。先验证alpha0、常数偏置、类别置换一致性及旧读出恢复。随机对照使用非零循环位移，保证每类偏置都换给另一类。查询真值仅在封存后评分。
