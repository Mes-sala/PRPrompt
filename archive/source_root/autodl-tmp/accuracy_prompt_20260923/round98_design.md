# 第98轮：留一类原型解耦损失

已读[DCL原文第3节与附录A.7](https://arxiv.org/html/2110.06848v3)。借鉴移除分母正项；原文监督分类多数设置略逊CE，此反例纳入预期。本轮监督非参数原型不同于原文图像实例预训练，不声称必然有效或原创。

同一冻结两层GCN与单768参数token；第一层预激活注入，教师、.1门控、100步、.001参数正则、中心化+k50均不变。GraphMAE用Adam.01，GraphMAE2用graftedShampoo.01。无KD。

$dcl$：$L_i=\log\sum_{c\ne y_i}\exp(s_{ic})-s_{iy_i}$。$w_i=1+\exp(s_{iy_i}-\log\sum_{c\ne y_i}\exp(s_{ic}))$，停止梯度；这是稳定计算的$1/(1-p_{iy_i})$。余弦/.2 logits界于[-5,5]，不截断。可能偏重容易支持样本、损害泛化，最终只按准确率判定。

$dcs$：均值权重乘全体CE；$dcp$：每步置换权重后乘逐支持CE。两者用自身当前轨迹权重，非匹配dcl轨迹梯度范数。置换CPU生成器seed+980000预生成。$dci$原CE、$dcw$逐样本逆权重CE只做预检；dcw与dcl梯度恒等但损失值不同。正则不加权。全部标签仅支持标签。

原语使用所有可微类原型共享参数验证dcl/dcw梯度，误差6.66134e-16；均匀置信及极限有界logits通过。预检154199三步33结果，检验dci恢复两根、dcw恢复dcl预测，再做完整几何、更新重放、首末步独立逐支持逐类梯度重建。正式154100..104五组、2权重125结果，Direct只记一次。评分前封存预测，保存全部梯度/权重/置换/首末参数及SHA。五项审计后分析；没有正增益停止扩大，有候选则固定新20组确认。重复同图查询限制不变。
