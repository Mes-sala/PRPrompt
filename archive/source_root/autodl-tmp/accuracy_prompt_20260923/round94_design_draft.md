# 第94轮草案：渐进筛选教师原型修正

来源：[Kumar、Packer与Koller，Self-Paced Learning for Latent Variable Models，NIPS2010](https://ai.stanford.edu/~koller/Papers/Kumar%2Bal:NIPS10.pdf)，已读原文。借鉴先用易样本再逐步引入更多样本的原则；这里以模型软分配作置信代理、预设三个比例，不复现原latent SSVM、自定步长目标或收敛保证。高置信不等于正确。

当前教师在三次原型修正中使用全部非支持节点。拟改为每类分别按该次软分配 $ a_{ic} $ 排序，依次选前25%、50%、100%的非支持节点；仅选择的节点参与该类加权均值，分母亦按同掩码重算。支持原始中心、混合系数.5、分配温度.05不变。各类选择集合允许重叠，这是类条件加权截断，不是伪标签argmax分组。每次从当前中心重算排序；并列按节点索引升序，比例向上取整，至少1点。最终100%不保证恢复旧教师，因为前两次中心改变会影响末次分配。

一个共享冻结GCN、一个768token，新固定教师概率形成第一层激活前门控，不做终端融合。主候选门控范数匹配原温度.1门控；原门控、原幅度新门控及纯幅度控制保留。教师层对照：反序100/50/25、固定50/50/50、随机嵌套25/50/100，后者每类用独立CPU随机排列seed+940000、整轮固定；身份100/100/100用于恢复。随机只是对应数量对照，各自后续概率轨迹不同，不称完全匹配置信分布。直接教师也需比较，避免提示掩盖教师恶化。

区别：第12轮是固定岭教师硬伪标签损失，第20轮是最终门控/KD熵加权，第27轮是原型迭代Sinkhorn；本轮在原型迭代中进行类条件节点筛选。不继续扫描第93轮失败的频率校正。

已实现独立teacher94.py及合成原语check94.py，尚未接入训练驱动、正式矩阵未封存。拟146100..104开发、146199预检（启动前确认）。需保存每步全选择掩码、非支持索引、中心及SHA，独立CPU逐类重建选择与加权中心，再审计GCN/读出与优化器。只用支持标签，查询标签封存后评分。恢复及原语通过不等于数据集收益；后续按匹配强根准确率判定。
