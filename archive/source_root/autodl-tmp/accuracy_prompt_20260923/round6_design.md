# 第六轮：仅使用支持标签的提示强度选择

来源：统计学 [Stone 1974 交叉验证](https://academic.oup.com/jrsssb/article/36/2/111/7027414) 的模型选择原则，结合前轮 PromptKD 条件提示。目标是让每个5-shot任务自行选择提示幅度/蒸馏开关，而不是用查询准确率替任务挑参数。本文不声称交叉验证理论保证适用于相关图节点。

沿用第一层激活前条件 token；固定候选：no-op、gamma1+KD、gamma3+KD、gamma10+KD、gamma3无KD。前轮gamma3在部分权重改善明显，gamma10作为预先列出的较强提示候选，不按查询早停。每类5个支持节点，五折各留出每类1个。每折用其余4个重新生成教师、门控与原型，训练100步；用留出支持节点的交叉熵均值选配置。同分按候选顺序选择。再用完整5-shot支持重训。

折内训练函数只接收内层训练索引与标签；held-out标签仅用于折间评分。held-out特征和图边允许作为无标签传导信息使用。原有训练LOO只用于支持loss，不等价于模型选择的完全重拟合；此处明确实现后者。教师自身也必须重建，不能先用全部支持标签生成再切片。

3数据集×GraphMAE/GraphMAE2×5个新支持种子10100..10104。最终保存8个配对预测（Frozen、GraphPrompt、rawprop2、四种固定token、cv_prompt），共240条最终查询指标。内部每个任务20次提示拟合，共600次折内拟合，单独记账，不能算作独立测试任务。使用已开发过的官方test后半区，只是支持内部选择的新支持验证，非独立全新测试集。

预测落盘与配置选择文件均先于查询评分。保存5折索引、每配置每折loss、选中配置、源码/划分/预测哈希。失败预检与正式实验分离。复用旧数据和权重，只保留最终token和预测，折内模型当场释放，不保存重复大张量。
