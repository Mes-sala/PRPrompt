# 第42轮草案：将近邻一致性放入提示训练

延续[视觉LaplacianShot的邻域一致性思想](https://proceedings.mlr.press/v119/ziko20a/ziko20a.pdf)，从第41轮传导读出走向训练内部条件提示。不是原文算法复现，不宣称新机制原创。当前只是设计草案，尚未运行。

第一阶段照旧训练100步强条件token（Cora平滑岭后层，PubMed/GraphMAE带VAT、GraphMAE2原型修正）。用第一阶段表示固定10近邻权重，图在第二阶段不更新。第二阶段继续100步，仅更新同一提示参数；原CE、教师KD、已有VAT保持，增加邻接上预测概率差的平方惩罚。概率来自当前支持原型，不能使用query标签。避免修改checkpoint权重或在最终读出额外传播，以辨别训练效果。

对照必须包括第一阶段100步结果、相同总步数200步但不加新损失、固定近邻损失、相同度数/权重随机重连损失；损失权重先固定1及10的少量两档。近邻生成从第一阶段标签适配后的表示构成，所以它不是标签无关的外部结构；应保存第一阶段表示/图哈希与参数来源。随机对照不能只比未继续训练的100步方案。另保留第41轮纯传播读出，以确定训练是否值得替换更简单的推理。

需在实现前冻结方法数/seed；验证第二阶段零新损失恢复匹配继续训练、主干冻结、邻接不变、概率一致时正则为零、真实/随机图边权总量一致。只选择超过200步与随机图的结果确认，不把额外训练步数归为邻域收益。
