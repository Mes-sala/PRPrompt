# 第46轮草案：检索式邻居表示聚合

参考并已读[Fine-tuning CNN Image Retrieval with No Human Annotation](https://arxiv.org/pdf/1711.02512)查询扩展部分：邻居权重由余弦相似度的幂决定。这里借用alpha=3的加权思想，适配图节点的有符号嵌入，负相似度截0；不复现原文CNN训练或完整检索系统。

强提示训练保持原100步。取归一化最终表示 $ z_i $，固定10NN或50NN，加入自身权重1，计算 $ \tilde z_i=\mathrm{normalize}(z_i+\sum_{j\in N_i}\max(0,z_i^Tz_j)^3 z_j) $，一次同步更新，所有节点包括支持均聚合，再由聚合后的支持表示重算类原型。如此与已有“原原型预测后在概率上传播”不同，不能把聚合当提示新增参数。需明确所有图节点传导、无查询标签。

至少带原提示、原10NN概率传播、相同k的均匀AQE、相同邻居权重随机置换节点、原图一次特征平滑。先Cora两权重，若有效再扩PubMed。原图比较不能独立证明表示近邻更好，须披露degree/weight差异。固定聚合前图并记录哈希，不反复迭代选择邻居。只保存稀疏邻接，避免N平方文件。

预检：仅自身恢复、零邻居权重恢复、参数未改、支持原型确实重算、同步而非顺序更新、符号/有限值检查、归一化与行权规范化等价。当前草案未实现未运行，方法数与seed需在实施前冻结。
