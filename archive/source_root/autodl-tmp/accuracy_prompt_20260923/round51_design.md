# 第51轮固定设计：支持缓存与强预测的终端组合

重新检索并阅读[Tip-Adapter ECCV2022](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136950487.pdf)第3.1节式4，其支持缓存预测与已有分类器做残差组合。本轮借用检索缓存和组合思想；使用图提示表示，没有CLIP文本分支。第29轮仅在异配图原始特征缓存上构造训练教师/门控，本次是训练完成后的提示表示缓存与最终概率组合，不重复该接入方式。

同一强提示训练完成后，归一化节点表示查询同一支持集key，以支持one-hot为value，指数余弦beta10/30；每类均值再行归一为缓存概率。支持节点自身项移除并按剩余每类数量补偿（不利用自匹配伪装留一正确率）。Cora强基础为k50概率传播，PubMed如后续扩展则为未传播VAT/ref50强根。最终混合概率=(1−lambda)强预测+lambda缓存概率，lambda固定.25/.5。该改动属于终端分数融合，不是新Prompt训练或主干内部机制；用户当前目标允许按准确率保留。

带缓存单独、强预测单独、原原型读出、相同混合强度的支持标签置换缓存，必要时强原始教师预测作为参照。没有按query拟合组合系数，支持标签只来自5shot。先Cora两权重5支持开发，启动前固定方法矩阵与seed。若超过强预测和纯缓存再新20支持确认；避免只报相对Frozen。可补同概率温度的原型核对，避免纯校准效果被误称互补机制。

预检：beta0在计数校正后均匀，lambda0精确恢复、lambda1等于缓存、支持自项0、概率行和1/有限、类别置换等变、原训练输出/图绑定不变。固定Cora两权重×seed77100..77104×14方法=140条dev500；见round51_config.json。14方法为Frozen/GP/原原型/强传播、beta10/30缓存单独、两beta×两lambda真缓存混合和相同四组置换混合。原100步提示不变；每组缓存/强传播只计算一次，避免覆盖同名图。
