# 第97轮固定设计：有效提示矩阵DropConnect

来源：[Wan等，ICML2013 DropConnect，第2.2和3节](https://proceedings.mlr.press/v28/wan13.pdf)，已读原文。借鉴训练时屏蔽连接。原文强调每样本独立掩码并使用近似分布推断；这里对整图共享每步一个提示连接掩码，最终用完整矩阵单次推断，不复现其每样本掩码/高斯近似或模型集成，不能引用其泛化保证。

保持原教师门控 $ B $，提示有效矩阵 $ U=\tanh T $。训练改 $ U'=M\odot U/.9 $，M元素保留概率固定.9，按步重采样；最终恢复U。一个冻结GCN和768token，仍第一层激活前注入 $ 10BU'\odot\sigma_u $，其余主干不做dropout。此处掩码放在tanh之后，条件于固定T时 $ E[U']=U $，但非线性GCN和训练梯度不因此无偏；最终完整推断也不等于精确集成。

主候选element；channel为整列同掩码、跨类共享的结构控制；gain为仅训练时乘 $ 1/\sqrt{.9} $ 的确定性控制，匹配元素屏蔽的有效矩阵期望平方范数，不能称匹配每步真实隐藏扰动；identity恢复根。三者最终均用完整U。对照原tr1/gsh、Direct/Frozen/GraphPrompt。第12轮改变提示后整个隐藏表示，本轮只改变提示分支的有效连接；没有新增伪标签损失。

CPU独立seed+970000预生成100步布尔掩码，保存及SHA，与训练其他随机流分离。保持原支持LOO CE+.001原T均方；正则作用未屏蔽T，不能声称所有被屏蔽坐标总梯度为零。需保存每步原梯度并NumPy重放优化器，另保存首末步token/掩码重建前向和梯度，防止仅检查随机掩码存在却未参与训练。最终独立CPU完整token重建读出；所有query标签封存后评分。

固定实现drop97.py、run_round97_drop.py。CiteSeer两权重，152100..104开发125条，152199三步预检29条。dce元素屏蔽为主候选、dcc通道屏蔽、dcg仅训练gain，dci身份恢复仅预检；原tr1/gsh、Direct/Frozen/GraphPrompt保留。原语已通过，枚举期望误差0。

保存100步布尔掩码、每步梯度与首末步更新前token快照及SHA。audit97_masks.py用CPU生成随机流，独立逐支持/逐类计算留一原型CE+.001原T均方，重建首末步梯度（绝对3e-5/相对2e-4启动前固定）；另NumPy全程重放优化器、CPU完整token重建最终GCN与读出。身份恢复预测必须一致。无掩码eval是固定流程，不按query选择推断方式。

源/configSHA启动前封存，预检五项审计通过才正式；只有超过当前匹配强根的固定候选继续20支持确认，同图重复查询限制保持。
