# R125草案：退火梯度噪声

来源：[Neelakantan等，Adding Gradient Noise Improves Learning for Very Deep Networks](https://arxiv.org/pdf/1511.06807)，2015预印本，第3节式1。原文对每步梯度加入高斯扰动，方差eta/(1+t)^gamma，gamma=.55；也报告浅层/更好初始化下不一定获益。当前只有两层冻结GCN与768参数Prompt，不能套用“深网逃离坏初始化”解释。

本地拟采用相对尺度适配：首步干净梯度RMS为s0，标准差sigma_t=c*s0/(1+t)^.275（t从0计），c固定.1/.3。此处eta=(c*s0)^2，与原文绝对eta网格不同，不称原实验复现。s0只在首步确定，不依赖查询标签；若s0=0，则当前适配不加噪声，须记录不能声称打破零梯度。注入在反向传播后、Adam/gsh状态更新前。

控制：退火原式、梯度范数匹配、仅梯度幅度、恒定标准差新噪声、固定一份随机向量随时间退火、强度0恒等。梯度幅度控制只保持当步方向，不等价于最终参数更新方向不变（自适应矩状态不同）。CPU独立Generator seed+125001，不修改全局随机流；各分支共享可复现底层标准正态序列，但更新后各自真实梯度流不同。保存每步clean/noisy/used梯度及随机流/尺度，审计先独立核对噪声再重放优化器。
