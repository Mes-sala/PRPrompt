# 五组方案跨数据集与全部兼容预训练 checkpoint 网格

## 目标与范围

在51542服务器逐一核查11个已有图数据集的预训练权重，为五组已保留方案建立跨数据集效果矩阵。使用现有ProG环境，不训练新的预训练模型，不改变历史方案源文件。

五组方案现有算子均使用单图节点支持集与节点分类读出。8个节点数据集进入执行检查：Cora、CiteSeer、PubMed、Computers、Photo、Actor、Chameleon、Cornell。MUTAG、PROTEINS、ENZYMES属于图分类，标记为unsupported_task；需要独立的图级适配方案，不能把节点随机分组冒充图分类验证。

按“数据集、预训练方法、实际SHA256”去重，同名不同权重作为不同网格单元，CiteSeer历史版本保留。GCN采用两层128维、严格state_dict加载、冻结和eval。MultiGprompt的原生架构不匹配，标记unsupported_architecture，不以strict=False、随机初始化或名称替换冒充运行成功。额外修复/适配的图级encoder仍保留在服务器，但不进入节点方法的效果分母。

主线02不依赖预训练权重：每个数据集、seed只计算一次，所有checkpoint比较引用同一直接方法结果，不能把重复引用当成独立实验。

## 固定实验协议

- 每类5个支持节点，种子24092400—24092404，训练100步，五组使用完全相同的支持集和查询集。
- Planetoid使用官方train池与完整test查询集；Actor、Chameleon、Cornell使用官方fold0。Amazon固定20260924种子，每类20节点为支持候选池，其他节点为查询集。
- 支持候选池必须每类至少5节点；不满足时单独记录数据失败，不悄悄改变shot数。查询集不参与参数选择、早停和方案选择。
- Planetoid和Amazon输入NormalizeFeatures；异配图遵循已有Actor路线使用原始主干输入。所有方法在同一个数据集上使用相同输入；属性教师使用NormalizeFeatures。
- 这是首轮固定配方的回顾性网格：部分数据已被历史实验使用，不宣称全新独立确认。5个seed仅是首轮估计，不能声称统计显著或跨随机图独立泛化。
- 参数冻结、同源checkpoint SHA、数据/切分SHA、源文件SHA、预测封存SHA逐行记录。算子仅接收支持标签；先保存预测，再读取查询标签计算准确率。

## 五条路线和对照

| 路线 | 本轮固定算子 | 匹配对照 |
|---|---|---|
| 主线01 | late条件Prompt，CE权重2，k=50概率传播；同时保留普通均值读出 | CE权重1、冻结主干及同样概率传播 |
| 主线02 | 两跳归一化属性中心化，3次soft原型修正，beta=.5，温度.05 | 未中心化修正教师、两跳属性原型 |
| 主线03 | 早期Prompt，锐化门控T=.1，无KD，输出中心化；Adam与Adam步长匹配Shampoo两个分支；普通/k50读出 | 两分支直接配对，冻结主干、GraphPrompt及主线02 |
| 主线04 | 修正教师beta=.5、gamma=3、KD条件Prompt，VAT epsilon=.3 | 完全相同Prompt不加VAT；两者均保留，不按数据集挑最好参数 |
| 主线05 | 固定self-loop100、self-only、self-only中心化、diag10几何校正 | 原图冻结主干、未中心化self-only、GraphPrompt |

每个可用checkpoint包含17个固定方法/对照。直接教师每数据集包含3种方法，不重复加载checkpoint。仅使用五组核心已保留算子，不扩张新超参数搜索。

## 执行与汇总

先执行2步小规模工程检查，只检验加载、shape、冻结、源文件、预测封存及算子有效性，不用于效果结论。正式网格使用独立results目录与100步；已完成结果必须验证配置、切分和预测SHA后才能续跑。

正式任务按节点数从小到大、数据集、预训练方法及SHA固定排序，不按准确率排序。单个任务失败后保留失败栈并继续其他组合，不以缺失单元计算完整覆盖率。磁盘少于5GB停止启动新任务。记录运行中、完成、失败、unsupported_task、unsupported_architecture，汇总paired delta并同时给出每个seed原始结果；只有结果数达到plan.json且无失败时才报告完成。

本地目录含不可改写的历史sources副本和哈希表。最终plan.json、results、summary.json、进展.md及运行日志形成可审计记录。长任务需后台可恢复运行，并持续同步进展；checkpoint不移动、不覆盖、不删除。
