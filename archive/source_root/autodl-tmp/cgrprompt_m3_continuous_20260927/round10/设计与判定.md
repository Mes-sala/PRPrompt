# 第十轮：保留不经过图传播的教师分支

第六轮融合两个经过相同图传播的预测，额外确认收益很小。当前CiteSeer强教师却是不传播的中心化教师，说明传播可能平滑掉有用的局部分类信息。因此本轮把未经传播的教师分类作为独立支路，与M3-LC的图传播支路融合；检验两种尺度是否互补，而非继续扩大第六轮权重。

四候选：中心化/未中心化教师不传播softmax概率，与校准Prompt传播概率各占0.5做算术平均或归一化几何平均。完全固定配比，不用查询标签选择。两种教师也以各自固定传播作为主支路，配上相同不传播教师支路形成teacher-only对照；保留所有固定及不传播单教师。由于一个支路不传播，这不再等价于两个初始化先融合再共同传播，但仍是已知末端集成，不声称图内部Prompt创新。

其他对照与第六轮相同：M3-T、M3-LC、原M3和partner概率节点对应置乱。教师自身的“传播+不传播”并非恒等，不能沿用第六轮自身融合的恒等断言。zero接口还原原M3-T。所有分数来自同一支持抽样与冻结编码器，先保存预测再看查询指标。
