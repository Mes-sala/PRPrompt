# 第十九轮：三次拟合的M3-E2新抽样确认

## 来源与固定结构

第十八轮CiteSeer纯集成在20次新支持抽样中平均超过M3-LC 0.32pp，但部署需6次拟合。其后在该批缓存上的事后成本诊断，K=2个留出模型平均+0.335pp，相对原六次版本+0.015pp；固定规则筛选了最小合格K=2。此次选择已使用开发查询，不作为新的确认结果。

现冻结：完整5shot模型LC概率占0.5，两个4shot留出模型LC概率的均值占0.5。折索引固定为seed mod 5和(seed+2) mod 5；不按预测效果选折，不改权重，无OOF残差校正。既有M1/M2训练、教师图与LC读出保持一致。每种教师都用其固定传播概率作为主支路及相同两个留出教师预测作对照，另保留两种固定与不传播强教师。

部署候选只需完整模型和指定两折，共3次Prompt拟合。本轮为严格配对比较，同时训练剩余三折以产生六次版本参考，因此实验每个支持抽样实际仍训练6次。报告必须区分候选所需拟合数与验证实际总拟合数，不能把测得的实验耗时直接称为三次版本耗时。

保留原M3/M3-T/M3-LC、六次集成版本、两种教师同操作与六次集成、不增加模型的端点，以及留出预测的节点对应置乱。zero实际还原M3-LC。保存全部折概率、OOF缓存及哈希以延续折身份核验；OOF缓存仅作工程核对，不用于候选校正。独立重算指定两折集成和六折参考，核对全部五指标、支持/查询身份和冻结骨干。
