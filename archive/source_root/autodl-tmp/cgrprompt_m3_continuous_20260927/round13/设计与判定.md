# 第十三轮待实现：将标签图先验与分类分数分别读取

第十二轮反向远邻传播未过筛查，停止该固定算子。本轮改换信号组合位置：先独立传播支持标签得到图先验H，再与校准分类器分数或其传播结果做乘性读取。

H初始化为均匀分布，支持位置钳制为真实独热标签；在当前教师属性50NN上做固定100次无重启传播，每次钳制支持标签。称为“固定100步标签传播”，不假称已收敛的精确调和解。H只使用支持标签，与分类器共享信息，因此不能假设两个分支统计独立或声称贝叶斯最优。

四候选：图先验H的指数beta=0.5/1，分别乘以（1）局部温度校准后的初始分类概率，或（2）M3-LC最终概率，最后归一化。两种直接教师同样使用各自初始/固定传播概率与H相乘。保留H单独预测、固定/不传播教师、M3-T/M3-LC；额外保存等权算术融合，区分分支提取和乘性规则的效果。H与节点对应置乱为信息控制；beta=0应还原相应初始或传播分支，做实际数值检查。

已知机制归类为标签传播加概率专家乘积，不声称原语创新。正式运行前补齐算子实现、来源说明与smoke。四个边预测设置，不新增DGI；100步原Prompt训练。开发seed26094000—26094009，平均改善M3-LC≥0.2pp且至少3组均值为正、相对同结构最强教师均值差距为正则进26094020—26094039确认。H单独预测或算术控制若更强，必须明确披露；不将其包装为Prompt收益。

实现前补充：标签传播机制参考Zhu等的图半监督研究；乘性组合属于已知概率专家乘积。本轮不采用其学习算法，也不声称固定100步传播等于精确调和解。工程smoke通过后按上述冻结设置运行。前十二轮封存实验不重复启动。
