# 第十二轮：相似邻居传播与不相似节点反向信息

第十一轮将M3纳入适配损失未过筛查，平均仅+0.0275pp，停止该固定训练目标。本轮恢复原100步训练，测试不同传播算子：教师近邻提供正向信息，属性最不相似的节点提供反向分类信息，避免只累积平滑信号。

W+为当前教师属性50近邻，W−为相同中心化两跳属性余弦最小的50个非自身节点，按负余弦/0.2做softmax加权。两图均只使用属性、不使用查询标签。Prompt初始概率采用localtemp；两种教师保持原初始概率。

每步 $ Q=0.1P_0+0.9W_+P-\beta(W_-P-1/C) $，随后clip到正数、逐行归一化，并固定支持独热标签，共20步。两个候选beta=0.05/0.1。反向项以均匀分布为中心，行和在精确算术下仍为1；clip处理可能的负分量。beta=0实际运行同一循环，应恢复M3-LC（教师恢复固定传播），以输出误差验证，而非直接返回基线。

额外控制：attract10将反向项符号翻转，perm10置乱W−与节点的对应；还保存每候选对应置乱输出。两种教师接受完全相同算子，保留所有原强教师。若反向关系并不代表类别差异，方法可能放大错误，必须用配对结果判断，不因输出更尖锐而认定有效。

参考[FAGCN, AAAI2021](https://arxiv.org/abs/2101.00797)对低频与高频信号的研究；本固定远邻反向概率算子不是其实现，不声称频率混合或有符号传播原创。
