# 条件性结构验证：尊重适用范围，不强求跨图统一

用户已明确不要求一个Prompt适用于所有图和预训练。本阶段保留先前统一筛查失败的事实，同时检验已观察到的、预先限定数据集的新假设。它不是改写原3/4门槛，也不把后验条件选择说成从未看过结果。

开发依据：第七轮OOF误差校正的四个候选在Cora两设置均改善、在CiteSeer均退化；第九轮proto_decor在CiteSeer两设置均改善、在Cora均退化。选择Cora的oof50l01（两设置平均改善M3-LC约0.365pp）和CiteSeer的proto_decor（约0.285pp）做条件性新支持抽样确认。

Cora沿用第七轮代码、参数与额外五折训练，20seed为26093420—26093439；CiteSeer沿用第九轮代码、参数，20seed为26093620—26093639。每种预训练分别配对，保留M3-LC/M3-T、原M3、两种固定教师、不传播教师和同结构教师。Cora总40包=240次Prompt拟合；CiteSeer40包=40次拟合。

仅在其已声明的数据集范围评价可重复性：平均优于M3-LC至少0.2pp且两种预训练均值均为正，才保留为该数据集的效果候选；逐设置配对区间另外报告。超过强教师要求同时比较原固定教师、不传播教师、同结构教师，不能以损害教师造成的差距作为成功。不会把Cora与CiteSeer的两个结构拼成未经验证的自动选择器；数据集身份不能伪装为可泛化选择机制。

原轮次开发结果已经参与假设形成。新的支持抽样为同图条件确认，不是跨数据集泛化验证。假设确认失败则停止该条件路线，不继续扩大相同超参数族。
