# 第二轮：改变传播状态与传播深度

2026-09-27运行前设计。用户要求持续尝试结构，单条路线的停止不等于停止整个研究。上一轮残差校正与类别边权加权停止；本轮不继续扩大其强度网格。

范围仍为Cora/CiteSeer × Edgepred_Gprompt/Edgepred_GPPT，不新增DGI。Prompt训练100步、固定教师属性50近邻及其边权保持不变，改变传递的状态或保留本地预测的方式。所有改动同样用于两种直接教师，保留各自固定传播强基线。无新增可学习参数。

1. multiscale：以原传播递推得到第1、5、20步概率，等权平均。检验单一深度是否损失不同尺度的有用信息。
2. adaptive：节点传播率 $ \alpha_i=0.5+0.45H(P_i)/\log C $，由初始概率熵确定；高置信节点保留更多本地分数，不确定节点依赖邻域。传播20步，支持标签固定。比较打乱节点传播率。
3. logit：用标准化的中心化logit作为传播状态，避免先softmax压缩判别差异。每行分数减均值除标准差（下限1e-6）；支持状态为 $ \sqrt C(Y-1/C) $；保持0.9传播、20步，最终softmax。支持状态幅度固定，不按查询指标选择。
4. balanced：先做固定M3-T，再按全体节点预测类别质量平方根反比校正：$ P'_{ic}\propto P_{ic}/\sqrt{\overline P_c} $。使用未标注节点统计但不用其标签；这会引入均衡倾向，可能不适合真实类别先验。比较打乱类别校正系数。

对multiscale的置乱对照打乱非支持初始分数；logit同样打乱非支持分数，仅作信息必要性诊断，不能据此证明新结构优于原M3-T。所有zero检查直接还原固定M3-T；另保存初始全节点分数供后续明确标注的开发重放，避免重复训练。

先2步smoke，后开发seed26092900—26092909，各设置10次。结构函数不接收查询标签。保存预测与哈希后计算指标，保存冻结断言与来源哈希。候选若四设置平均改善M3-T≥0.2pp且至少3组均值改善，则冻结候选，进入新20seed确认（26092920—26092939）；多个通过者按相对同结构两种教师中较强者的平均差距排序。开发筛查使用查询结果作研究选择，不能称为支持选参。未通过的结构停止，下一轮须改变机制而非隐瞒退化或扩大当前网格。

借鉴来源：[PPNP/APPNP](https://arxiv.org/abs/1810.05997)分离预测与传播；[GAMLP](https://arxiv.org/abs/2206.04355)研究多尺度与节点自适应利用。本轮是固定小算子的效果验证，不是这两篇论文官方实现复现，也不声称上述原语首创。
