# 第四轮：教师图的几何和互近邻可靠性

2026-09-27。在读取第三轮效果前冻结此独立机制。已知当前教师属性50近邻采用有向、按行归一化的中心化余弦图。即使图源不变，单向近邻、公共属性方向和局部密度仍可能影响传播。上一轮类别预测加权失败，故本轮不用类别预测修改边权。

四个候选：rawgraph由未中心化两跳属性构建相同温度0.2、50NN图；dualgraph将当前中心化图与rawgraph各占0.5；symmetric将当前邻接W与转置平均再按行归一化；mutual仅保留双向都存在的边，边权取两方向乘积平方根后归一化，孤立行退回当前W。不改变传播方程、Prompt训练、初始分数。两种直接教师同样接受每种图，同时保留原固定图教师。

这是常见kNN图构建操作的效果验证，不声称互近邻或对称化原创。设计依据为已有M3-T图源替换有效，而分类一致性加权失败；本轮检验无需预测类别的关系可靠性处理。

检查行和为1、非负、有限，zero直接返回原M3-T。置乱控制用同一随机节点置换同时置换新图的行和列，以破坏图与节点分数的对应；保留分数和支持标签。记录每个图的哈希、非零边数、孤立回退行数，所有候选均不读取查询标签。
