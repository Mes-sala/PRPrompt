# 第九轮：消除类别原型之间的干扰

第八轮聚合适配特征未带来整体改进。当前余弦原型头仅计算节点与各类别中心相似度，没有显式处理类别中心之间的相关性。本轮改变M3分类读出，测试支持集闭式判别头，骨干及Prompt训练仍不变。

单位行表示Z，支持表示S与独热Y。三个ridge候选 $ L=ZS^T(SS^T+\lambda I)^{-1}(Y-1/C)/0.2 $，固定lambda=0.01、0.1、1。第四候选proto_decor：先形成归一化支持类别中心B，使用 $ L=ZB^T(BB^T+I)^{-1}/0.2 $。ridge利用各支持样本，proto_decor仅校正类别中心间的相关性。

Prompt的新分数经冻结localtemp进入原教师图传播；两种直接教师以各自属性表示计算完全相同的闭式头，后接原固定传播。保留原固定/不传播教师及M3-T/M3-LC，避免用一个不合适的替代头削弱教师。置乱对照打乱支持标签对应，保持类别计数；proto_decor对照打乱中心对应类别。所有矩阵求解仅使用支持标签；节点特征仍属于原transductive协议。零接口返回原M3-T，检查解的有限性及线性系统相对残差。

这是已知核岭回归及原型相关性校正的效果实验，不将闭式线性头声称为新Prompt原语。分类头改变属于M3读出结构变化，需明确额外拟合的头，不说“没有任何新参数”：ridge包含支持标签决定的闭式系数，无梯度训练。

四个边预测设置，100步Prompt；开发seed26093600—26093609。平均改善M3-LC≥0.2pp且至少3/4改善、相对同结构教师均值差距为正才进入26093620—26093639的20seed确认。先2步smoke，完整保存全部结果。若失败，记录各数据集差异，不扩大lambda网格。
