# 第六轮：校准Prompt与教师读出的互补性

第五轮localtemp已完成20seed确认，四设置平均改善固定M3-T 0.23625pp，Cora两设置区间均正；但Cora/GPPT尚未超过强教师，CiteSeer与不传播中心化教师仍接近。这轮保留localtemp，检验其是否与直接教师存在可利用的互补错误。

四个固定候选：校准Prompt传播概率与中心化/未中心化教师固定传播概率分别等权算术平均（arith_center、arith_unc）或归一化几何平均（geom_center、geom_unc）。没有学习融合权重，不扩大配比网格。额外输出校准Prompt、不传播教师、固定传播教师，以及只有两种教师的同形式融合。不能仅和较弱单教师比，也不能将融合本身称为新Prompt原语。

对于固定图和相同支持标签钳制，概率算术融合再传播与分别传播后算术融合等价（有限精度误差除外）。本轮明确按末端集成研究，不能包装为图内部交互或结构创新。几何池为已知概率集成原语。若它有用，只能证明互补性和效果，不能证明原创性。

source=Prompt使用已冻结localtemp作为主支路；source=两种教师使用各自固定传播。每种融合的partner由候选名指定为中心化或未中心化教师；教师与自身的融合退化为恒等，另一种得到教师-教师融合。因此同时保存所有source候选，比较两教师集合中的最强者。置乱对照打乱partner非支持节点概率行，zero返回未校准固定M3-T以检查原接口；另显式检查教师与自身融合恢复相应教师固定读出。结构函数只接收分数、图和支持标签。

范围仍为四个边预测主设置。开发seed26093300—26093309，每组10次，100步Prompt。筛查要求平均优于同轮localtemp至少0.2pp、至少3/4均值为正，且相对同形式教师-only融合的四设置平均差距为正。通过后选匹配教师差距最大者，冻结到26093320—26093339共20seed确认。先2步smoke。全部未通过则终止固定末端融合路线，保留localtemp，继续不同机制。
