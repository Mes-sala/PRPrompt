# 基础 M3 初始概率软化：首轮结论

2026-09-28，迁移和首轮配对实验均已完成。

## 结果

下表是相同Prompt、相同适配表示近邻图、相同传播规则下，仅提高初始概率温度的Accuracy。每组20个支持抽样，均值单位为%，括号为相对原始温度的百分点变化。

|设置|原始T=0.2|T=0.4|T=0.8|
|---|---:|---:|---:|
|Cora / Edgepred_Gprompt|74.205|74.210（+0.005）|74.150（−0.055）|
|CiteSeer / Edgepred_Gprompt|67.765|67.795（+0.030）|67.710（−0.055）|
|Cora / Edgepred_GPPT|71.620|71.565（−0.055）|71.435（−0.185）|
|CiteSeer / Edgepred_GPPT|65.280|65.280（0.000）|65.230（−0.050）|

提高到0.4没有任何一组出现全正的95%配对区间；Cora / GPPT出现全负区间。提高到0.8四组均值均下降，Cora / GPPT区间全负。当前证据不支持把“单独软化初始概率”替换为新M3，不启动新支持抽样确认，也不据此扩大温度搜索。此结论限于该改动和当前四组，不意味着所有软化结构都无效。

不传播对照的Accuracy分别为73.810、67.135、70.945、64.750，原始M3相对它仍提高0.395、0.630、0.675、0.530 pp。单独软化无稳定增益与基础M3本身有增量是两个不同结论。

四个设置逐抽样的原始M3 Accuracy均与历史core补验一致。Cora / GPPT的71.620来自core重放，与统一协议主表的71.615分属不同批次，继续分别记录。
