\subsection{训练与预测细节}
正文描述实际生效的前向计算。Adam 使用 $\beta_1=0.9$、$\beta_2=0.999$、$\epsilon=10^{-8}$，学习率为 0.01，权重衰减为 0。提示正则为提示矩阵元素平方的均值乘以 $10^{-3}$，与优化器权重衰减不同。逐通道尺度使用分母为 $n-1$ 的样本标准差；欧氏归一化采用实现中的 $10^{-12}$ 范数下界。没有蒸馏或额外测试标签目标；重叠测试节点作为支持节点参与监督。

对于支持损失，令 $\bar z_i=\norm{Z_i}$，$m_c=\sum_{j\in S_c}\bar z_j$。当 $\min_c k_c>1$ 时，支持节点 $i$ 的训练原型为
\begin{equation}
\begin{aligned}
p_c^{(-i)}&=\norm{\frac{m_c-\mathbb I[y_i=c]\bar z_i}{k_c-\mathbb I[y_i=c]}},\\
\ell_{ic}&=\bar z_i^\top p_c^{(-i)}/0.2.
\end{aligned}
\label{eq:loo}
\end{equation}
$\min_c k_c=1$ 时，以包含自身的类别原型 $\norm{m_c/k_c}$ 替代 $p_c^{(-i)}$。预测时定义
\begin{equation}
\begin{aligned}
z_i^*&=\norm{Z_i-\frac1n\sum_{j\in V}Z_j},\\
p_c^*&=\norm{\frac1{k_c}\sum_{i\in S_c}z_i^*},\\
\widehat y_i&=\arg\max_c (z_i^*)^\top p_c^*.
\end{aligned}
\label{eq:predict}
\end{equation}
将余弦 logits 除以 0.2 后取 softmax，得到五项指标使用的概率分数。训练时不使用预测阶段的输出中心化。读出是固定实现选择，不是本文的实验比较因素。

\paragraph{计算流程。}
给定图、固定预训练权重及支持标签：
\begin{enumerate}
\item 归一化邻接，计算式~\eqref{eq:attributes} 及第一层预激活表示。
\item 依式~\eqref{eq:anchor} 初始化支持原型，执行式~\eqref{eq:assignment}--\eqref{eq:refinement} 三轮。
\item 依式~\eqref{eq:routing} 计算固定路由；共享提示消融则将其替换为 $B_{ic}=1/C$。
\item 初始化 $P=0$ 并缓存隐藏通道尺度，固定编码器与路由。
\item 重复 100 步：运行提示编码器，构造支持 logits，依式~\eqref{eq:loss} 更新 $P$。
\item 依式~\eqref{eq:predict} 计算最终原型分数，封存预测后再使用查询标签评分。
\end{enumerate}

\subsection{基线拟合与随机种子}
任务seed为30093000至30093019，训练seed为0、1、2。每个任务先生成测试集，再独立生成支持候选池，按类取前 $k$ 个并打乱支持顺序。各方法的任务索引相同，1/3/5-shot支持集合嵌套。候选不足时保留实际 $k_c<k$，不补抽样。冻结预训练保留三个seed槽位以对齐记录，不能解释为三次独立拟合。

本地全量微调使用支持交叉熵与任务读出，最小类别支持数为1时的固定参数为学习率 0.01、权重衰减 0.0001。实际最小类别支持数大于1时，使用 $\min(3,\min_c k_c)$ 个支持内折，各留出每类一个节点，按留出支持交叉熵均值选择四种候选配置，再在完整支持集上重新拟合；不使用额外验证标签预算。该本地协议控制标注信息与最终训练步数，但总选参计算量或读出参数化并不完全一致，也不适用于导入的文献基线。

\subsection{同一条件内的统计}
固定数据集、shot 数、预训练权重和方法，以 $a_{st}$ 表示支持 seed $s$、训练 seed $t$ 的某项指标，计算
\begin{equation}
\begin{aligned}
\bar a_s&=\frac13\sum_{t=1}^{3}a_{st},\qquad
\widehat a=\frac1{20}\sum_{s=1}^{20}\bar a_s,\\
\widehat\sigma&=\sqrt{\frac1{19}\sum_{s=1}^{20}(\bar a_s-\widehat a)^2}.
\end{aligned}
\label{eq:stats}
\end{equation}
本地单元报告 $100\widehat a\pm100\widehat\sigma$，不是标准误。本地配对比较对 $d_s=\bar a_s^{\mathrm{PRPrompt}}-\bar a_s^{\mathrm{reference}}$ 按任务抽样块重采样，以 10,000 次重采样均值的百分位点构成 95\% 区间，本轮按该规则重新计算全部区间。文献单元保留来源中的五次抽样均值与标准差，不套用式~\eqref{eq:stats}。不跨数据集、shot、方法或数据来源计算指标均值与平均效应。

数据包保留 Accuracy、Macro-F1、Micro-F1、宏平均 one-vs-rest ROC-AUC 和宏平均 AP。单标签多分类下 Micro-F1 与 Accuracy 相同，此处为完整性一并列出。不同任务重新抽取支持与测试集；区间反映固定图条件下任务抽样与训练波动，并非独立图样本的不确定性。

\subsection{环境、来源与数值复核}
复用ProG环境及既有图／权重，使用PyTorch 2.11.0+cu130。逐单元记录拟合时间；并发任务的墙钟时间不用于推断方法效率优势。

本轮八个数据集共完成5760个正式单元，另有96个两步smoke单元，不计入正式统计。本地核验覆盖任务数、有限指标、配对支持／测试索引以及均值、标准差和bootstrap区间重算。保存表示读出采用 $2\times10^{-6}$ 容差；旧滤波器行和的严格浮点断言改为误差记录，运算未改。未重复执行逐文件哈希扫描或全新CUDA前向逐位审计，也不将旧版数值审计作为本轮证据。

外部 Accuracy 转录自 \citet{mtg2026} 表 4--6（arXiv:2606.03290v1 的 PDF 第 37--38 页），记录保留表号、页码、原始小数、来源链接与 PDF 哈希。排除 MTG 后，共记录 147 个节点分类单元，论文使用其中三个数据集的 63 个单元。来源表结合 ProG 结果与作者复现，未逐单元标注来源归属或选中的预训练策略。导入记录不含原始预测，因此不计算外部配对检验。历史本地提示结果保留归档，不用于填补文献缺失指标。

代码与结果见 \url{https://github.com/Mes-sala/PRPrompt}，运行脚本位于 \texttt{experiments/prog\_split\_20261002}。本轮新增的是原ProG划分下的适配复算及其统计，没有重新预训练。前七个数据集沿用原始Edgepred\_Gprompt checkpoint，预训练seed未知；ogbn-arxiv沿用此前全图边预测checkpoint，预训练seed为42。权重、图快照与模型状态留在服务器，本地只保留代码、预测结果、划分、表格与文档。
