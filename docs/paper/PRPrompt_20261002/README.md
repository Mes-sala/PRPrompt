# PRPrompt 论文材料

最终方案统一命名为 **PRPrompt：面向少样本节点分类的原型路由图提示**。叙事围绕“支持集锚定的原型关系如何组织节点提示、适配冻结编码器”展开；最终采用原型分类。

## 阅读顺序

1. [论文叙事](论文叙事.md)：核心问题、摘要、引言、方法与结果解释。
2. [主比较表](主比较表.md)：对比冻结预训练、全量微调和三种 Prompt；完整展示七数据集 1/3/5-shot 的 Acc、Macro-F1 和标准差。
3. [消融与分类器对照](消融与分类器对照.md)：共享提示、去掉提示、单独训练线性分类器，以及固定 PRPrompt 表示后的线性分类器。
4. [配对比较](配对比较.md)：全部条件的两项主要指标差值及 95% 区间。
5. [实现与实验协议](实现与实验协议.md)：实际路由、优化、信息范围、1-shot 适配和统计口径。

- [数据来源与验收](数据来源与验收.json)、[数值复核](数值复核.json)、[证据索引](证据索引.json)。
