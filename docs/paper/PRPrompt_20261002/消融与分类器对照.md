# 原型路由消融与分类器对照

单位为 %；先平均每次支持抽样的 3 个训练种子，再报告 20 次支持抽样的均值 ± 样本标准差。所有方法使用同一图、checkpoint、支持集和查询集。

## 对照定义

| 对照 | 改动与检验目标 |
| --- | --- |
| 无节点相关门控（共享提示） | 固定每个节点的系数为 1/C；保留同一类别提示矩阵、注入位置、尺度、损失、优化器和读出。检验节点相关原型路由相对共享提示的价值。 |
| 冻结预训练＋原型分类 | 完全去掉提示，冻结预训练编码器并保持相同原型读出。检验内部表示适配的整体价值。 |
| 冻结预训练＋线性分类 | 不使用提示，仅在冻结预训练表示上训练线性分类器。检验单独训练分类器是否足够。 |
| PRPrompt 表示＋单独训练线性分类器 | 先按完整方法训练提示，再冻结该提示和最终表示，只拟合线性分类器。检验同一表示的读出差异；不是提示与线性头联合训练。 |

共享提示保留名义 token 参数量，但所有节点相同的组合降低了有效自由度，不能宣称完全排除了容量差异。固定表示分类器的选参条件于已经使用全部支持标签训练的父表示，不能称为整个流程的严格嵌套验证。
