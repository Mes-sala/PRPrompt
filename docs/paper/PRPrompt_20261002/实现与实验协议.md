# PRPrompt 实现与实验协议

## 固定方案与信息范围

正文统一称为 PRPrompt。内部数据来源为用户确定的 F100Soft；1-shot 使用明确的损失适配，3/5-shot 使用其原训练配方。所有数据集统一使用这一方案，没有逐条件选择不同实现。

编码器为两层 ProG GCN，隐藏和输出维度均为 128。所有方法按数据集使用相同的原始 Edgepred_Gprompt checkpoint；预训练种子未知，仅比较这些固定 checkpoint 下的适配效果。完整图结构和属性可见，支持标签用于拟合和选参，查询标签在预测封存后才用于评分。

## 路由原型校正

令 $ R $ 为两跳聚合属性的全图中心化、逐行归一化表示。对类别 $ c $ 的支持集 $ S_c $，初始原型为：

$$ \mu_c^{(0)}=\frac{1}{|S_c|}\sum_{i\in S_c}R_i. $$

对不在支持集中的节点 $ U_V=V\setminus S $，重复三轮：

$$ a_{ic}^{(t)}=\operatorname{softmax}_c\left(R_i^\top\operatorname{norm}(\mu_c^{(t)})/0.05\right), $$

$$ \mu_c^{(t+1)}=0.5\mu_c^{(0)}+0.5\frac{\sum_{i\in U_V}a_{ic}^{(t)}R_i}{\max(\sum_{i\in U_V}a_{ic}^{(t)},10^{-8})}. $$

校正利用所有非支持节点的特征，包含查询节点及其他未标注节点，不读取这些节点的类别标签。三轮结束后，以温度 0.1 计算关联矩阵，再经列中心化及一次归一化图聚合得到固定路由。支持锚定原型、未标注校正和邻域聚合共同构成当前路由，现有消融检验的是整套路由相对共享提示的作用，不分别声称每一步贡献均已证明。

## 提示与优化

| 项目 | 实际执行值 |
|---|---|
| 可学习参数 | $ C\times128 $ 类别提示矩阵 |
| 初始化 | 全零 |
| 注入位置 | 第一层 GCN 输出、LeakyReLU 激活之前 |
| 通道尺度 | 第一层预激活的逐通道样本标准差，最小值 $ 10^{-6} $ |
| 幅度 | 10 |
| 提示约束 | 对提示矩阵逐元素取 tanh 后参与组合 |
| 优化器 | Adam，lr=0.01，实际 epsilon=$ 10^{-8} $，weight_decay=0 |
| 最终训练步数 | 100 |
| 提示正则 | $ 0.001\operatorname{mean}(P^2) $ |
| 训练分类 | 归一化表示上的余弦原型，温度 0.2 |
| 3/5-shot 损失 | 对每个支持节点，构造其同类原型时排除自身，再计算支持交叉熵 |
| 1-shot 损失 | 包含自身的支持原型交叉熵；这是对无法定义的单样本留一损失的适配 |
| 预测 | 最终全图表示先减全图均值，再归一化并使用支持原型分类 |

训练阶段的原型损失不额外减全图表示均值；预测阶段才使用该中心化。训练目标仅包含上述支持损失及提示正则，没有查询标签损失。Adam 的实际参数以被调用优化器为准，不能把通用配置字段中的 weight_decay 误写成最终方案的实际权重衰减。

## 配对实验与基线

七个数据集：Cora、CiteSeer、PubMed、Photo、Computers、Actor、Chameleon。每类 1/3/5 个支持节点，20 个支持抽样种子 30093000–30093019，三个训练种子 0/1/2。不同 shot 使用同一类别节点排列的前 1/3/5 个节点，构成嵌套支持集。

主表的七个方法覆盖 8,820 个单元；加上共享提示的 1,260 个单元和同一提示表示上的 1,260 个线性分类器诊断，共提取 11,340 个不同单元。免训练原型读出仍按原三个训练种子槽位保留，不能把这些槽位当成独立拟合或增加支持样本量。

冻结预训练＋原型分类采用与最终方案相同的预测中心化和原型读出。冻结预训练＋线性分类在归一化的冻结表示上训练带偏置线性头。全量微调更新编码器及线性头。GPF 使用共享输入提示，GPF-plus 使用输入相关提示组合；GraphPrompt 为冻结表示上的对角读出提示适配。三者是统一节点协议实现，未声称复现各原论文最佳完整配置。

PRPrompt 使用固定训练配方。需要选参的比较方法，3/5-shot 使用支持内三折、学习率 $ \{0.001,0.01\} $ 与 weight_decay $ \{0,0.0001\} $ 的四候选组合，各折及最终拟合均 100 步；1-shot 使用预先固定参数，不额外使用验证标签。因选参流程不同，不能声称所有方法总训练计算量相同，也不把性能差全部归因于某一个模块。

## 两种分类器对照的准确含义

1. **冻结预训练＋线性分类**：不加任何提示，只训练分类器。
2. **PRPrompt 表示＋单独训练线性分类器**：先按完整 PRPrompt 训练提示，再固定提示和输出表示，另行拟合线性分类器。提示不接受该线性头的梯度。线性头对原表示逐行归一化，不额外减全图均值，因此该对照包含读出预处理差异，不只比较是否学习分类权重。该对照用于同一表示的条件读出分析，不能标为联合训练消融；线性头的支持内选参条件于已经使用全部支持标签训练的表示，不是全流程严格嵌套验证。

无节点相关门控的对照将路由直接设为 $ 1/C $，保留类别提示参数矩阵及训练配方；不再中心化这组常数，否则提示会恒为零。这里“无门控”意指无节点相关分配，仍有共享提示。完全去掉提示的对照单独由冻结预训练＋原型分类给出。

## 统计与结果完整性

保留 Accuracy、Macro-F1、Micro-F1、macro ROC-AUC 和 macro AP。每个条件先平均三个训练种子，再对 20 次支持抽样计算均值及样本标准差。跨 21 个条件的均值为等权描述性汇总，没有把查询节点数作为跨数据集权重。

配对区间以相同支持抽样为块，使用 10,000 次有放回 bootstrap；区间未做多重比较校正，不能把包含零解读为等效。原来已存在的 735 个五指标区间保持不变。冻结预训练＋线性分类的 105 个五指标区间由本次提取按同一统计单位补算，随机种子 20261002，并在数据中明确标为新增描述性分析，没有重新训练或选参。

提取过程重新核对 11,340 个指标文件的原清单 SHA256、支持／查询及图／checkpoint 哈希，复算所有 189 行独立聚合值，并核对配对差值方向。此前完整交付审计已经独立复核保存预测的五指标及预测／状态／选择哈希；本次复用该验收并进行定向数据提取，不声称再次重做全部预测重放。模型 checkpoint、训练状态仍只在服务器保存。

数值诊断必须随结果保留：PRPrompt 1/1,260 个单元超出原门控／前向阈值，共 211 次查询类别变化事件；共享提示 2 个单元超限；GPF 8 个单元超限；GraphPrompt 的新全链前向有 1 次类别变化。类别变化按单元累计，不是唯一节点计数。保存表示上的读出均精确通过，但这不能替代新 CUDA 全链逐位一致性。所有原封存预测都保留在主表中。

## 可复现入口

实际训练函数：仓库 `experiments/boundary_20261002/model.py` 的最终配方分支，调用 `experiments/v1_f100/historical.py` 载入冻结参考函数。共享提示控制：`experiments/f100_boundary_20261002/model.py`。固定表示分类器：`experiments/boundary_20261002/probes.py`。

提取脚本：`tools/build_prprompt_paper.py`。在包含已验收结果的仓库中，用带 NumPy 的 Python 执行；使用新的输出目录，脚本拒绝覆盖现有论文材料：

```bash
python tools/build_prprompt_paper.py --output /tmp/prprompt-paper-tables --receipt-dir /tmp/prprompt-paper-receipt
```

该命令生成结果表和数据，不启动实验、不下载权重。论文叙事、证据索引和材料导航是人工组织的工作稿，与数据提取输出共同交付；完整文件哈希见本目录的 `文件校验清单.json`。
