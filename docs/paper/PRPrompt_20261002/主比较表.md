# PRPrompt 主比较

单位为 %；先平均每次支持抽样的 3 个训练种子，再报告 20 次支持抽样的均值 ± 样本标准差。所有方法使用同一图、checkpoint、支持集和查询集。

冻结预训练＋原型分类采用与 PRPrompt 相同的最终表示中心化及原型读出。GPF、GPF-plus、GraphPrompt 为本项目统一节点协议实现；GraphPrompt 为对角读出提示适配，不能解释成全部原论文最佳配置复现。

## 结果边界
