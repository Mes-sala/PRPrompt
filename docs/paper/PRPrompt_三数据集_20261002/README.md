# PRPrompt 三数据集论文材料

当前报告范围为 **Cora、CiteSeer、PubMed × 1/3/5-shot**，采用一个固定 PRPrompt 方案。主线是支持集锚定的原型路由对节点提示适配的价值，最终采用原型分类。

## 文档

- [论文叙事](论文叙事.md)：摘要、引言、原型路由方法、结果与适用边界。
- [主比较表](主比较表.md)：冻结预训练、全量微调、GPF、GPF-plus、GraphPrompt 统一适配及 PRPrompt。
- [路由消融](路由消融.md)：完整方法、共享提示及完全去掉提示。
- [配对比较](配对比较.md)：九个条件的 Accuracy、Macro-F1 差值及原配对区间。
- [实现与实验协议](实现与实验协议.md)：原型校正、优化、信息范围和统计口径。

## 数据

- [主比较数据](主比较数据.json)：54 行，六方法、九条件、五指标及标准差。
- [路由消融数据](路由消融数据.json)：27 行，三个方案、九条件、五指标及标准差。
- [PRPrompt 逐次结果](PRPrompt逐次结果.jsonl)：540 个最终方案结果及配对身份哈希。
- [配对差值与区间](配对差值与区间.json)：270 个五指标配对效果，全部保留原区间。
- [条件内统计](条件内统计.json)：63 个独立数据集／shot／方法条件，均值与标准差仅由本条件的 seed 结果计算。
- [数据来源与验收](数据来源与验收.json)、[数值复核](数值复核.json)、[证据索引](证据索引.json)。

本次重新组织既有结果，没有新增训练或重算 bootstrap 区间。论文仍为工作稿；数据范围在实验完成后确定，结论仅适用于所列条件。模型权重及训练状态不包含在本地材料中。
