# PRPrompt 三数据集主比较

仅 Cora、CiteSeer、PubMed，1/3/5-shot。单位为 %；先平均 3 个训练种子，再统计 20 次支持抽样的均值 ± 样本标准差。

冻结预训练采用与 PRPrompt 相同的预测预处理和原型读出。GPF、GPF-plus、GraphPrompt 为本项目统一节点协议实现，不能描述为各原论文最佳配置复现。

所有均值仅在同一数据集、同一 shot、同一方法内计算，不跨数据集或实验设置汇总。
