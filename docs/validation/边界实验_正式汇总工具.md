# 边界实验的正式汇总工具

`tools/build_boundary_report.py`只读取完整回传且独立审计通过的R2主实验及F100同配方补充。
运行中的源码快照、预声明选参和统计协议保持原样。

输入要求主实验31,500个单元、15,120个固定表示探针，以及F100补充3,780个新控制和
2,520个复制参考；两个`local_delivery_status.json`必须是完整交付的`complete`状态，
并与对应plan及最终文件清单SHA一致。777单元主实验smoke不能作为输入。

工具读取已经保存且逐文件核对的五指标表与配对区间，不新采样bootstrap，不生成新统计检验。
展示Soft−对照时，F100补充的控制−Soft差值及区间统一反向：
$$ (\Delta,[L,U])\mapsto(-\Delta,[-U,-L]). $$
单位为百分点；均值和标准差转换成百分数。所有负差值与包含零的区间保留。

输出包括软分配边界、联合训练/固定表示分类头边界、全部方法1/3/5-shot表现、
原始五指标CSV和完整结果副本、数值资格、参数与实测成本、来源及报告文件SHA。
CSV和服务器原始结果Markdown按字节复制，派生表只用于展示已审计值。
参数和最终拟合时间没有实际记录的字段保留null；各单元耗时包含并发竞争，不能相加冒充墙钟时间。
CUDA峰值包含worker当时的主干、数据、缓存滤波器和分配器保留量，不是隔离测得的方法独占显存。

示例命令（只有两个完整交付审计都通过后才可执行）：

```sh
python3 tools/build_boundary_report.py \
  --main experiments/outputs/boundary_5090_20261002_R2 \
  --supplement experiments/outputs/F100_route_boundary_5090_20261002_R2 \
  --main-delivery experiments/local/boundary_20261002_R2/local_delivery_status.json \
  --supplement-delivery experiments/local/f100_boundary_20261002_R2/local_delivery_status.json \
  --output experiments/local/boundary_20261002_R2/final_report
```

工具拒绝覆盖已有报告。报告生成后，还需要根据全部配对结果、负结果、微调差距、
数值资格、成本和机制解释形成论文方案建议；工具不会按每个数据集的query结果自动拼装方法。
最终人工科学审核与投稿批准没有发生，不能把工具输出写成投稿就绪。

目前已验证差值/区间反向、百分数格式、实际两个计划的哈希以及拒绝smoke输入。
正式报告的完整集成验证等待两套正式结果完成，不能用这些预检替代最终交付验收。

汇总工作流使用本地`scientific-writing`技能的证据和数值一致性约束。
