# 五数据集扩展：研究结论与验收说明

本轮沿用未修正 Edgepred 权重＋历史 v1 F100，无 M3，完成五个新增数据集、十个 checkpoint 条件、九种方法、5400 个正式单元。完整表格见 [五数据集 F100 验证](../五数据集_F100验证_20261001.md)。

## 效果与负结果

F100 的收益明显依赖数据集，不能将此前 Cora/CiteSeer 的表现推广为通用优势。

- 相对使用相同中心化原型读出的 FrozenPrototypeCentered，Accuracy 均值10/10更高，8/10配对描述性区间完全为正；但不能只看这个冻结对照。相对 FrozenLinear，均值8/10更高，区间完全为正7/10，Actor的两个条件均值都更低。
- 相对 v2 PRPrompt，F100只有 Chameleon 的两种权重条件明确更好：26.974% / 27.544%，相对 v2 增加2.639 / 2.770个百分点。Photo、Computers四个条件均明显落后于 v2；Actor/GPPT也出现负的配对区间。
- 相对完整微调，F100均值5/10更高，但只有 PubMed/Gprompt 和 Chameleon 两个条件的配对区间完全为正。Photo、Computers四个条件的完整微调显著更强。
- Actor上F100仅约21% Accuracy，五类任务的均匀随机参考为20%，绝对表现很弱，不能解释为有效的普适提升。

统计单位是固定图/权重条件下的20个支持抽样，先在每个抽样内平均三个训练重复。配对区间是10000次bootstrap的95%描述性区间，未做多重比较修正。每条件只有一份原始checkpoint，预训练种子未知。其他可训练方法支持内选参，F100采用预先固定的历史配方。这些差异和单图边界限制推广。

本轮结果支持保留 F100 作为有明确适用条件的版本，不能以它统一替代 v2 PRPrompt。实验不扩展为额外方法或选参搜索。

## 原数值验收未全部通过

Actor/GPPT的60个F100单元有7个独立前向未通过原混合误差界限，最大比例1.35634，阈值1未改。九个checkpoint的原审计通过；剩余条件的补充采集器保留该失败，继续检查全部540个方法单元，其余断言通过。

全5400个单元的保存分数重放精确一致，F100保存表示的原型读出重放误差为零。全部指标从封存概率独立重算，支持/query隔离、预测/状态/选参SHA及配对划分通过。交付完整性与评分验证通过，不能等同于原数值验收全部通过。

完整新CUDA前向诊断记录了9个类别变化；F100独立重建gate全链另记录1个类别变化，最大概率误差约 $5.61\times10^{-6}$，严格全链诊断标志为False。逐单元路径与数值在完整接收目录的各checkpoint审计JSON中保留。

固定第一个失败单元在两张GPU各重复10次，无拟合和query标签，原始表示最大重复抖动约 $1.24\times10^{-5}$；概率最大误差约 $3.98\times10^{-7}$、重放类别无变化。与CUDA稀疏归约数值差异相符，但没有以这项诊断放宽阈值或删除失败。

## 已完成的交付复核

48325个文件SHA无差异，约16.54GB结果完整回传。5400个单元五指标、90个方法汇总和400个配对五指标/区间均由本地NumPy独立复核；最大指标误差 $3.33\times10^{-16}$。交付状态为`delivery_complete_with_numerical_qualification`；数值验收False原样保存。原训练源码、协议、失败日志及改动前的交付审计代码均保留。
