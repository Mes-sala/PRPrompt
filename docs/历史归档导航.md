## 环境与运行

复用已有 **ProG conda 环境**，不将 Conda 环境或第三方安装目录打包到 Git。
历史 5090 快照使用 `prog-v2-cu130` 环境，其冻结说明见 `archive/source_root/autodl-tmp/PROG_ENV_README.txt` 与 `prog_env_freeze.txt`；具体选择机器上已有且兼容的 ProG 环境。

1. 先执行 `python tools/verify_repository.py`，验证仓库来源文件与运行入口的冻结哈希。
2. 根据 `runtime/plan.json` 将四个原始 checkpoint 放到 `runtime/checkpoints/<job-id>.pth`，必须匹配记录的 SHA256。
3. 将原始 Planetoid 数据置于 `runtime/data/Planetoid/`，保证与原实验一致。权重、数据和完整预测保留在服务器原目录，不包含在本仓库。
4. 在有兼容 CUDA/PyG 环境的机器上运行：

```bash
python runtime/run_softening.py --job Cora__Edgepred_Gprompt__87bd546f7897 --smoke
python runtime/run_softening.py --job Cora__Edgepred_Gprompt__87bd546f7897
```

其余 job ID 见 `runtime/plan.json`。默认温度含基础 M3 的 `T=0.2` 与软化对照。软化实验没有提供稳定升级证据，不能将候选当作已验证改进。

本次整合只验证文件完整性与入口语法，**没有重新训练或复现实验指标**。历史脚本保留冻结源码及原绝对路径，以维持哈希证据；`archive/` 不是直接可运行的统一软件包。历史重跑需要参照来源映射恢复数据、checkpoint 和路径，不能仅修改源码后跳过冻结校验。
