# PRPrompt 当前实验计划与执行协议

## 当前完整主比较

| 方法 | 训练内容 | 边界 |
|---|---|---|
| FrozenLinear | 冻结预训练 GCN，仅训练普通线性头 | 预训练表示基线 |
| FrozenPrototype | 冻结表示，以支持原型余弦分类 | 无梯度适配的预训练参考 |
| FullFineTune | 预训练初始化，训练全部 GCN 与线性头 | 完整微调 |
| GPF | 输入共享提示向量与线性头 | 统一整图节点协议中的提示算子 |
| GPFPlus | 输入注意力组合 20 个提示基与线性头 | 含可学习路由的提示对照 |
| GraphPromptDiag | 冻结表示上学习对角提示，支持原型分类 | 不是原论文完整子图流程复现 |
| PRPrompt | 支持原型固定路由、隐藏提示与线性头 | 当前完整方案 |

当前主张是：同一预训练模型、同一少量标签下，原型路由提示是否改善任务适配。按预训练来源展示全部比较，收益不一致时写条件性结果；尤其须保留低于 FrozenLinear 或 FullFineTune 的条件。机制与新颖性不能仅由主表胜负证明。

## 当前预训练版本与路径

当前使用原始 Edgepred_Gprompt/Edgepred_GPPT。Cora、CiteSeer、PubMed、Photo、Computers、Actor、Chameleon 每个数据集/预训练家族各保留一份原始 checkpoint，共 14 份；预训练种子统一记作 `unknown_original`。这些是既有权重，不重新预训练或择优替换。

5090 原代码位于 `/home/shq/ProG`，权重按标准路径 `/home/shq/ProG/Experiment/pre_trained_model/<dataset>/<family>.GCN.128hidden_dim.pth` 加载。本地对应 `archive/source_root/ProG/`。[固定原权重清单](../../experiments/configs/original_edgepred_checkpoints.json)绑定 SHA256，加载器拒绝同名但内容不同的权重。

## 标签、训练与统计

使用公开 train_mask 抽取每类 5 个支持节点，公开 test_mask 为查询；不使用公开验证标签。支持抽样种子 30093000–30093019，下游训练种子 0/1/2。所有方法在同一抽样使用相同支持/查询。整图无标签属性与边可见，属于同图、已知类别、传导式任务。

训练 100 步，学习率候选 0.001/0.01，权重衰减候选 0/0.0001。支持集内部最多 3 折，每折留出每类一个节点；该折的提示原型及路由只由剩余训练支持节点构造。选参后从相同初始化使用全部支持标签重新拟合。1-shot 配置若另行执行，则用固定默认参数，不增加验证标签；本轮正式仅运行 5-shot。

PRPrompt 温度 0.1、幅度 10，GPFPlus 提示基数 20，均沿用当前固定配置。所有线性头使用归一化表示与相同种子独立初始化。预测先保存及封存，再读取查询标签计算 Accuracy、Macro/Micro-F1、macro ROC-AUC 与 macro AP；不按查询指标早停、选 checkpoint、选种子或选参数。

先对每次支持抽样内的 3 个训练种子取平均，再统计 20 次支持抽样的均值和标准差；配对 bootstrap 重采样单位为支持抽样。每份 checkpoint 分层统计，不混成独立图样本。汇总检查完整覆盖、重复记录、预测/状态/选参哈希及封存记录。

## 执行方式

复用 5090 的 ProG 环境 `/data1/shq/miniforge3/envs/prog-v2-cu130/bin/python`。在当前 PRPrompt 仓库根目录生成机器本地清单：

```bash
python experiments/prepare_original_edgepred.py \
  --prog-root /home/shq/ProG \
  --datasets Cora CiteSeer PubMed Photo Computers Actor Chameleon \
  --output experiments/local/checkpoints.json
```

当前七方法主比较使用 `experiments/configs/main.json`，先检查计划：

```bash
python experiments/run_benchmark.py \
  --manifest experiments/local/checkpoints.json \
  --config experiments/configs/main.json --dry-run
```

双卡分片可使用 `experiments/run_parallel_benchmark.py`。所有 worker 使用同一 manifest、配置、输出根目录及 worker 总数，每个 index 仅启动一个进程。开始新实验前先确认旧进程和锁；回退操作只验证路由和权重，没有重启训练。

历史 v1 F100 配方及五数据集的九方法协议分别保留在 `experiments/v1_f100/`、`experiments/f100_multidata/`，其支持内选参、种子和训练预算不随本次预训练回退改变。报告和原始预测/状态继续按封存版本解释。
