# 从旧三模块版本到 Prompt 核心版本

本文件记录实现差异，供维护和溯源；它不是论文中的模块贡献叙事。

| 旧版内容 | v2 决策 | 原因 |
|---|---|---|
| M1 的类别条件提示、隐藏注入 | 保留核心：原型关系组织类别提示矩阵，注入第一层预激活 | 与 Prompt 的对象、参数和作用位置直接相关 |
| M1 中无标签原型迭代、旧 ridge/teacher 计算链 | 删除；类别参照仅来自支持集 | 让路由来源更明确，避免把独立强分类器的复杂修正包装成提示本体 |
| 全图属性中心化、软分配中心化、原图聚合 | 保留，并在方法中显式给出 | 它们定义固定路由；因此仍需披露全图无标签可见性及平滑假设 |
| M2 的矩阵预条件和更新幅度嫁接 | 删除，实际使用普通 Adam | 不再作为提示方案的独立贡献，也没有在实现中隐蔽保留 |
| M3 的近邻构图、概率回注、支持标签钳制 | 删除，实际直接线性分类 | 不让预测后处理成为完整 Prompt 性能的来源 |
| 旧 leave-one-out 原型训练读出 | 换成普通线性头；适配方法使用共同读出 | 将路由原型与最终分类器分开，并使 1-shot 无需对单样本类别做无定义的 LOO |
| F000–F111 编码和因子消融主表 | 新配置完全不使用这些方法名 | 主表是完整方案与外部方法；诊断对照用有语义的名称 |

**v2 不是把 F100 改名。** 除优化和预测阶段的删除，路由来源、训练读出、标准差实现也发生明确变化，因此任何旧结果都不能作为新版结果。`runtime/`、`archive/`、`local/` 是冻结历史资料，未改写；新的源代码位于 `prprompt/` 和 `experiments/`。

新数据不回填历史 SHA256 清单。原 `tools/verify_repository.py` 继续检查旧来源文件，新版验收记录则保存在 `docs/validation/`。旧根 README 已另存为历史导航，不再作为默认方法说明。

尚未得到正式实验结果时，可写“提出并实现了一种支持原型路由的提示参数化”，不能写“证明固定路由更稳定”“消除了预训练差距”或“达到了顶会创新标准”。强基线胜负决定后续主张，而不是先拟定结论再选择有利结果。
