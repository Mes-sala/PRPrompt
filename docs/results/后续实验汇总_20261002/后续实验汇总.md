# PRPrompt 后续实验汇总：F100 与 v2

更新：2026-10-02。本文是本地研究结果整理，按当前保留的原始 checkpoint 汇总。未重新拟合、未根据 query 结果修改方法或选参，也未恢复已删除的实验记录。

**主要结论：F100 在 Cora/CiteSeer 的四个 Edgepred 条件下高于 v2 和全量微调；这一优势没有在全部新增数据集上延续。v2 在新增五数据集的 10 个条件中有 8 个高于 F100，Photo/Computers 的全量微调仍领先两者。两版都存在明确的底座与数据集依赖。**

## 1. 本轮汇总覆盖哪些实验

| 批次 | 正式评估单元 | 用途 |
| --- | --- | --- |
| v2 原六 checkpoint 验证 | 4,680 / 4,680 | Cora/CiteSeer × Gprompt/GPPT/DGI × 20支持抽样 × 3训练重复 × 原13方法 |
| 原 Edgepred 的 F100 重跑 | 240 / 240 | 4 checkpoint × 20支持抽样 × 3重复；与前批原 v2 结果配对 |

三批共 **10,320 个正式评估单元**。这是执行记录总数：原 v2 批次仍包含现在不纳入研究比较的历史方法。主结果只展示冻结预训练图表示、全量微调和 Prompt 方法；不比较 AttributeRidge/AttributePrototype。复制的参考结果与 GPU smoke 不重复计入。历史因子确认和 M3 软化在第 7 节单列，不并入该总数。

## 2. 共同协议和两版差异

主表覆盖 7 数据集 × 2 原 Edgepred checkpoint = 14 条件。每个条件使用5-shot，可训练方法最终拟合100步；支持抽样为 30093000–30093019，训练重复为 0/1/2。先平均同一支持抽样的三次训练，再计算 20 个支持抽样的均值及样本标准差。F100 的三次重复 Accuracy 完全一致，不能将其解释为 60 个独立样本。

Cora/CiteSeer/PubMed 使用官方支持候选池及测试 query；Photo/Computers 用固定种子 20260930 建立每类 20 个节点的候选支持池，其余为 query；Actor/Chameleon 使用官方 fold0。整图无标签属性与结构可见，属于同图、已知类别的传导式小样本节点分类；不提供跨图或新类泛化证据。

| 项目 | 历史 F100 | PRPrompt v2 |
| --- | --- | --- |
| 主干 | 冻结原 GCN | 冻结同一原 GCN |
| 路由 | 保留历史 raw 教师/路由方程，温度0.1 | 支持原型路由，温度0.1 |
| 训练/读出 | 留一原型损失；最终全图中心化余弦原型读出 | 线性分类头与支持监督损失 |
| 固定配方 | 幅度10；sample std；Adam lr=.01, eps=1e-8, wd=0；提示正则.001 | 幅度10；population std；支持内选参 |
| 选参 | 固定历史配方 | 三折支持内CV：lr .001/.01 × wd 0/.0001；每折及最终均100步 |
| M2/M3/KD | 无活跃M2/M3/KD，无分类头 | 本批 v2 不等同于旧 F111 三模块管线 |

F100 与 v2 是两套完整配方的比较，不能把分数差归因为单一模块。冻结线性读出及其他可训练对照采用与 v2 相同的支持内选参预算；两种冻结原型读出免训练。GPF、GPFPlus、GraphPromptDiag 为本项目统一 GCN/节点协议下的适配实现，不声称原论文最佳配置复现。原预训练种子未知，sidecar 的 ProG-adapted / not_fully_verified 或 legacy_unverified 边界保留。

## 5. 分数据集解读

- **Cora/CiteSeer：** F100 对两份 Edgepred 底座均领先 v2，提升约2.07–18.48个百分点；相对全量微调约5.53–24.40个百分点。优势在同图、匹配支持集条件下成立，不能据此推断所有底座都有效。
- **PubMed：** v2 对两底座略高于 F100；两者配对区间跨0，不能下确定优劣结论。Gprompt 下两版高于微调，GPPT 下与微调接近。
- **Photo/Computers：** v2 在两底座上均高于 F100，但 FT 又高于两版。它们构成最明确的推广反例，不能只用 Cora/CiteSeer 支撑普遍优势。
- **Actor：** 分数约21–22%，F100 没有稳定优势，v2 也未显示明显的强效果；应保留为弱结果。
- **Chameleon：** F100 对两底座均高于 v2 与 FT，配对区间完全为正；绝对 Accuracy 仍仅约27%，结论应限于这些固定条件。

## 8. 完成状态与审计限制

三批正式覆盖和本地结果回传均已完成。以前的逐文件交付审核记录分别核对24,192 / 2,998 / 48,089个文件，SHA256不匹配均为0；这是原交付记录，本次没有重新对全部权重、状态和日志做一次全文件审核。

本次新核对包括10,320个正式 metrics.json、保留研究范围的8,160个单元的五指标汇总、配对图/权重/支持/query/支持标签哈希，以及240个F100单元引用的原v2 metrics SHA。与原CSV的最大汇总误差为3.33e-16，配对均值误差为6.59e-17。三批v2核心源码哈希相同，两轮F100历史源码哈希相同。

**数值验收并未全部通过，不能因交付成功而抹掉：**

- 四checkpoint F100：原始前向绝对误差阈值小于2e-6，6/240单元超限，最大3.81469727e-6。补充混合误差规则为执行后的审计修订，不能写成原阈值通过；完整重建概率严格阈值也有超限，分类无变化。
- 五数据集：预声明混合前向误差规则在 Actor/GPPT 的7/60个F100单元失败，最大误差比例1.35634053；其余9份checkpoint该项通过。完整新CUDA前向另有类别漂移诊断，保存分数/状态读出重放通过不等于完整新前向逐位通过。
- 两轮保存预测、五指标重算、配对划分与交付哈希均已核对通过，故保留已封存分数并明确限定；没有更改模型、阈值、种子或评分去消除负结果。

## 9. 可用于当前研究陈述的边界

目前可以陈述：原Edgepred固定图/权重下，F100在Cora/CiteSeer及Chameleon显示条件性优势；v2在新增数据集多数条件优于F100，但Photo/Computers仍落后全量微调，DGI与Actor结果弱。现有实验不足以支撑“统一优于微调”“适用于全部预训练底座”或“三模块创新机制已经成立”。不能按每个数据集事后选F100/v2较高分组成一个未经预声明的新方法。

下一步研究判断应围绕现有差异的机制与适用条件，本文未自动开展新方法搜索、shot曲线或新增训练。
