# 1/3/5-shot 完整表现

均值±标准差为百分数：先平均3个训练重复，再对20个支持抽样计算样本标准差。
支持集使用相同随机排列的嵌套前缀。这里展示描述性shot变化，不新增跨shot显著性检验。
F100列在1-shot是F100OneShotAdapt，在3/5-shot是F100Historical；不能将三列视作完全相同的训练损失。
