# 完整方案的描述性统计

每个方案固定应用于七个数据集的1/3/5-shot，共21个条件。跨条件等权均值仅用于描述，不把嵌套shot或同一固定图视作独立图样本，不生成新的跨图区间或p值。

F100的1-shot为预声明的inclusive适配，3/5-shot为原LOO历史配方。数值资格和微调负结果见结果总结；本表不能替代这些限制。
