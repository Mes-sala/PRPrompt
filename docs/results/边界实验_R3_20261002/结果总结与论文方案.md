# 完整边界实验结果与论文方案建议

**建议主方案采用 F100 原配方的类别相关 Soft 路由与居中原型读出；3/5-shot 使用 F100Historical，1-shot 明确标为 F100OneShotAdapt。** 联合训练框架中的简化备选为 Soft＋Ridge。选择依据是完整的配对表现、Macro-F1、反例、参数量和数值资格；本次没有按数据集或shot拼接不同获胜方法，也没有根据query表现修改训练或选参。

这项建议是当前固定 Edgepred_Gprompt 底座上的研究方案选择。**Soft 优于 Hard 的整体主张未成立；居中原型头的优势取决于父表示与训练配方。** 本轮不能写成“软分配普遍更优”或“替换原型头普遍提升”。两组数值复跑未全部通过原门槛，结果和失败证据均保留。

## 证据范围与验收

七个数据集 Cora、CiteSeer、PubMed、Photo、Computers、Actor、Chameleon，仅原 Edgepred_Gprompt checkpoint；每个数据集1/3/5-shot、20个嵌套支持抽样、3个训练重复。主实验25个完整方法条件，共31,500个方法单元；固定表示分类头探测15,120个；F100同配方新增路由控制3,780个，另有2,520个字节相同的R3父引用。引用不重复计作训练，None的解析头也不称为100步拟合。

两组控制器与worker已实际退出，完整清单生成后才接受交付。222,363个本地保留文件和51,268个仅保留远端的文件逐文件SHA核验匹配；本地模型二进制为零。五指标独立重算最大误差4.440892098500626e-16，主/探测6,090项与F100同配方735项配对效应和区间逐项重算通过。精确支持身份、支持/query隔离、$ 1 \subset 3 \subset 5 $ 嵌套及保存表示读出均通过。R1/R2失败版本、smoke和旧v2结果未并入本轮正式统计。

指标先平均每个支持抽样内的3个训练重复，再对20个支持抽样求均值和样本标准差。原配对95%区间按20个支持抽样聚类重采样10,000次，PCG64 seed 20261002，未校正多重比较。以下21条件等权均值只是描述性比较，不推断独立跨图总体，也不新增跨shot显著性检验。

全图无标签特征和边可见，拟合及选参仅接触支持标签，预测封存后才评分。1-shot使用预声明超参；联合配方和常规基线的3/5-shot进行支持内选参。F100保持历史固定优化配方，不与联合框架视为相同选参/损失。最终训练100步；联合配方的4个候选×3折×100步选参另计。1-shot的F100损失为inclusive适配，不能称为原LOO配方。

## 为什么建议保留 F100 主方案

F100全条件 Accuracy均值为51.43%，Macro-F1为49.80%；Hard版本为51.46%/49.66%，HardMatched为51.44%/49.64%。Hard的平均Accuracy仅高约0.03个百分点，并未形成稳定升级；Soft的Macro-F1均值略高，原数值门槛超限也少于Hard控制。保持既有Soft方案的依据是整体配方的收益与这些限制共同成立，不是证明软概率优于硬分配。

F100相对FullFineTune的平均差值为Accuracy +4.65、Macro-F1 +5.28个百分点；原区间分别13正/4负/4含零、17正/4负/0含零。相对冻结GCN＋CenteredPrototype，两指标均在21/21条件均值为正、17/21区间全正；相对GPF、GPFPlus、GraphPromptDiag的完整配对证据也更明确。F100相对联合Soft＋CenteredPrototype的Accuracy平均高5.18个百分点，10个区间全正、1个全负，但这是整体历史配方比较，不能归因为分类头的单独作用。

## 论文表述与方案落点

论文主实验可以采用一个统一的F100/Soft方案，1-shot适配单列说明；Ridge保留为联合头收益对照。较有证据的表述是：固定预训练GCN上，类别相关路由驱动的小参数提示在本轮多个条件中提高少样本适配表现；收益依赖数据集、shot、训练配方与分类头。软分配的相对优势和居中读出的联合训练优势都有明确反例。

不能把“Soft压过Hard”“居中原型普遍优于Linear”“所有数据集胜过微调”列为已成立创新结论。强基线和头的收益比较证明有效性边界，不自动证明原语新颖性。预训练种子未知、历史预训练来源未完全核实，本轮只有七个固定checkpoint和同图传导设置，不能推广为全部backbone、预训练来源、跨图归纳或未知类别任务。

截至本轮完整结果，F100原配方是更有依据的主实验选择；Soft＋Ridge是联合框架中的条件备选。保持统一方法，保留Photo/Computers微调反例、Actor弱收益及全部数值异常。本文档完成用户要求的方案判断；投稿级无异常数值复现、作者核验和新的研究协议不在此次完成声明之内。
