## 编辑方式

AI 组件是独立嵌入的位图，可逐个移动、缩放和替换；不是可逐节点修改的矢量图。名称、箭头和辅助符号为 draw.io 原生元素。所有图片均已复制至本目录，并嵌入源文件，无外部图像依赖。

清理提示词统一要求白底、纯色、去掉光晕/纹理/阴影/渐变，保持结构，不添加文字或公式。完整生成流程使用内置 imagegen，没有调用 CLI。

## 图外说明

图案是机制示意，不表示具体节点数、网络宽度或实验结果。基础 M3 从适配表示构造读出近邻，回注原型初始概率，每轮恢复支持标签。M2 中“矩阵方向”对应 Shampoo 的类别轴和特征轴统计，“步幅匹配”对应同轨迹 Adam 候选的范数，最终更新同一个共享残差参数。更多推导保留在正文，未塞入框架图。

已检查实际导出 PNG；XML 结构检查无错误。组件图片包含透明或白色边距，所以边界框重叠提示不代表实际图案覆盖。
