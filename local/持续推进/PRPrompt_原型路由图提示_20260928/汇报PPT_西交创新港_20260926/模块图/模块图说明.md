# 汇报用三模块中文 Framework

采用“鲜明大字双语版”的原配色：青色 `#008E87`、紫色 `#9056C3` 区分示意类别，蓝色 `#2B75B9` 表示共享计算与冻结主干，橙色 `#D47A23` 突出锐化和方向/尺度适配。

三张图均为横版 1800×900 画布，主要标签 34–42 px。原生可编辑 Draw.io 组件构图，分别保存 `.drawio`、高分辨率 `.png` 和嵌入源图的 `.svg`。图中的节点数、向量维数、概率分布为局部机制示意，不是实验结果。

## 文件

| 文件前缀 | 内容 |
| --- | --- |
| `M1_类别语义引导与软原型` | 支持原型、未标注节点软分配、按类权重求软原型、原始支持锚定、循环修正、锐化、有符号门控、共享类别提示组合及激活前注入 |
| `M2_更新方向与尺度匹配` | 同一梯度分支到 Shampoo 和 Adam；Shampoo 保留方向，Adam 提供全矩阵范数；实体箭头显示原方向、适配方向、Adam 参照方向；相反方向更新唯一 P |
| `M3_支持约束概率传播` | 同一适配表示同时生成原始 F₀ 和表示近邻 W；排除自身并依相似度选邻居；概率传播、10% 原始概率回注、90% 邻居项、支持标签恢复与循环 |

## 原生组件

- `mxgraph.basic.star`：支持/软原型；空心星表示原始支持锚点，实心星表示当前软原型。
- `rhombus`：50% 支持锚点与 50% 软原型融合得到的修正原型。
- `hexagon`：冻结图编码器、优化器分支与损失。编码器中的节点、边也是独立可编辑矢量组件。
- `mxgraph.ios7.icons.locked`：冻结编码器或固定支持标签。
- `mxgraph.mockup.graphics.pieChart`：节点类别概率；双圈表示支持节点。
- `mxgraph.arrows2.arrow`：有宽度的实体方向箭头，M2 的方向几何通过数值检查。
- 圆角向量条和圆点：示意特征、类别提示和节点修正。

边框通常为 2.8–3.8 px，主要连接线为 4 px，实体方向箭头宽 24–38 px。仅表示权重的示意边随贡献强弱变化。

## 机制检查

- M1 两幅按类求均值图使用相同节点坐标，通过不同的归一化权重得到不同星形中心。每轮原型融合始终使用原始支持锚点。未标出固定循环次数、锐化温度或中心化细节。
- M1 门控和类别提示是两个输入，组合为节点修正；只训练 P。节点修正注入冻结第一层输出的激活之前。
- M2 同一梯度并行进入两优化器统计分支。原方向与适配后方向严格共线，适配后方向与 Adam 参照严格等长，实际参数运动与适配方向相反。没有将 Adam 参照误画成另一条模型训练轨迹。
- M3 原始 F₀ 始终保留；初始化后及每轮混合后均恢复支持标签。近邻 W 来自最终表示，区别于原图；W 和表示在传播时固定。只传播概率，没有显示循环次数。

## 保存与验收

生成器为 `build_modules.py`。三个页面均通过已安装的 Draw.io MCP `set_page` 实际写入，调用记录见 `*_mcp_result.json`。PNG/SVG 通过 Draw.io Desktop 31.4.5 原生导出；PNG 已逐图目检，修正了 M1 提示组合连线、M2 并行分支连线、M3 百分比和路径避让。

本目录只新增汇报图，不替换主文档或用户选定的总 Framework。

M2 符号复检：顶部适配方向、等范数公式、实际 P 更新公式均使用 Draw.io MathJax `\widetilde{D}`，范数下标使用 `_F`；已在原生 PNG 中确认波浪符可见，负方向实体箭头与公式无交叠。
