# 总 Framework：鲜明配色与大字版

中英文同步调整。主要配色改为青绿 `#008E87`、紫 `#9056C3`、蓝 `#2B75B9` 与橙 `#D47A23`，矩阵填充、箭头和原型标记提高颜色对比；背景维持浅色。深色正文也提高对比度。

文字整体放大约8%–12%，局部受限位置作小幅调整。英文长标签使用必要换行，以避免文字与连线或相邻标题重叠。模型内容、方向与长度几何关系、循环和概率权重不变。
