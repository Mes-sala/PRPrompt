## 论文图注

**图：类别语义引导与节点提示生成。** 原始属性经过两跳原图传播、中心化和逐节点归一化，形成固定教师使用的特征。支持节点按类别求均值，得到原始支持原型；无标签节点与当前类别原型比较，经温度0.05的softmax形成软分配。对每个类别，将节点特征按该类分配权重汇总，再除以该类的权重总和，得到软原型；软原型与原始支持原型各占50%，修正当前类别原型。上述分配与修正重复3轮。随后由修正原型生成全图类别分配，以温度0.1锐化，减去全图平均并沿原图传播，得到有符号门控。不同节点利用各自门控组合共享类别提示，经tanh限幅和隐藏尺度缩放后，注入同一冻结编码器第一层激活之前。门控保持固定，只有提示参数由M2更新。所有点、矩阵和维度为局部机制示意。

## 软原型到底怎样计算

**支持原型**是已知同类节点的平均特征。**软原型**是无标签节点的加权平均特征；一个节点可以以不同权重同时贡献给多个类别，不需要先给它一个确定标签。

设三个无标签节点的特征分别为 $ r_1,r_2,r_3 $。图中softmax得到：

| 无标签节点 | 属于类1的权重 | 属于类2的权重 | 行和 |
| --- | ---: | ---: | ---: |
| u1 | 0.80 | 0.20 | 1.00 |
| u2 | 0.60 | 0.40 | 1.00 |
| u3 | 0.20 | 0.80 | 1.00 |
| 类别权重总和 | 1.60 | 1.40 | |

**行归一化与求类中心时的归一化，是两个不同操作。** 表里每行和为1，表示一个节点在各类之间分配其权重；求某一类的软原型时，还要除以这一列的总权重，使该类的节点贡献总和为1。

因此：

$$
p_1=\frac{0.80r_1+0.60r_2+0.20r_3}{1.60}
=0.50r_1+0.375r_2+0.125r_3,
$$

$$
p_2=\frac{0.20r_1+0.40r_2+0.80r_3}{1.40}
\approx0.142857r_1+0.285714r_2+0.571429r_3.
$$

这里除以的是1.60或1.40，而不是节点个数3。图中两组三角形使用**相同节点坐标**；圆点面积和连线粗细表达该类中的贡献强弱，星形位于对应加权中心。类1主要受u1、u2影响，类2主要受u3影响，所以两个星形中心不同。两组点分别着青色、紫色，只表示“正在计算哪一类的软原型”，不表示节点已经获得真实标签。

对每个类别，修正原型是原始支持原型与当前软原型的中点：

$$
c_c^{(j+1)}=0.5o_c+0.5p_c^{(j)}.
$$

下一轮用新 $ c_c^{(j+1)} $ 重新计算软分配，再得到新的软原型。每轮混合的支持参照始终是最初的 $ o_c $，不是把上一轮修正原型再当作支持原型。当前代码固定修正3轮。

## 数字与几何示意如何对应

绘图脚本设定两个初始单位原型为(1,0,0)、(0,1,0)，构造三个单位向量，并通过真实的“相似度除以0.05，再softmax”计算出表中的0.80、0.60、0.20。向量和完整计算结果保存在[可核算示例](/Users/shq/Research/GP/持续推进/主线03_硕士论文三模块_20260924/三个模块Framework详解_20260926/M1_example.json)。

例如，第一类软原型计算结果约为(0.469923, 0.436327, 0.742514)，第二类约为(0.416614, 0.440528, 0.783113)。上方的两组节点位置由同一三维示例作二维仿射投影得到，加权中心的位置按对应贡献计算，而非任意摆放。仿射投影允许拉伸坐标，因此图上的距离不用于读取余弦相似度。

该示例只核验软分配和加权平均这两个局部操作，不代表真实数据集，也不代表完成整个原图预处理后的实验结果。图中上下两个概率示例各自说明一段操作，不共享节点编号或数值。点数、类别数、特征维数均作了缩减。

## 下半张图怎样读

1. **分配变尖。** 温度0.2与0.1的并列概率条表示对照。降低温度后，高分项更集中；完整方案固定使用0.1，不是训练中逐步退火。
2. **变成有符号门控。** 每一类别减去其全图平均后，再沿原图归一化邻接传播。图中每列各有零线，左伸为负、右伸为正。此时系数不再是非负概率；它表达相对全图共同倾向的偏移。
3. **组合提示。** 每类一行的共享提示矩阵 $ P $ 从零初始化，训练中由M2更新。不同节点用自己的门控系数组合这些行；原型是固定教师的类别中心，提示是可学习修正向量，两者不是同一份参数。
4. **进入主干。** 提示先经tanh压到有限范围，再按第一层隐藏特征的逐维标准差及系数10缩放。得到的修正在第一层激活前加入，后续沿同一冻结编码器计算。图上的雪花表示编码器权重冻结，不表示梯度不能经过这些运算。

## 本图涉及的名词

| 名词 | 通俗解释 |
| --- | --- |
| 特征向量 | 用一串数字描述节点属性或模型内部表示。 |
| 两跳传播 | 连续两次沿原图汇总邻居信息；含自环时也包含自身与一跳的信息。 |
| 原型 | 代表某个类别的中心向量。 |
| 软分配 | 对每个类别给出一个权重，允许同一节点部分属于多类。 |
| softmax | 把一组分数转换为非负、总和为1的权重。 |
| 温度 | 控制softmax分布集中程度的正数，越小越集中。 |
| 中心化 | 减去共同均值，保留相对偏移。 |
| 门控 | 决定各类别提示对某个节点如何起作用的系数。 |
| tanh | 将数值平滑限制在-1到1之间的函数。 |
| 预激活 | 经过一层线性/图卷积计算、尚未使用非线性激活时的值。 |
| 仿射投影 | 用线性映射加平移将高维位置显示在二维平面上；加权平均的位置关系保持，但角度与距离不一定保持。 |
