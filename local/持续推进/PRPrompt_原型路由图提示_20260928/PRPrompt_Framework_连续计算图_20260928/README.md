## 阅读与设计依据

实际查看本地论文中的 GPF Figure 1、GPPT Figure 1、MultiGPrompt Figure 2，以及 GraphPrompt Figure 2。

- [GPF / Universal Prompt Tuning for Graph Neural Networks](https://arxiv.org/abs/2209.15240)：借鉴冻结编码器与提示向量的具象符号表达。
- [GPPT](https://doi.org/10.1145/3534678.3539249)：参考图节点、编码器及提示结构之间的直接计算连线。
- MultiGPrompt：参考提示支路和冻结编码器之间的插入关系，以及训练反馈的辅助层级。本地论文位于项目 ref 目录。
- [GraphPrompt](https://arxiv.org/abs/2302.08043)：参考以共享计算对象组织方法的阅读顺序。

参考的是图形表达方式，未复用论文图像。图中所有内容均为原生可编辑图元。旧稿保留历史，但不再作为当前框架图入口。

## 图注草稿

PRPrompt 的总体框架。M1 由传播属性与支持标签构造原型，经软分配、融合迭代、锐化、中心化及原图传播形成固定路由；路由组合共享残差并注入冻结图编码器的第一层预激活。M2 利用类别轴和特征轴的梯度统计确定矩阵更新方向，以同轨迹 Adam 候选范数匹配整体更新长度，仅更新共享残差参数。训练后，基础 M3 从适配表示构造原型初始概率与余弦近邻读出图，在迭代融合中回注初始概率并恢复支持标签，输出查询预测。节点颜色与向量长度仅示意，不表示实验数值。

## 校验范围

对照当前基础 M3 叙事核查：唯一学习参数 P；第一层预激活注入；Adam 仅提供候选范数；读出图来自适配表示；初始概率回注与支持标签恢复；不含 M3-T、M3-LC 或超参数数值。已进行 PNG 视觉检查。XML 结构验证无错误，重叠提示主要来自冻结编码器外框与内部图元、锁图标的组合绘制。
