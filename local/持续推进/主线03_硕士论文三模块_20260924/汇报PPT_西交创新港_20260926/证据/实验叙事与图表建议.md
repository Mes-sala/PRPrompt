# 实验叙事与可审计数据

2026-09-26，为 XJTU 科研汇报整理；仅重算封存记录，没有新训练。**主表只使用最新 1680 条/14 方法统一协议。** 早期确认轮单独承担机制、直接教师和交互边界分析，不与主表混算。

## 适合汇报的八条主结论

1. **有限监督需要贯穿“分配—更新—读出”。** 一个固定教师产生节点类别条件，一组类别提示矩阵被注入同一个冻结 GCN。M1 改变节点对类别提示的分配；M2 决定这组提示的更新方向与尺度；M3 在最终适配表示上继续施加邻域与支持标签约束。功能依赖解释组合逻辑，组件贡献与统计交互分别由实验回答。
2. **完整方案稳定改善既有条件 Prompt 基础。** 最新统一轮中，F111 相对 F000 的 Accuracy 六格均提高，增量 **+2.210～+18.815 pp**，六个配对 95% 区间下界均正。F000 已经有教师、类别 token、普通温度门控与 Adam，不能把此前条件 Prompt 的全部收益归给三个新开关。
3. **M1 的收益随冻结表示而变。** Accuracy 移除差从 Cora/Edgepred_Gprompt 的 **−0.060 pp** 到 Cora/DGI 的 **+8.900 pp**；前者区间跨零。早期 CiteSeer/Edgepred_GPPT 的 raw 锐化比等范数锐化高 **+2.030 pp**，比仅幅度变化高 **+2.315 pp**，支持形状与幅度共同作用；不能说锐化纠正了教师类别排序。
4. **M2 在 DGI 明显有效，在 Edgepred_GPPT 未确认独立收益。** DGI 两格为 **+12.095、+11.260 pp**，区间均正；Edgepred_GPPT 两格为 **−0.060、+0.185 pp**，区间跨零。早期完整矩阵相对对角近似在 DGI 为 **+3.475、+3.710 pp**，但 Cora/Edgepred_GPPT 为 **−0.455 pp**，区间均不跨零，说明完整矩阵结构并非始终必要。
5. **M3 是本轮最一致的增量来源。** 六格 Accuracy 移除差 **+0.395～+2.450 pp**，配对区间下界均正。它是训练后的表示近邻概率读出，不反向传播；原 GCN/教师已经利用图结构，因此不宜说“首次引入结构”。早期 Actor/GraphCL 中 M3 为 **−0.053 pp**、区间跨零，适用范围仍有边界。
6. **内部改进不能替代外部竞争力。** 四个 Edgepred 配置高于本轮九个外部对照的平均 Accuracy；DGI 两格仍低于 GPrompt **4.260、9.865 pp**。本轮固定 100 次更新，保留方法原生输入/读出，并未做等额支持集超参数搜索；DAPrompt-fixed 仅是固定底座的提示阶段适配，不能用本轮结果评价原论文最佳性能。
7. **功能衔接成立，但统计协同有条件。** 早期八格全因子中，M3 开启时 M1×M2 的交互在 DGI 为 **+3.680、+4.515 pp**，在 Edgepred_Gprompt 为 **−0.690、−0.985 pp**，区间均不跨零。建议说“功能衔接与条件性交互”，不要说“三模块普遍协同”。最新五格消融缺少完整八格，不能直接重算完整交互。
8. **直接教师仍是必须正面面对的强对照。** 早期同轮 Cora/Edgepred_Gprompt 完整方法超过未中心化教师 **+1.885 pp**；CiteSeer/Edgepred_Gprompt 低于中心化教师 **−2.100 pp**。DGI 两格低于未中心化直接教师 **−21.920、−20.915 pp**。最新统一轮未重跑直接教师；早期均值不能拼到最新主表当作配对证据。当前最稳妥结论是“对条件 Prompt 的改进得到支持，超过直接教师的普遍价值尚未建立”。

## 建议的实验页顺序

1. **实验协议页：哪些条件被固定。** 六份 checkpoint、每类 5 个支持样本、20 个共同支持采样、100 次更新、14 方法、1680 行；仅训练 C×128 个参数（Cora 896，CiteSeer 768）。页脚说明同图支持采样、转导访问无标签节点。
2. **整体收益页：相同基础上，完整流程是否有用。** 六格 F000→F111 哑铃图，旁边一句“六格配对 CI 下界均正”。避免把三种底座平均成一个数字。
3. **四指标页：分类与排序是否一致改善。** 六格×四指标增量热图，Cora/Edgepred_GPPT 的 AUC 用空心/星号明确跨零，旁边解释 F1/AUC/AP。
4. **组件作用页：哪个环节在什么条件下有用。** 六格×三模块增量热图或三列森林图，跨零标记；重点标注 DGI 内部作用强，M3 本轮最一致。
5. **机制对照页：不是只换了名字。** 早期同轮 M1 形状/幅度、M2 矩阵/对角的 4～5 个精选对照，同时保留 Cora/Edgepred_GPPT 的负差；页角明确“早期独立 seed 组”。
6. **竞争力页：内部收益与外部领先分开。** 两组（三底座×两数据集）柱状图，显示本方案和本轮外部最优，DGI 失败格用对比色突出。DAPrompt-fixed 适配边界放脚注。
7. **边界页：何时值得采用完整适配。** 左侧早期直接教师与 F111 同轮对比；右侧“组合合理≠普遍协同、参数高效≠计算成本可忽略”。交互细表和 Actor 负例可放附录，但正文至少口头/短句保留。

## 可复用统计口径与来源字段

- 主源：`三底座统一协议对比_20260924/all_metrics.json`，`rows[].metrics.accuracy / macro_f1 / roc_auc_macro_ovr / auprc_macro` 是小数；展示均值、SD 乘以 100。按 `dataset, checkpoint, method` 分组，按 `seed` 对齐，检查 `split_sha256` 相同。
- 配对源：`all_metric_pairs.json`，`mean / sd` 已是 %；`full_minus_method / ci_low / ci_high` 已是 pp。不要再次乘以 100。
- 早期源：主线03目录下三个 `stage2*/confirmation_pairs.json`；`cells[].accuracy` 与 `cells[].contrasts` 已是 %/pp。复核已读取这些阶段的 **2380 个原始 `results/*/*/result.json`**。
- 本次完整重算主轮 **420 组**均值、样本 SD、配对差与 10000 次 bootstrap CI，最大误差 **0**；120 个同 checkpoint 同 seed 的跨方法划分组相同。早期关键对照最大误差也为 **0**。
- Bootstrap 固定种子 20260924，10000 次；每次对 20 个支持采样 seed 有放回重采样；取排序后索引 249、9749。区间仅反映固定图、固定查询集下的支持采样不确定性，未校正多重比较。
- `final_audit.json` 的 1440 行是核心12方法；`extension2026/final_audit.json` 的 240 行为 MTG、DAPrompt-fixed 扩展。两者组成 1680；`metrics_transport_verified.json` 明确 1680 行复算通过，`state.json` 为 complete_audited_synced。PPT 不应把旧审计的 1440 写成最新总数。

## 近期证据是否改变旧叙事

已检查主线03 `research_state.json`、`completion_evidence_audit.json`、三个确认轮、最新统一协议状态/扩展审计，以及 2026-09-25 叙事重构。当前可见的更新是：
