> 本文解释当前已经运行的方案，包括组织方式、各模块输入输出、计算步骤、公式、实现细节与术语。依据为2026-09-24三底座统一协议的锁定源码。本文是方案设计说明，不是新增算法或新一轮实验计划。
> 
> 阅读建议：先看第1、2节把握整体，再阅读第4–7节理解计算过程。公式符号见第3节；不熟悉的专业词可查第12节。正文首次出现的重要名词也提供简要解释。

## 1. 方案究竟在做什么

任务是**少样本节点分类**：一张图包含许多对象，每个对象是一个“节点”，对象之间的关系是“边”；只知道少量节点的类别，希望预测其他节点的类别。例如，在论文引用图中，论文是节点，引用关系是边，节点属性可以是论文的词特征，类别可以是研究主题。

本方案使用一个已经预训练好的两层**图卷积网络（GCN）**。GCN会结合节点自身与邻居的信息，把原始属性变成便于分类的数字向量。已经学好的网络称为**主干**；本方案将主干**冻结**，也就是不再改变其权重。

为了适应当前分类任务，系统另外学习一小组**提示参数（Prompt token）**。这里的token是一行可学习的数字向量，不是自然语言中的词。每个类别对应一行，共同组成一个矩阵。系统根据各节点的类别倾向，用不同系数组合这些向量，将组合结果加入主干中间层，改变节点的表示。

三个模块分工如下：

| 模块          | 通俗理解                  | 实际负责的事情                  | 是否有独立可学习权重            |
| ----------- | --------------------- | ------------------------ | --------------------- |
| M1：语义门控锐化   | 决定每个节点怎样使用各类别的提示      | 调整节点到类别token的分配，并生成隐藏层修正 | 门控本身没有；修正使用共同的token矩阵 |
| M2：更新尺度匹配   | 决定这些提示参数每一步怎样改        | 计算token的更新方向，并控制更新幅度     | 没有新增模型权重；维护优化器统计量     |
| M3：支持约束概率传播 | 让相似节点参考彼此的预测，同时相信已知标签 | 在适配后的表示近邻图上更新类别概率        | 没有                    |

整个系统只有一个冻结GCN和一组可学习token。M1、M2、M3不是三个各自训练的模型，也不是最后把三个模型的预测投票相加。

### 2.1 三个阶段如何衔接

**准备阶段。** 从图属性和原图关系生成教师特征，利用已知标签和无标签属性计算类别分数，再生成固定门控；同时计算冻结第一层的输出。

**训练阶段。** 从零初始化token，重复100次“生成提示—主干前向—计算支持集损失—更新token”。“前向”就是从输入逐层计算输出；“损失”是衡量预测与已知标签不一致程度的数值；“梯度”告诉我们参数的小幅改变会如何影响损失。

**读出阶段。** 用最后一次更新后的token重新计算节点表示，对其做共同中心化，再计算类别原型和表示近邻图。M3在近邻图上进行20轮概率传播，输出最终类别。“读出”指从向量表示得到类别分数或预测的过程。

### 2.2 支持标签在三个位置使用

**支持集**是本轮允许使用标签的节点集合。本轮每类有5个支持节点，即5-shot。**查询集**是最后用于评价预测效果的节点集合。

支持标签用于：①建立教师的初始类别原型；②计算token训练损失；③在概率传播中固定支持节点的类别。查询节点的真实标签不进入这三处计算。

这是**转导学习**：训练时能够看到包括查询节点在内的全图属性和结构，但看不到它们的真实类别。除支持节点外的无标签集合还可能包含其他可见节点，不一定恰好等于用于测试的查询集。

### 2.3 系统里有两张作用不同的图

| 图     | 来自哪里             | 用在哪里                | 是否因token训练而改变         |
| ----- | ---------------- | ------------------- | --------------------- |
| 原图    | 数据集给定的边，例如引用关系   | 两层GCN、教师两跳属性传播、门控传播 | 不改变                   |
| 表示近邻图 | 根据最终节点向量的相似度重新计算 | M3的类别概率传播           | 构建结果依赖最终token；训练结束后固定 |

## 3. 符号、形状与基本运算

**张量**可以理解为有形状的数字表：一维是向量，二维是矩阵。下表的 $ N\times C $ 表示有 $ N $ 行、$ C $ 列。

| 符号                           | 含义                            | 形状或范围                             |
| ---------------------------- | ----------------------------- | --------------------------------- |
| $ N,F,C,d $                  | 节点数、原始属性维数、类别数、隐藏表示维数         | 当前 $ d=128 $                      |
| $ X,E $                      | 节点属性矩阵、原图边集合                  | $ X\in\mathbb{R}^{N\times F} $    |
| $ S,y_i $                    | 支持节点集合、支持节点 $ i $ 的真实类别       | 每类5个支持节点                          |
| $ \widehat A $               | 原图的归一化邻接矩阵，含自环                | $ N\times N $                     |
| $ R,\widetilde R $           | 两跳传播属性、其中心化版本                 | $ N\times F $                     |
| $ o_c,c_c^{(j)} $            | 第 $ c $ 类原始支持原型、第 $ j $ 次修正原型 | 每个是 $ F $ 维向量                     |
| $ B,\Pi_T,Q_T $              | 教师分数、温度处理后的概率、最终门控            | 均为 $ N\times C $                  |
| $ U,H,Z_P $                  | 第一层预激活、提示激活后表示、第二层输出          | 均为 $ N\times d $                  |
| $ P $                        | 唯一可学习的类别token矩阵               | $ C\times d $                     |
| $ s_U $                      | 第一层输出在各维度上的标准差                | $ d $ 维                           |
| $ G_t,L_t,R_t $              | 第 $ t $ 步token梯度、左右梯度统计矩阵     | $ C\times d,C\times C,d\times d $ |
| $ D_t,A_t $                  | 矩阵预条件方向、Adam候选方向              | 均为 $ C\times d $                  |
| $ \overline Z,\widehat z_i $ | 最终中心化表示、节点单位长度向量              | $ N\times d $、$ d $ 维             |
| $ \mu_c,W $                  | 最终类别原型、近邻传播权重矩阵               | $ d $ 维、$ N\times N $             |
| $ F_0,F^{(t)},Y_S $          | 初始类别概率、第 $ t $ 轮传播概率、支持标签独热矩阵 | 前两者 $ N\times C $；后者 $            |

注意：教师特征 $ R $ 与优化器统计 $ R_t $ 是不同变量；图邻接 $ \widehat A $ 与Adam方向 $ A_t $ 也是不同变量。

常用运算：

- $ \operatorname{norm}(v)=v/\max(\lVert v\rVert_2,\epsilon) $：把向量长度缩放到约1，保留方向，零向量通过小常数保护。$ \lVert v\rVert_2 $ 是向量的欧氏长度。
- $ \operatorname{softmax}(b)_c=\exp(b_c)/\sum_k\exp(b_k) $：把一组任意实数分数变为非负、总和为1的概率。
- $ AB $ 或代码中的 `A @ B`：矩阵乘法；$ \odot $：逐元素相乘，即对应位置分别相乘。
- $ A^\top $：转置，把矩阵的行列交换。$ I $：单位矩阵，对角线为1，其余为0。
- $ \operatorname{mean}_V $：对所有节点取均值；$ \lVert M\rVert_F $：Frobenius范数，即矩阵全部元素平方和的平方根。
- $ \arg\max_c $：选择分数最大的类别编号；$ \log $：自然对数；$ \exp $：自然指数函数。
- $ \epsilon $：用于避免除零或数值问题的小正数。不同位置使用的值不一定相同。

## 4. 共同基础：冻结主干、提示参数和训练目标

### 4.1 输入与原图归一化

当前Cora/CiteSeer使用`NormalizeFeatures`预处理节点属性。在这些非负词特征上，它相当于按节点对属性做行和归一化，即把同一节点的属性总量调整到可比较尺度。这里的行和归一化不同于后文把向量欧氏长度变为1的L2归一化。

原图加入**自环**，即允许节点也接收自身信息；随后按节点度数缩放邻居信息。在当前无向原图的常用矩阵记法下：

$$
\widetilde A=A+I,\qquad
\widehat A=\widetilde D^{-1/2}\widetilde A\widetilde D^{-1/2}.
$$

$ A $ 是原始邻接矩阵，有边的位置非零；$ \widetilde D $ 是记录加自环后节点度数的对角矩阵。**度数**就是节点连接的边数或权重总和。归一化用于避免邻居很多的节点仅因连接数量多而产生过大的累加值；实际实现由PyG的`gcn_norm`与GCN层处理边索引。

### 4.2 唯一可学习参数与前向过程

冻结第一层先计算：

$$
U=\operatorname{GCN}_1(X,E),\qquad
s_{U,k}=\max\bigl(\operatorname{std}_{i=1}^{N}U_{ik},10^{-6}\bigr).
$$

$ U $ 是激活函数之前的输出，因此叫**预激活**。$ s_U $ 记录每个隐藏维度在节点之间的波动大小；小值截断防止某维尺度完全为零。

学习参数初始化为 $ P=0\in\mathbb{R}^{C\times128} $。得到门控 $ Q_T $ 后，前向过程为：

$$
\Delta U=10\,[Q_T\tanh(P)]\odot s_U,
$$

$$
H=\operatorname{LeakyReLU}(U+\Delta U),\qquad
Z_P=\operatorname{GCN}_2(H,E).
$$

矩阵乘法 $ Q_T\tanh(P) $ 将“每个节点的类别系数”与“各类别的修正向量”组合成每个节点的修正。$ \tanh $ 把每个token数值压到 $ (-1,1) $，有助于限制token作用幅度，但不保证整个修正范数恒定。$ s_U $ 为各维修正提供主干内部的尺度参照，乘法会沿节点维自动复制这一向量，称为**广播**。系数10是锁定配方中的固定幅度，不是本轮训练学出的数值。

**LeakyReLU**是带少量负半轴输出的激活函数：正数保持原值，负数乘一个小斜率；当前工具函数默认采用PyTorch的0.01负斜率。它给前向计算引入非线性。

零初始化意味着最开始 $ \Delta U=0 $，恢复冻结主干的输出，属于**无操作起点（no-op）**。这不意味着开始时不能学习：$ \tanh $ 在零点仍有非零导数，token可以接收梯度。

当前token参数量为 $ C\times128 $：Cora有7类，对应896个参数；CiteSeer有6类，对应768个参数。代码中的备用`tokens2`在当前分支没有加入优化参数列表。

### 4.3 支持集留一原型损失

**原型**是一个类别的代表向量。本方案将支持节点表示归一化后求平均，再将均值归一化作为类别代表。训练时采用**留一原型**：评价某个支持节点时，把它自己从所属类别原型的计算中排除，避免它通过“自己与自己相似”过于容易地完成分类。

设 $ v_i=\operatorname{norm}(Z_{P,i}) $，$ S_c $ 是第 $ c $ 类支持节点。对支持节点 $ i $，计算：

$$
\mu_c^{(-i)}=\operatorname{norm}\left(
\frac{\sum_{j\in S_c}v_j-\mathbb{1}[y_i=c]v_i}{|S_c|-\mathbb{1}[y_i=c]}
\right),\qquad
\ell_{ic}=\frac{v_i^\top\mu_c^{(-i)}}{0.2}.
$$

$ \mathbb{1}[y_i=c] $ 是**指示函数**：条件成立取1，否则取0。$ \ell_{ic} $ 是**logit**，即尚未变成概率的类别分数。单位向量点积等于**余弦相似度**，用于比较方向是否相近。除以0.2控制类别概率的集中程度。

训练损失为：

$$
\mathcal L=-\frac{1}{|S|}\sum_{i\in S}
\log\frac{\exp(\ell_{i,y_i})}{\sum_c\exp(\ell_{ic})}
+0.001\operatorname{mean}(P\odot P).
$$

第一项是**交叉熵**：真实类别概率越低，惩罚越大；第二项是**正则项**：惩罚过大的token，防止参数仅为降低训练误差而不断增大。

留一只发生在训练分类原型中，不会重新删除该节点在固定门控教师中的标签；不能将它解释为整套系统对该节点进行了完整留一重训练。每类5-shot时留一后仍有4个同类支持节点，当前公式不能原样用于1-shot。

当前**知识蒸馏（KD）**损失关闭。知识蒸馏通常指用教师概率指导学生模型学习；源码仍计算KD诊断值，但实际训练目标只有上面两项。字符串`token_ridge_kd10plain`保留了历史命名，不能据此判断当前KD已开启。

## 5. M1：语义门控锐化的完整设计

### 5.1 设计目标与接口

本模块希望让不同节点以更有区分度的方式使用类别token。这里的**语义**就是当前任务的类别信息；**门控**就是控制不同类别token作用大小的一组系数。

输入是全图属性、原图关系和支持标签；输出是固定的 $ N\times C $ 门控矩阵。教师构造和普通温度门控属于所有分支共享的基础，M1开关只决定是否将门控温度从0.2改为0.1。

### 5.2 第一步：构造教师使用的属性空间

$$
R=\widehat A(\widehat AX),\qquad
\widetilde R=R-\operatorname{mean}_V(R),\qquad
r_i=\operatorname{norm}(\widetilde R_i).
$$

连续两次沿原图聚合称为**两跳传播**：节点特征吸收经过两次邻接聚合可到达的节点信息。由于存在自环，并不只包含距离恰好为2的节点。

减去全图均值叫**中心化**，将所有节点共有的偏移移除。这一步在原始属性维度 $ F $ 上进行，不需要调用预训练GCN。之后将各节点向量归一化，便于通过方向比较相似性。

### 5.3 第二步：支持原型与无标签软原型共同生成教师

先用支持节点形成每类原始原型：

$$
o_c=\frac{1}{|S_c|}\sum_{i\in S_c}r_i,\qquad c_c^{(0)}=o_c.
$$

令 $ \mathcal U=V\setminus S $ 为所有非支持节点。重复3次如下修正：

$$
a_{ic}^{(j)}=\operatorname{softmax}_c\left(
\frac{r_i^\top\operatorname{norm}(c_c^{(j)})}{0.05}
\right),\quad i\in\mathcal U,
$$

$$
p_c^{(j)}=\frac{\sum_{i\in\mathcal U}a_{ic}^{(j)}r_i}
{\max(\sum_{i\in\mathcal U}a_{ic}^{(j)},10^{-8})},\qquad
c_c^{(j+1)}=0.5o_c+0.5p_c^{(j)}.
$$

$ a_{ic}^{(j)} $ 是**软分配**：一个节点可按不同权重参与多个类别，而不是立刻被指定为某一类。$ p_c^{(j)} $ 是**软原型**：对无标签节点按上述概率加权求平均。每轮都与最初支持原型 $ o_c $ 混合，保留真实标签提供的参照，避免类别中心完全由无标签预测支配。

3轮后，教师分数为：

$$
B_{ic}=\frac{r_i^\top\operatorname{norm}(c_c^{(3)})}{0.2}.
$$

**教师**在这里是这套固定原型计算产生的参考分数，不是另一套可训练神经网络。软分配使用了非支持节点特征，却没有使用其真实类别。

### 5.4 第三步：温度锐化、中心化与原图传播

$$
\Pi_T=\operatorname{softmax}(0.2B/T),\qquad
Q_T=\widehat A\left(\Pi_T-\operatorname{mean}_V\Pi_T\right).
$$

**温度**是控制softmax分布集中程度的正数。普通分支 $ T=0.2 $，完整方案 $ T=0.1 $。因为 $ B $ 已含一次除以0.2，所以代码使用 $ 0.2B/T $，等价于“余弦分数除以当前门控温度”；不能再误写成 $ B/T $。

**锐化**就是降低温度，使高分项概率更高、低分项概率更低。例如，两个原始相似度为0.2和0.1时，温度0.2得到约[0.622,0.378]，温度0.1得到约[0.731,0.269]。类别最大值的位置没有改变，只是分布更集中。此例仅解释运算，不是实验结果。

随后对每个类别减去其全图平均概率，使门控表达“这个节点对某类别的倾向相对全图平均高或低”；再沿原图传播一次，结合原图邻域的类别倾向。因此最终 $ Q_T $ 可以出现负数，行和也不再是1，它是有正负的修正系数，不再是类别概率。

门控生成后保持固定，不随token每一步更新。M1并不学习教师，也不保证教师判断变准确：错误的高分同样可能被锐化。

### 5.5 第四步：门控组合token，影响同一主干

对节点 $ i $：

$$
\Delta u_i=10\left(\sum_{c=1}^{C}Q_{T,ic}\tanh(P_c)\right)\odot s_U.
$$

各类别token是共享的，但不同节点的组合系数不同，所以能得到不同提示。这里的token类别索引来自门控，但token本身是学习得到的修正向量，不是支持原型的副本。

### 5.6 对照设计与作用边界

改变温度同时可能改变门控的分配形状和总体范数。为区分两种影响，历史确认中有以下对照：

| 对照    | 操作                | 想排除或检验的问题           |
| ----- | ----------------- | ------------------- |
| 普通温度  | $ T=0.2 $         | 锐化相对共同基础是否有增量       |
| raw锐化 | $ T=0.1 $，不额外改范数  | 当前完整模块的总效果          |
| 等范数锐化 | 锐化门控除以其相对普通门控的范数比 | 收益是否只由总幅度变化造成       |
| 仅幅度变化 | 普通门控乘以上述范数比       | 不改变分配形状，仅改变幅度能否解释收益 |

这些对照用于解释操作，不足以保证“语义更正确”。当前六格统一协议未全部重跑这些诊断对照，其记录在早期确认阶段。

## 6. M2：更新方向与尺度匹配的完整设计

### 6.1 为什么它是训练模块

M1给出了怎样使用token的规则，但token数值还需要通过支持集损失学习。**优化器**就是根据梯度决定参数如何更新的算法。M2替换普通Adam的更新规则，仍然更新同一个 $ P $，没有添加另一套提示或分类器。

M2输入当前 $ P $、梯度 $ G_t=\partial\mathcal L/\partial P $ 和历史统计；输出下一步参数 $ P_{t+1} $。$ \partial\mathcal L/\partial P $ 表示损失对参数的导数：哪个参数小幅改变会使损失增加或降低，以及变化有多快。

### 6.2 左右矩阵统计与Shampoo方向

$$
L_t=10^{-4}I+\sum_{i=1}^{t}G_iG_i^\top,\qquad
R_t=10^{-4}I+\sum_{i=1}^{t}G_i^\top G_i.
$$

$ L_t $ 的大小是 $ C\times C $，汇总类别轴的梯度关联；$ R_t $ 为 $ 128\times128 $，汇总隐藏特征轴的梯度关联。这里的关联是梯度外积统计，不是类与类之间已被证明的语义关系。

随后构造：

$$
D_t=L_t^{-1/4}G_tR_t^{-1/4}.
$$

这是一种**矩阵预条件**：使用历史梯度统计重新缩放、组合梯度的不同方向。其核心形式来自已有优化算法**Shampoo**，不是本方案新发明的优化器原理。它属于使用梯度二阶矩统计的方法，当前代码没有计算损失的Hessian（二阶导数矩阵），不能直接称为牛顿法。

**矩阵的负四分之一次幂**不是把每个元素分别取幂。实现将对称矩阵分解为 $ L_t=V\Lambda V^\top $，对对角线特征值取 $ -1/4 $ 次幂，再组合回去：

$$
L_t^{-1/4}=V\Lambda^{-1/4}V^\top.
$$

这叫**特征分解**。$ V $ 表示不同方向，$ \Lambda $ 表示这些方向对应的数值尺度。初始化的 $ 10^{-4}I $ 为统计矩阵加入稳定项，便于计算负幂。

### 6.3 同轨迹Adam候选方向

**Adam**是的自适应优化器，会平滑历史梯度，并根据各坐标历史梯度平方调整更新。M2在自身实际经过的每一步上，同时维护Adam的候选状态：

$$
m_t=0.9m_{t-1}+0.1G_t,\qquad
v_t=0.999v_{t-1}+0.001(G_t\odot G_t),
$$

$$
\widehat m_t=\frac{m_t}{1-0.9^t},\qquad
\widehat v_t=\frac{v_t}{1-0.999^t},\qquad
A_t=\frac{\widehat m_t}{\sqrt{\widehat v_t}+10^{-8}}.
$$

这里最后的除法逐元素进行。$ m_t $ 是梯度的指数滑动平均，常称**一阶矩**；$ v_t $ 是梯度平方的指数滑动平均，称**二阶原点矩**。一阶、二阶在这里指统计量的次数，不表示计算了一阶和二阶导数。带帽变量做了**偏差校正**，补偿从零初始化时滑动平均在前几步偏小的问题。

“同轨迹”意味着这些统计使用M2实际访问参数位置上的梯度，不是另开一个Adam模型训练100步后拿到的梯度。因此它只提供当前轨迹上的Adam参照。

### 6.4 用Adam范数控制Shampoo方向的长度

$$
\widetilde D_t=
\begin{cases}
D_t\dfrac{\lVert A_t\rVert_F}{\lVert D_t\rVert_F},&\lVert D_t\rVert_F>0,\\
0,&\lVert D_t\rVert_F=0,
\end{cases}
\qquad P_{t+1}=P_t-0.01\widetilde D_t.
$$

直观上，$ D_t $ 决定“往哪个方向走”，Adam范数决定“这一步走多长”。这种把一种算法的方向与另一种算法的尺度组合的做法称为**grafting（嫁接）**。当方向为零时保持不动，不借用非零动量强行更新。

举例：假设矩阵方向范数为2、Adam候选方向范数为6，便将矩阵方向乘3；学习率0.01使实际名义更新范数变为0.06。这里的匹配是整个token矩阵的Frobenius范数匹配，不是每个元素都与Adam一致，也不是与独立Adam训练的每一步严格一致。

### 6.5 实现组织与额外成本

左右统计和特征分解在CPU的**float64**中计算，也就是使用64位浮点数提高数值精度；更新再转成GPU参数所用的数值类型。CPU是通用处理器，GPU是适合大规模并行运算的处理器。数据类型转换存在舍入，所以精确匹配的是计算出的名义范数，实际参数加法还受float32舍入影响。

M2需要维护两个统计矩阵、Adam状态并执行矩阵分解，参数少不意味着训练开销可忽略。历史对照包括普通Adam、只使用对角统计的预条件，以及不进行Adam范数匹配的Shampoo；这些对照分别检验更新替换的收益、完整矩阵的必要性和尺度匹配的作用。

## 7. M3：支持约束概率传播的完整设计

### 7.1 训练结束后重新计算表示

完成第100次参数更新后，使用最终token重新前向得到 $ Z_P $，再做：

$$
\overline Z=Z_P-\operatorname{mean}_V(Z_P),\qquad
\widehat z_i=\operatorname{norm}(\overline Z_i).
$$

这次中心化在GCN输出空间进行，与M1教师属性空间的中心化不同。当前训练损失使用未进行这次最终中心化的 $ Z_P $；不能把训练过程误写为每一步先中心化再求损失。最终中心化是所有因子分支共享设置，不是M3独有贡献。

### 7.2 建立初始类别概率

$$
\mu_c=\operatorname{norm}\left(\frac{1}{|S_c|}\sum_{i\in S_c}\widehat z_i\right),\qquad
(F_0)_{ic}=\operatorname{softmax}_c\left(\widehat z_i^\top\mu_c/0.2\right).
$$

这里使用所有支持节点建立最终原型，不再留一。$ F_0 $ 表示尚未传播时每个节点的类别概率，也是M3不断回到的原始预测参照。

### 7.3 根据最终表示建立50近邻图

对每个节点 $ i $，排除自己后，找到余弦相似度最高的50个节点，记为 $ \mathcal N_{50}(i) $。这叫**k近邻（kNN）**，这里 $ k=50 $。建立权重：

$$
W_{ij}=\begin{cases}
\dfrac{\exp(\widehat z_i^\top\widehat z_j/0.2)}
{\sum_{k\in\mathcal N_{50}(i)}\exp(\widehat z_i^\top\widehat z_k/0.2)},&j\in\mathcal N_{50}(i),\\
0,&\text{其他情况}.
\end{cases}
$$

每一行权重之和为1，称为**行归一化**。节点 $ i $ 选择节点 $ j $，不保证节点 $ j $ 也选择节点 $ i $，所以这个近邻关系可以是有向的；代码没有额外对称化。这里只排除自邻居，没有沿用原图的自环设置。

实际实现按1024个节点分块计算与全图的相似度，以降低一次性中间内存需求；但总的相似度计算仍是 $ O(N^2d) $ 量级。$ O(\cdot) $ 是大O记号，描述数据规模增大时运算量大致如何增长。分块不等于把精确近邻搜索改成了线性复杂度。当前`qeps-50`路径要求至少51个节点，没有自动对小图缩小50这个数。

### 7.4 支持标签钳制与20轮概率迭代

设 $ Y_S $ 为支持标签的**one-hot（独热）**表示：真实类别位置为1，其他位置为0。先复制 $ F_0 $ 为传播状态 $ F^{(0)} $，并将支持节点行替换为 $ Y_S $；之后执行20轮：

$$
F^{(t+1)}=0.1F_0+0.9WF^{(t)},\qquad
F^{(t+1)}_S=Y_S.
$$

$ WF^{(t)} $ 是按邻居权重计算的类别概率平均。系数0.9控制对邻居预测的依赖，0.1保留未经传播的初始预测。持续将已知标签固定称为**钳制（clamping）**。

注意，原始 $ F_0 $ 与初始化后已钳制的 $ F^{(0)} $ 概念不同：代码保留原始 $ F_0 $ 用作每轮回注项，并对每轮更新结果重新钳制支持行。代码固定运行20次，不以达到收敛阈值为停止条件。

例如，一个非支持节点的原始两类概率为[0.55,0.45]，当前邻居加权概率为[0.80,0.20]，下一轮概率就是[0.775,0.225]。这是计算示例，不保证现实中的邻居判断一定正确。

### 7.5 输出及源码中容易误读的部分

最终输出分数为：

$$
\operatorname{score}_{ic}=\log\max(F^{(20)}_{ic},10^{-12}),\qquad
\widehat y_i=\arg\max_c\operatorname{score}_{ic}.
$$

对数不会改变概率的大小顺序；$ 10^{-12} $ 防止出现对零取对数。代码随后封存查询节点的分数和预测，再使用查询真实标签计算指标。

实际调用链是`diffusion_readout` → `qe_readout(kind='qeps-50')` → `propagate`。`qe_readout`是多种历史读出方式共用的函数，因此其中还计算、保存了`expanded_embedding`（近邻聚合后的扩展表示），但`qeps`分支的最终预测覆盖为原始适配表示上的概率传播结果。**不能因为看到了扩展表示的代码，就把当前M3画成“先聚合嵌入再分类”。**

M3没有可学习分类头，也不反向更新token。它假设表示近邻具有有用的类别一致性；当相近向量不对应相同类别时，传播可能扩散错误。

## 8. 从输入到输出的完整操作步骤

```text
输入：节点属性 X、原图边 E、支持节点 S 及标签、冻结的两层 GCN
输出：查询节点类别分数和预测

准备阶段：
  1. 按协议预处理属性；生成包含自环的原图归一化传播算子。
  2. 计算两跳属性 R，全图中心化后构造支持原型。
  3. 对非支持节点进行软分配；与支持原型混合，固定修正 3 次。
  4. 得到教师分数 B；以 T=0.1 锐化，中心化并传播，固定门控 Q。
  5. 计算冻结第一层预激活 U 与每维标准差。
  6. 初始化唯一训练参数 P=0；建立优化器统计。

训练阶段，重复 100 次：
  7. 计算 ΔU = 10 × (Q @ tanh(P)) × std(U)。
  8. 计算 H=LeakyReLU(U+ΔU)，通过冻结第二层得到 Z。
  9. 对支持节点计算留一原型交叉熵，加上 token 均方正则。
 10. 反向计算 P 的梯度，更新左右矩阵统计及同轨迹 Adam 状态。
 11. 用 Shampoo 方向配合 Adam 范数，更新 P；主干权重不变。

最终读出：
 12. 使用更新后的最终 P 重新前向；将最终 Z 做全图中心化。
 13. 计算支持原型概率 F0，并构造 50 近邻权重 W。
 14. 初始化传播状态并钳制支持标签；固定进行 20 轮概率传播。
 15. 输出对数概率与最大概率类别。
 16. 封存分数、预测、支持与查询索引，再评价查询标签。
```

冻结主干与梯度计算并不矛盾：主干权重不更新，但第二层的运算仍影响token如何改变损失，梯度需要穿过它。相反，第一层输出不依赖token，可以提前计算并缓存。**缓存**就是保存重复使用的中间结果，避免重复计算。

## 10. 为什么这三个模块能组织成一个方案

M1定义了“节点怎样使用token”，也影响损失向token传回的梯度；M2基于这些梯度学习同一组token，决定最终隐藏修正；M3使用前两者共同形成的最终表示来建立原型和近邻。它们有清楚的前后依赖。

这种依赖是功能层面的：M1与M2共同作用于表示适配，M3负责结果读出。M3不会反馈改变门控，教师不会随token训练反复更新，当前系统也没有三个模块共同优化的统一端到端损失。**端到端训练**指最终目标的梯度贯穿全部可训练处理环节；本方案的M3在反向训练之外。

“组合有逻辑”也不等于“每项在所有场景都有效”。当前统一实验中，三项Accuracy移除差的配对区间均为正只出现在DGI的Cora/CiteSeer两格；这些格的完整性能仍低于GPrompt。六格完整方案相对F000均有收益，M3的Accuracy移除差区间也均为正，而M1和M2存在未确认或负收益设置。完整结果见[统一实验结论](/Users/shq/Research/GP/持续推进/三底座统一协议对比_20260924/结论与完成状态.md)。

这里的**配对区间**描述在相同支持划分下，两种设置分数差异的统计不确定性。它不会自动证明某个机制解释正确；20个支持seed也不是20张独立的图。

### 12.1 图学习与任务

| 节点分类              | 给图中的每个待预测节点分配一个类别                              |
| 邻接矩阵              | 用矩阵记录节点之间是否连接或连接权重                             |

| 适配                | 在已有模型基础上，让它更适合当前下游任务                           |

### 12.2 提示、表示与概率

| 术语                  | 通俗解释                                      |
| ------------------- | ----------------------------------------- |
| Prompt / 提示学习       | 用少量额外参数调节已有模型在当前任务中的行为                    |
| token               | 本方案中是一行可学习修正向量；不是输入文本或单词                  |
| embedding / 表示 / 嵌入 | 模型给对象生成的数字向量，用于表示它的特征                     |
| 隐藏层、预激活             | 隐藏层是模型中间计算层；预激活是应用非线性函数前的数值               |
| 激活函数、LeakyReLU、tanh | 激活函数提供非线性；LeakyReLU保留少量负值；tanh把数值压到-1与1之间 |
| 门控、条件提示             | 门控控制各token的作用系数；条件提示会依节点条件而变化             |
| 教师                  | 提供参考分数的机制；此处是修正原型算法，不是额外训练的网络             |
| 原型、软原型              | 原型代表一类的中心；软原型是按概率加权计算的中心                  |
| 软分配 / 伪标签           | 软分配允许一个节点对各类有不同权重；伪标签是模型推测的标签，不能当作真实答案    |
| logit、softmax       | logit是未经概率化的分数；softmax将一行分数变成总和为1的概率      |
| 温度、锐化               | 温度控制softmax有多集中；降低温度使分布更集中，叫锐化            |
| 中心化                 | 对数值减去均值，去除共同偏移，不等于把向量长度变为1                |
| L2归一化               | 将向量的欧氏长度缩放为1附近，便于比较方向                     |
| 行归一化                | 调整矩阵各行，使每行元素和为1；与L2归一化不同                  |
| 余弦相似度               | 比较两个向量方向的接近程度，归一化向量点积即为该值                 |
| kNN / k近邻           | 为每个对象选出相似度最高的k个其他对象                       |
| 概率传播 / 标签传播         | 沿关系图更新节点类别信息；当前传播概率并固定已知标签                |
| one-hot / 独热        | 长度等于类别数的向量，真实类别为1，其余为0                    |
| 钳制 / clamping       | 每次更新后强制某些位置恢复已知值；本方案固定支持标签                |
| 读出、分类头              | 读出是表示到预测的转换；分类头通常是可学习的末端分类器，当前M3不另训练线性头   |
| argmax              | 返回数值最大的位置；类别分数的argmax就是预测类别               |

### 12.3 训练与优化

| 术语            | 通俗解释                                               |
| ------------- | -------------------------------------------------- |
| 训练 / 拟合 / 推理  | 训练或拟合利用已知标签更新参数；推理使用已确定的参数产生预测；本方案推理还使用本任务支持标签进行读出 |
| 参数 / 超参数      | 参数由训练更新，例如token；超参数是预先设定的控制量，例如温度、学习率、轮数           |
| 前向 / 反向传播     | 前向从输入计算输出；反向计算损失对参数的梯度                             |
| 梯度、学习率、步长     | 梯度给出局部变化信息；学习率缩放更新；步长常指实际参数变化幅度                    |
| 损失、交叉熵        | 损失衡量训练预测好坏；交叉熵惩罚真实类别概率过低                           |
| 留一（LOO）       | 在评价当前支持样本时，不把它自己放入对应分类原型                           |
| 正则化           | 为控制参数大小或复杂性而加约束；当前是token平方均值惩罚                     |
| Adam          | 结合历史梯度均值及平方统计的逐坐标自适应更新算法                           |
| 动量、指数滑动平均     | 保留历史趋势并逐渐降低旧信息权重，使统计比单步值更平滑                        |
| 一阶矩 / 二阶原点矩   | 数值本身的平均及平方的平均；在Adam里不是一阶、二阶导数                      |
| 偏差校正          | 修正滑动平均从零开始时前几步系统性偏小的现象                             |
| 外积            | 一个列向量与一个行向量相乘形成矩阵，用来记录分量间的联合变化                     |
| 预条件           | 利用统计信息变换更新方向，重新平衡不同方向的变化                           |
| Shampoo       | 一类按矩阵或张量结构累计梯度统计并进行预条件的已有优化算法                      |
| grafting / 嫁接 | 将一种更新规则的方向与另一种规则的尺度组合                              |
| Frobenius范数   | 将矩阵所有元素平方求和再开根号，衡量整个矩阵的大小                          |
| 特征值 / 特征分解    | 用特殊方向及其缩放倍数来表示矩阵变换；本方案据此计算矩阵负幂                     |
| 对角矩阵 / 对角对照   | 仅主对角线非零的矩阵；对照中只用对角统计，去掉完整矩阵的交叉项                    |
| Hessian / 牛顿法 | Hessian是损失二阶导数矩阵；牛顿法利用它更新参数；当前M2不是直接计算Hessian的牛顿法  |
| 同轨迹           | 使用同一实际训练过程访问到的参数和梯度；不是两个优化器各跑一条路线                  |
| no-op / 无操作   | 模块此时不改变原输出；当前零token使隐藏修正为零                         |
| eval / detach | eval切换模型运行状态；detach切断某个张量的梯度联系；二者不是同一操作            |
| KD / 知识蒸馏     | 利用教师输出指导学生学习；本方案当前关闭该损失                            |
| VAT / 虚拟对抗训练  | 通过寻找能改变预测的微小扰动，再约束预测稳定性的训练方式；当前未使用                 |
| 端到端           | 最终训练目标通过梯度连接各可训练环节；M3在当前反向训练之外                     |
| 收敛            | 迭代变化逐渐变小或达到某种稳定标准；固定运行100步不等于已证明收敛                 |
